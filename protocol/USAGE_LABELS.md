# 用法标签与适用场景

适用于正式章节、复习及以章节为来源的教学解释。两份实际教材的标签核查见 `../research/textbook-usage-labels-2026-10-09.md`；标签与说明属于教学内容，继续使用第一部分已有说明段落，不新增正文部分或前端标签系统。

## 教学目标

学完章节后，学习者应基本掌握所教词汇：理解词形、核心义与各义项的区别，了解搭配和语法，并能判断在什么对象、场合、时代或领域中适用。常用表达通过例句和运用建立主动表达能力；特殊用法也须正确理解、辨别并在相应语境中学习使用。完整保留第一部分全部用法、第二部分例句及第三部分真实覆盖，不因少见而删除或写成“可以不学”。

全量用法覆盖可能使范文带有教学编排感，这是用户接受的取舍。第三部分继续追求连贯、有意义的作品；不以普通读物自然度为由缩减义项，也不新增固定体裁、长度或场景配额。语义、语法、词形、适用语域和事件连续性仍须正确。

## 标签的语义

| 维度 | 常见教材标记 | 教学说明 |
|---|---|---|
| 使用媒介 | Collins `SPOKEN / WRITTEN` | 主要用于口语／书面语；不等于绝对不能用于另一种媒介。 |
| 语体 | `FORMAL / INFORMAL`；Oxford `formal / colloq. [口]` | 正式／非正式、口语化。正式不等于书面，非正式不等于口头专用。 |
| 文学与修辞 | `LITERARY`；`literary [文学用语] / poet. [诗]` 等 | 文学、诗歌或修辞语境；不能一概标成书面或生僻。 |
| 使用时代与频度 | `OLD-FASHIONED`；`archaic [古义] / hist. [史义] / rare` 等实际标记 | 旧式仍在使用；古义属旧时代表达；历史义指历史事物制度；少见指频度低。四者不能互相代替。 |
| 地域 | `BRIT / AM / AUSTRALIAN / DIALECT`；`Brit. / US / N. Amer. / Austral. / NZ / dial.` 等 | 英式、美式、北美、澳大利亚、新西兰或特定方言。区分拼写、读音差异与词义地域限制。 |
| 专业领域 | `TECHNICAL / LEGAL / MEDICAL / COMPUTING / BUSINESS`；`Geol. / Law / Eccl. / Naut.` 等 | 技术、法律、医学、计算机、商业、地质、教会、航海等。保留具体领域，不一律改成学术或正式。 |
| 态度与交际效果 | `APPROVAL / DISAPPROVAL / HUMOROUS / RUDE / OFFENSIVE / EMPHASIS` 等；`derog. / joc. / euphem.` 等 | 褒义、贬义、诙谐、粗鲁、冒犯、强调或委婉。保留强度和适用对象，避免误教为无色彩替换词。 |

词性、可数性、句法模式、通常位置、单复数限制也必须说明，但不是语域。CEFR 等级、频率符号与索引排序不能直接换算成正式、口语、生僻等标签；商标、缩略或变体关系按其本义处理。

## 建设方式

1. 在逐词工作文档保留标签原文和作用范围：主词整体、单个义项、词组、派生词、拼写或读音。`usu. / often / chiefly / especially` 等程度限制应保留，不能翻成“只能”。不要把词条内例句、同义词条或读音括号的标签复制给全部义项。
2. 合并两书对应义项时保留互补标签。另一书未标不构成反证；标签冲突或作用范围不清时查原文和交叉引用，必要时用可靠现行词典核实。工作文档记录依据；正文用简明中文说明，不显示教材名、内部编码或审核过程。
3. 正文在相关用法已有说明中写“正式用语”“主要用于口语”“法律用法”“古义”等，并补足会影响实际使用的限制。已经清楚说明的无需再堆重复标签；默认用法不必统一挂“普通／中性”。
4. 无原标签但确需补充少见、较旧等判断时，先核实确切词形和确切义项，在工作文档记录独立依据及判断边界；不能仅凭感觉、缺少检索结果、长词形或少见派生后缀批量判定。证据不足时只说明已知的构词、义项关系及适用场景。
5. 例句与第三部分须符合所教标签的实际语境。历史引用、旧档案、正式发言、日常对话及专业描述均可承载相应用法；不能依靠中文译文把错误的英文义项或语域解释成正确。

## 审阅与纠错

逐项核查标签是否保留、范围是否正确，以及例句中的目标词本身是否真正表达所教义项。描述立法活动的句子不必就把其中的 `legislation` 用成“立法过程”；应判断词在句中的语义角色。结构检查通过不能替代这一步。

已发布正文纠错采用新摘要版本，保持 WORD、USE、SENTENCE 身份稳定，保留旧正文供答疑、练习来源和历史回读。修订发布不重新选词、标 VIX、领取新日课或消耗下一章音频配置。未变的语音文本及读音继续复用；改变的例句按正常音频链路处理。
