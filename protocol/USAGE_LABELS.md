# 用法标签与适用场景

适用于正式章节、复习及以章节为来源的教学解释。2026-10-27起，尚未冻结selection的新运行按[AUTHENTIC_CONTEXT](AUTHENTIC_CONTEXT.md)在用法旁建设真实语境；已有冻结选择或VIX标注的运行从[DAILY_RUN](DAILY_RUN.md)恢复原合同。两份实际教材的标签核查见[教材标签研究](../research/textbook-usage-labels-2026-10-09.md)。

## 教学目标

目标是理解词形、核心义和不同用法，了解搭配/语法，并判断对象、场合、时代和领域；常用表达逐步支持主动使用，特殊用法也须正确理解、辨别并在合适语境学习。完整教学是交付目标，个人掌握需真实反馈；不因少见删义或写成“可以不学”。

标签与限制属于相应用法说明，不另建正文部分或前端分类系统。选定语境及教学fallback须适配标签，不能为自然、简短或口语收益削去意义；也不能把专业/历史例都宣传成日常可说。真实语境的展示份数、原例取优及整块译文统一按AUTHENTIC_CONTEXT执行。

## 标签的语义

| 维度 | 常见教材标记 | 教学说明 |
|---|---|---|
| 使用媒介 | Collins `SPOKEN / WRITTEN` | 主要用于口语／书面语；不等于绝对不能用于另一媒介。 |
| 语体 | `FORMAL / INFORMAL`；Oxford `formal / colloq. [口]` | 正式／非正式、口语化。正式不等于书面，非正式不等于口头专用。 |
| 文学与修辞 | `LITERARY`；`literary [文学用语] / poet. [诗]`等 | 文学、诗歌或修辞语境，不能一概归为书面或生僻。 |
| 时代与频度 | `OLD-FASHIONED`；`archaic [古义] / hist. [史义] / rare`等 | 旧式仍在使用；古义为旧时表达；历史义指历史事物制度；少见指频度低，四者不互代。 |
| 地域 | `BRIT / AM / AUSTRALIAN / DIALECT`；`Brit. / US / N. Amer. / Austral. / NZ / dial.`等 | 英式、美式、北美、澳大利亚、新西兰或特定方言，区分拼写、读音与词义地域限制。 |
| 专业领域 | `TECHNICAL / LEGAL / MEDICAL / COMPUTING / BUSINESS`；`Geol. / Law / Eccl. / Naut.`等 | 保留技术、法律、医学、计算机、商业、地质、教会、航海等具体领域，不一律改成学术或正式。 |
| 态度与交际效果 | `APPROVAL / DISAPPROVAL / HUMOROUS / RUDE / OFFENSIVE / EMPHASIS`等；`derog. / joc. / euphem.`等 | 褒贬、诙谐、粗鲁、冒犯、强调或委婉，保留强度和对象，不误教成无色彩替换词。 |

词性、可数性、句法模式、通常位置、单复数限制也必须说明，但不是语域。CEFR、频率符号和索引顺序不能直接换算成正式、口语或生僻；商标、缩略和变体关系按本义处理。

## 建设与审阅

1. 逐词资料保留标签原文和作用范围：整词、单义、词组、派生、拼写或读音。`usu. / often / chiefly / especially`等程度不翻成“只能”，不把例句、同义词条或读音括号标签扩散至全部义项。
2. 双教材融合保互补标签；另一书未标不是反证。冲突或范围不明时回原文与交叉引用，必要时核可靠现行词典。来源和判断可回查，正文用简明中文，不打印教材名、内部编码或审核过程。
3. 影响当前理解的历史、专业、态度或对象限制先说明，其余贴相应用法补充。已清楚说明的不堆重复标签，默认用法不统一挂“普通／中性”。
4. 无原标签但确需补少见、较旧等判断，先核确切词形与意义，留独立依据和边界；不能凭感觉、长词形、检索无结果或后缀批量判断。证据不足只说明已知构词/义项/场景。
5. 实读语境中的目标词，核其真正意义、语法和语域；历史引文、旧档案、正式发言、真实对话与专业文档可各自成立。不能靠中文译文把错义或错语域补成正确。描述立法的句子也不必将`legislation`用成“立法过程”，须看词在原句中的角色。

结构检查不能替代以上判断。发现实质独立语义分支按CONTENT分配独立USE，不由标签或“或”机械拆义；所选原文的题材标签也不能反过来替教材意义定级。

## 修订与历史保护

已发布纠错采用新摘要版本，语义未变的WORD、USE和句身份保持稳定，新增意义另分身份；保留旧正文供原问答、试卷和历史回读。修订不重新选词、标VIX、领取新日课或消费下一章音频配置。未变的合格语音文本/读音复用，改变文本沿正常声音授权与未知计费保护处理，不冒用旧声音或自动重新付费。
