# 雅思表达练习协议（增量建设）

状态：申请、题目、文字作答与批改交接可运行；口语录音、转写和发音分析为待接入能力。正式日课的三部分、40 主词、VIX 标注与休息开关语义不变。表达练习是长期保存的独立练习册，在阅读器中称为“第四部分”，不写入 `chapter.md`，不占日期章节，也不沿用临时页的 48 小时期限。

## 申请与来源

读者主动申请一次表达练习。后端在申请时固定**第一章至当时最新已发布章节**的 ID、日期和正文 digest，以及显式焦点章（默认最新已发布章）。待发布申请不重复创建；超过领取期限后可重新领取，已有工作文档继续使用。申请不领取日课运行、不改 VIX，也不自动触发教材检索。休息按钮仅控制既有每日 03:00 日课；表达练习申请由独立处理通路领取，用户可在练习书架中看到其状态。若需要休息时连表达练习也暂停，应增加独立开关，不暗改现行休息语义。

随着章节增加，Codex 可以增量维护逐章主题与可迁移表达索引，但每次出题须看到第一章至焦点时刻的完整章节清单及其 digest；当前章和经主题筛选入围的旧章须回读正文。主题索引只作导航，不能用摘要替代入围章节。章节修订后，旧练习册保留当时的 digest 和题目版本，不悄悄改题。

## 题目建设

先从真实雅思任务形式与能自然讨论的日常、社会、教育等话题提出多个候选，再用累计课程内容和用户历次反馈寻找有价值的联系。当前焦点章获得显著的**判断注意力**，不设词汇命中配额；本章材料若不适合题目，使用更合适的旧章。题目不得要求使用指定单词、复述第三部分文章或展示课程内部编码。口语优先完整 Part 2 任务卡与自然递进的 Part 3 追问；Part 1 可作热身。写作优先 Academic Task 2；Academic Task 1 只有可靠可核实的图表、表格、流程等信息载体时才建立。

在 `work/expression/<request-id>/` 自由保存来源地图、候选题与驳斥、题目定稿、参考答案草稿、质量审阅及续作说明。逐题确认问法真实、应答空间足够、并不依赖专业知识或虚构统计；检查 Part 2 是否可讲个人经历，Part 3 是否较之 Part 2 更抽象；写作题是否要求清楚且容纳不同立场。正式题目为原创，不能复制官方样题全文。生成的每道题至少有一个自然关联的来源章节；关联到 `USE` 时使用复合身份 `章节ID#USE编码`，仅作读书器导航，不当作答题硬指标。无真实关联的强制命中应删除。

每题给出默认隐藏的约 7.5 水平教学示范、立意与替代路线。示范不是唯一正确答案，也没有官方认证的分数。提交前可主动揭示，但记录已提前查看，后续反馈据此说明练习条件。口语示范需保持自然口语长度和语体，不把写作范文改行充当口语；写作示范完整回应题目并容许另一合理立场。展示层不以 CSS 隐藏答案，未揭示前后端不向浏览器发送参考文本。

## 作答、批改与保真

个人作答与批改在独立 `PRACTICE_DB` 中，不提交公开仓库。每次文字提交形成不可变 attempt，绑定题目版本；重答生成新 attempt。后端待批改队列通过发布令牌供 Codex 领取，领取与完成有幂等身份。Codex 先独立阅读题目和答卷，再使用参考答案作为启发而非逐字比对标准；按官方四维标准分析，指出已有优势、最重要的改进点和可操作的重答建议，不因没用课程词汇扣分，也不把练习估计说成正式雅思评分。提交后可从 PWA 查看反馈与先前尝试。

口语提交未来以原始录音为权威；转写、词级时间、声学分析分别记录提供商、模型版本与质量状态。语音识别的文字不能证明发音、节奏或真实停顿；没有原声分析时只反馈内容、词汇和语法，不给完整口语分数。Azure 自由表达发音评估可作为首个实测候选，但其分数不能直接换算 IELTS band。录音应进入独立私有对象存储，库内仅存受控定位、摘要和授权状态；在对象存储和 iPhone 录制链路可用前，PWA 不展示伪录音提交。

## 索引与版本

长期索引支持练习册、焦点章、任一来源章、题型、题目、复合 `USE` 身份、申请状态、作答状态与反馈状态。题目版本、参考答案版本、来源 digest 与 attempt 绑定；不能拿后来修订的答案默默重评旧尝试。Codex 读取接口和未来 Chat/MCP 只经后端授权，提供必要范围的题目、索引、个人答案和反馈，不直接暴露 D1 或存储密钥。Chat 手动对话不承担唯一可靠的异步批改队列。
