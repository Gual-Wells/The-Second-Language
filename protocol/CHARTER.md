## 1. 产品身份与当前基准

- USER-DECISION：欧洲中古风格、英文书写、陈旧古朴的羊皮纪念卷轴。它是章节测试激励下的私人纪念艺术品，题辞、书写、纸膜和器物体验共同承载纪念价值；保持庄重，不虚构王权、宗教、学历、公证或外部机构权威。
- 受誉者为**Gual Wells**；稳定主体键为`second-language-owner`，公开显示入口`web/owner-identity.js`。不推断证件姓名，不因改名重置账户、Passkey、答卷或学习进度。
- 闭合横卷与展开页正面朝向，保留体积、卷边和轻微非均匀卷曲。可反复开合、细看、释读与单独展示器物；不以含背景的整张AI图冒充可交互卷轴。
- 古旧不等于霉变、全页脏污、整圈烧焦、四边等量破损或现代圆润裁边。不要火漆。木轴不是中古正式文书统一必备结构；当前基座不新增木轴，新系列可在实物研究后另行设计。
- 第一章v12长方藏记和文书已获用户肯定，第五章作品方向曾获初步肯定；真实皮扣结构/审美已有明确接受。2026-10-20用户在v20雾染交付后说“可以了”，该版雾染成为当前共用基准；不追认所有旧版或未来每章设计。
- 正式测试仍为`testing:true, certification:false, coin:false`。现有卷轴均为`specimen`，无真实首次通过事件，不启用颁发，不恢复纪念币、展厅或罐子。

## 2. 自动化分工与模型

| 层面 | 稳定复用 | 按章创作 |
| --- | --- | --- |
| 系列工艺基座 | 纸膜/卷绕、扣具/动作、字体集、印模、做旧配方、光照/雾染、许可与兼容范围 | 基座升级另做样品验证，不在每章重造机构或重跑Kaggle |
| 章节艺术作品 | 项目身份、真实来源、系列语言及记录规则 | 主意象、文学形式、完整英中、图像、整页排印、留白和有依据的纸张/墨迹细节 |
| 交互展示 | 已封存纸面、模型、贴图、参数及运行器版本 | 仅按时间/手势播放；开卷不请求模型、不重抽布局、不改日期或身份 |

自动化应串起研究、创作、制材、排印、审阅和封存，不能退化成固定槽位换字。母材可以复用；章与章在意象及表达关系上有实质区别。无需机械新增图种、纹样数量或模型，也不能用镜像、换色、随机噪声替代设计。

USER-DECISION：语义提炼、文书创作、图像指导和成品艺术审阅使用`gpt-6.1-sol`、`model_reasoning_effort="xhigh"`。本草案将修订纳入同等质量，并建议独立新上下文审阅；后者是执行方案，不冒称用户指定了某个worker机制。卷轴有专用配置，不能直接继承现有答疑worker的`gpt-6-sol/high`或静默降档。

生图工具的型号/质量独立于Codex推理档位。分别记录requested和实际可观察的observed配置；未暴露参数写未核实。`artPlan.models.creativePolicy`是政策声明，不是执行证明。不可用则保留进度并告知，不自动购买或切付费平台。

对话内生图经验不证明后台无交互桥接已可用。接线前核所选工具的提交、取回、结果ID、错误及计费语义，不预设对话工具等同某个独立API；只生成确需的新资产，成功原件永久复用。

每章不必复制共用引擎、字库和母版；可按内容摘要共享，但清单须覆盖依赖闭包，目录名或latest不足以恢复原件。

## 5. 制作工艺

### 5.1 题辞、意象与排印

1. 从完整章节提炼具体物象、词义关系或动作，留可回查的词/义/句位置；不只看标题，不限定第三部分。第一章墨线/真实水域与第五章气息/手迹/种子是有效实例，不是所有章节的模板。
2. 写能独立阅读的原创题辞；短诗、散文、铭辞均可。避免复述教学剧情、堆目标词、学习建议、空泛格言、伪古拼写、硬押韵或虚构用户品德。章内文学质量不成为艺术品的上限。
3. 内容与版式共同决定：可变图文比例、对称/偏置、分区、首字、边饰、分行、字级与归属位置。不固化第一章左饰右文或第五章横画双节。
4. 图像工具只制图像/材质，不生成正文、印文、日期、哈希和姓名。实际文字由已加载字库排印，默认复用Aboensis；缺字/加载失败停止该版成品制作并保留释读，不无声回退现代系统字。
5. 用真实字形检查边界、图文相交、坏分行及身份安全区。失败重构图，不无限缩字、压扁字形、删真实信息或靠高光遮掩。完整英文/译文包括题头、题辞、归属、印文和状态。
6. 释读与器物文字同源；正式章名与艺术副题分开。Gual Wells保持个人联系，不机械占全页最大字级；不退回三段机构授予说明书。

### 5.2 羊皮纸与墨迹

工序：母材/图稿选择 → 该张纸轮廓、厚薄和主要折痕 → 接触/手持/折谷与边缘年龄痕迹 → 微表面法线/粗糙度 → 字迹/印迹 → 实际光照下保真。

- 以手工裁切、少量不直/斜切/短裂口及不均匀磨损形成轮廓。旧水痕、色差、折谷积尘有分布关系，不用均匀污斑、霉点或一圈焦边充数。
- 年龄色斑主要在基色，微粒产生克制凹凸，明显折痕才进几何。大色斑不能全部变浮雕，艺术图不冒称历史实物/PBR扫描。
- 母材像素、排字画布与屏幕分辨率分别记录。第五章母图1060×1484、排字2048×2868，放大画布不增加原生材质细节。
- 正视时清楚保留做旧、污损、微纹理和墨迹；控制高光、再调色及重复受光。沿用v6保真经验，不以全局提亮证明高清，不把艺术性着色称作完整物理标定。
- 可以同一母材形成独立变体，无须每章生图；主要裁边、折痕、磨耗和色泽须共同成立，单纯镜像/换色不足。前后、透明alpha及UV一致。

### 5.3 项目藏记与印迹

当前系列默认复用v12小长方藏记：`The Second Language / In remembrance`。保持它与纸面、手稿字及归属尾记的协调，不每章随机换机构印，不恢复大正方Attested印或现代开卷图标。

印模、吃墨及受压分别制作：稳定母版小伤/划痕 → 不均匀沾墨/局部缺墨 → 越出印模线条的肩墨/浸晕 → 深褐近黑墨色与纸纹相融 → 克制的独立压痕/高度。不是浅色细线贴纸、整体高斯模糊或光滑液滴。印模身份稳定，该张落印细节按冻结种子变化。

这是参考历史书写/收藏印记的当代项目设计，不声称欧洲中古统一用此式，不仿冒真实公证人标记或用户亲笔签名。圆印保留作历史候选，不自动替换默认系列。

### 5.4 皮扣机构、解扣与适配

复用已接受实体，不每章整图AI重建。正确结构：有两个端部的连续带坯、固定折返包边/铆孔、独立框和完整针轴。**活动带从右框杆后方穿入，左侧前方伸出并遮住包边；扣针左段被带遮住，右端穿孔后搭在右框杆。**实体边界明确，不嵌入粘连或吞带尾。

原生工程有骨骼/材料坐标，网页实际用材料路径和数据纹理变形皮革，金属刚性；GLB骨骼数不代表网页播放方式。动作依次松孔、越针、退带、归置、移离、开纸，收起同一路径反向。纸从当前进度0.40后展开；这是v17基座数值，不是所有未来机构的常数。

适配用原生环周长派生物与整件等比缩放。现有v17为30mm环半径、18mm带宽、2.5mm厚度；禁恢复被否决的1.8倍单轴拉伸。不能用闭死环加前扣装饰、透明淡出、轴向滑脱或虚化放大拼贴冒充真实解扣。当前是编排可逆动作，不是皮革FEM或任意力学模拟。

### 5.5 皮革与铜件做旧

复用v19原生节点工艺、已有艺术基色和许可扫描微表面：

- 皮革：基底粒面/旧裂 → 手持暗润、穿带压磨 → 长边/带尾不连续磨穿 → 局部屈折压褶 → 克制手工刻带 → 粒面/切面/孔壁分别取样。
- 铜件：旧铜/扫描微坑 → 修锉、压平痕 → 简单刻槽 → 接触/遮蔽处稳定氧化 → 凸部和常触区磨亮。
- 颜色、法线、粗糙度和金属度联合烘焙；仅微表面高度不改机构。避免迷彩大黑斑、全物同粗糙度、皮革金属不分、完美新件或霉变。
- Blend、PNG母版及发布WebP分别保存；核真实文件头、色彩空间和解码差异，不只改扩展名。当前六WebP逐像素无损核对、共约12.75MiB，不是零下载成本。
- 网页读烘焙图，不逐章增加实时随机噪声层；保留v19材料长度UV、切面区分及释放被替换GPU纹理的处理。

### 5.6 雾染、光照与运行维护

共用v20：Pavel压力/平流核心，宽域漂移、独立狭长流区、局部细卷动、交错聚散源及纸缘/皮扣真实速度的有限带动。没有固定单向入口，不全场铺小漩涡，不靠喷嘴式脉冲制造互动；浓度变化和流速变化分开。

保留正确皮扣投影、有限值、屏外、进度跳变及闭纸重合边保护。雾染30Hz保留余量、最多追赶三步，当前速度网格96/染料512；纸面按屏幕刷新。不为雾染降低纸面清晰度或以关雾修复。仍为二维画面近似，不冒称三维湿度凝结、体积遮挡或完整流固耦合。

环境/模型/最终材质就绪 → 纹理上传/程序编译 → 隐藏实绘主要姿态 → 开交互。首次动作不临时编译新材质；减少动态模式保留可读状态。隐藏暂停并排除后台时长；中途反向、拖动取消、上下文丢失后的静态/释读回退及恢复重预热均保留。

## 6. 变化与重验范围

| 改动 | 必须重看/重验 | 可复用证据 |
| --- | --- | --- |
| 题辞/图像/排印 | 英中、章节联系、整页、字形边界、细看和卷后清晰 | 同基座扣具接触，不重跑无关几何 |
| 纸基色/墨迹/微表面 | 实际光照与保真、透明边、细看/开合 | 未移顶点的机构证据 |
| 纸幅/厚度/主要折痕/裁形 | 卷绕连续、UV/阴影、字区、扣具比例与穿插/遮挡 | 不能直接借旧纸膜结论 |
| 框/针/孔、带宽厚度、环径/材料路径 | 实际动作与关键接触、刚性比例、脱针/退带/套回 | 旧动作需重新判断兼容 |
| 雾染/运行器/纹理编码 | 静置/开合/反向、区域运动、首载/性能、隐藏恢复和降级 | 不涉及的语义/几何可保留 |

接触核对针对真实渲染几何和动作。v17检查纸膜为手工对应GLSL，改变形时同步检查表达；历史66个离散姿态不是连续空间、自碰撞、制造公差或艺术质量证明。

艺术审阅看作品是否值得收藏，不按通过检查项数评分。脚本只证明所测身份、边界、依赖、动作及恢复。最终目标为iPhone 17标准版；402×874/DPR3本机Chromium只是代理证据，不冒充物理Safari验收。

## 7. 首次通过、任务与恢复（正式接入前实现）

1. 服务器依据已存完整试卷、不可改答卷及最终口答核定结果确认全部正确；客户端assertCharter不是认证权威，识别疑义按CHAPTER_TESTS处理。
2. 事务及`(recipientId, chapterId)`唯一约束记录首次事件，另绑定chapterDigest、attemptId、assessmentVersion、paper/result摘要及姓名快照。后续独立随机重测不限次，不重复身份，不因章节修订绕过同章唯一性。
3. passedAt取首次服务器核定完成时刻，不取申请/提交、章节发布、领取或渲染时间。制作与资格分开，失败不撤销通过、不要求重考。
4. 拟议任务最少保存requestId/stage/status/sourceDigest/eventId/claim/lease/outputDigests；沿用pending/running/attention/failed/complete，阶段见第4节。领取、心跳及完成条件更新，失效执行器不能覆盖新结果。
5. 输出按摘要落盘后再推进，重启从最近有效原件继续。同requestId同内容复用，异内容冲突；同一正式eventId绑定唯一制作任务/作品身份，不同requestId或自动触发/申领并发也复用该任务。外部阶段按eventId、stage及固定输入摘要原子领取，修订按顺序产生新候选，不并行重复付费；样品用独立specimenId隔离。
6. 外部生成先查成功原件及provider结果ID，再提交一次；调用前保存calling及可得结果引用。超时/断网且未知是否计费转outcome_unknown/attention，即使租约到期也不自动再发；不能换requestId或微改提示词绕过未解决调用。先找原件，必要重试按原保护规则取得授权。
7. 独立审阅读取真实来源、最终英中、整页/细看与必要动态，不只看创作者自评。review绑定确切候选内容及资产清单；审后任何影响成品的内容、资源或profile改变均使原通过不再适用于新候选，按变化范围复审。美术问题回对应阶段；超配置时间/费用或缺工具，保存可恢复工作并告知，不无限循环。

可复用`worker/src/chapter-tests.js`、`scripts/question-worker.mjs`的领取/续约思路及`worker/src/pronunciation.js`未知结果保护。它们不是现成卷轴服务；不能照搬旧模型配置或把实验认证表直接升格。

## 8. 时间、摘要与永久原件

### 身份和时间

记录RFC3339毫秒时间，摘要前归一UTC，默认Asia/Shanghai显示英文日期与`HH:mm:ss.SSS +08:00`。毫秒是记录分辨率，不夸大时钟准确度，也不声称现代时间/哈希是中古惯例；拟议正式规则统一使用首次通过事件固定的姓名快照，制作、颁发和重开不再读取当前显示名。

样品用proof.sampleTime、attestation=null，保留`Specimen — Not issued`，时间不随打开刷新。删字样或切客户端分支不能成为正式作品。不恢复顺序发行编号，不把随机码冒称哈希；短码为内容SHA-256前16位、四位一组，完整64位/事件/原文可核对。短码不作唯一数据库键、签名或鉴权。

### 两种摘要分开

- 内容摘要：v12为`second-language.memento.v2`，v13/v14及后继纸面为memento.v3，由版本化UTF-8 JSON位置数组计算，绑定正文、身份、状态、时间和艺术方案等；不是通用RFC8785/JCS实现。旧格式/原件保持，字段或编码变化升版本，不改旧摘要。
- 整包摘要（拟议）：候选清单绑定内容摘要、方案、实际图像/字体/纸面层、GLB、贴图、动作/运行器/shader、许可、种子及母版引用的字节SHA，但不含review。review引用该候选清单摘要，最终包清单再收录候选清单及review摘要；各清单自身摘要外置。已印短码的PNG不参与其自身内容摘要，避免自引用或审阅与包互相循环。

v17–v20保留v14纸面摘要，不证明该摘要覆盖后来的材质/雾染。清单须锁全依赖，不能只存纸面hash或计划里声明的资源hash。构建封存时验实际字节，运行时按固定清单加载，不必每次开卷全量下载再hash。

保存验收过的最终纸面/贴图，不要求不同GPU、字库光栅化或浏览器重算出同字节PNG。参数/种子用于解释恢复，精确原件优先读取；雾与手势按已定义参数随时间变化，不等于重新生成纸张、印迹或身份。

### 存储与恢复

- 沿用STORAGE：OneDrive文件基座，D1只留紧凑任务/资格/作品指针；大图、GLB、Blend、文本、许可与清单内容寻址共享。先上传/回读核完整包，再原子发布ready指针。现有单对象24MiB；大母版可复用离线归档分块/恢复清单。在线展示资产保持单对象限制或拆为可独立加载资源；现无通用multipart/浏览器重组接口，确需大对象重组须另补。不能塞D1或临时KV。
- permanentBucket.putContent/getContent及存储API可复用，但不是不可删除WORM。公开预览与正式私有原件分开；领取路由核身份和章节权限，不暴露云盘token或把publisher写接口交前端。
- 母版含Blend、扫描源、PNG、依赖纹理、工艺脚本/参数、版本/许可；网页可展示不等于原生工艺已归档。普通归档不自动覆盖全部research/scroll-*、.cache/keeper-*及未来work/scroll，须显式接入并回读。
- 新任务/缓存/依赖/输出真实存D盘；记录工具真实路径、版本和恢复方式，不以本机恰有maintenance依赖冒充仓库自包含。封存版本不自动跟随资产库latest更新。
- 未颁发候选按版本修订；已颁发艺术/原件不被新模板覆盖。兼容/安全修复可发布新呈现器并保留原manifest/文件，不借修复改字、时间或通过事件。
