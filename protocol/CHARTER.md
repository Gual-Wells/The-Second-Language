# 第二语言章节认证卷轴

## 权威、范围和当前状态

2026-10-17。本协议是章节认证卷轴的正文、章印、排版、身份与资产制作规范。由中世纪文书/印模研究结合本项目实际学习语义形成，不能将其写成严格历史复原。用户要求的英文、古朴正式、无火漆、无霉变、正面展示、原项目图标、刚性金属扣及可控松环动作、视觉保真继续有效。

**当前仅有第一章独立试样 `/labs/chapter-scroll-v8/`。正式章节测试仍按 CHAPTER_TESTS：testing=true、certification=false。**本协议不启用正式认证，不将实验满分或样品导出写为真实认证，也不恢复纪念币/展厅。章印定稿仍需用户视觉验收；协议已供当前与后续工程执行，不能用自动检查代替美术通过。

## 一、文书所证明的事实

未来正式认证依用户既定规则：每次独立随机，不限次重测；第一次满足正式认证条件的通过事件产生本章唯一永久认证，之后仍可测，不重新发证。制作失败不撤销通过，不要求重考。

认证只能陈述：**某一固定版本章节、某份被保存的理解测验、该次回答全部核定正确、首次达成的时间**。不得声称全部义项已永远掌握、所有情境均可主动运用、获得学位/官方资质、达到IELTS band，或因为一次答对便证明长期记忆。识别疑义按CHAPTER_TESTS先核实，不将未决口答当成已通过。

图形印记表示本项目文书的发行身份；它不是电子签名、持有者鉴权凭据或反伪造系统。未来权威是服务端不可变通过记录及其章节/测验关联，不以浏览器字段、SVG图案或可下载图片代替。这里不为艺术印记另建PKI或外部认证服务。

## 二、输入、版本与保存

### 内容输入

- `chapterId / chapterNumber / chapterDigest / displayTitle`：已发布固定版本。第一章核对 `chapters/2026-10-02/chapter.json`；不能只用标题猜测内容。
- `themeParagraph`：由Codex阅读原章后写出的英文纪念短文，核对语义依据。它不由关键词拼接脚本或随机格言产生。
- `status`：仅 `specimen` 或 `issued`。未颁发时 `attestation:null`，正文和释读都明确未颁发，不能填当前时间、随机真号或虚构得分伪装完成。
- 未来 `issued` 必需 `attestation.id / attemptId / assessmentVersion / allCorrect:true / passedAt / publicCode`，并由真实服务端通过事件提供。客户端呈现校验不是服务端鉴权。

### 身份与日期

- 不用顺序发行编号。短公开识别码为不可变的16位大写十六进制值，按四组显示，如测试中的 `A1B2 C3D4 E5F6 7890`。生成时使用安全随机、权威存储检查唯一；展示和再次导出不重新取随机。它不是章节摘要，也不冒称图形/内容的密码学哈希。
- `passedAt`记录首次通过事件真实时间，RFC3339含毫秒和时区；UTC保存优先。不得使用章节发布日期、素材生成时间、打开或领取时间替代。
- 画面按`Asia/Shanghai`显示`YYYY-MM-DD  HH:mm:ss.SSS  +08:00`，同时保留原时间。毫秒是记录精度，不保证设备或服务器时钟具有毫秒级测量准确性。
- 正文、章印主版、字体、材质、排版版本、资产摘要和生成结果一并固定。以后升级模板不静默改写已有颁发原件；重导出优先返回原件。
- 完整文本/PNG/SVG/资产清单和权威记录快照按STORAGE存永久文件基座；D1只需紧凑身份、状态和索引，不存逐帧顶点或反复复制位图。当前试样仅静态仓库材料。

## 三、正文创作

### 研究所得的可用结构

历史文书可区分发行者、告知、事由/处分、印证、日期等功能段。采用这种职责清楚的结构，**不照搬赠地、宗教或王权的法律主张**。文书正文仍为英文；可读的庄重英语优先，不伪造中古英语、拉丁文和历史拼写。

本项目固定骨架：

1. **发行者**：`The Second Language`。
2. **告知句**：主版使用`Be it remembered`；不能把它当成所有年代通用的唯一公式。
3. **章名**：真实章序与原英文题名，题名不能为了排版擅改；长题名先换行，确需另拟短题须保存正式映射并审核。
4. **本章纪念段**：约25—40个英文词，选择一至两个真实主题或用法关系，形成一个明确意思。不是罗列全部词、缩写全篇故事、AI赞颂或重复章名。可从词义本身取象，不必总由第三部分叙事代表全章。
5. **认证事实句**：正式版明确“该份已保存测试全部答对”，并限定为这份测试；试样使用未颁发文案，不调用正式版通过时态。
6. **纪念/寄语句**：一小句指向理解与实际使用，避免夸大、空泛誓言和自我神圣化。标准寄语可以全系列复用；纪念段应有本章根据。
7. **印证区**：项目署名、同版章印；正式版使用`In witness of this record`，试样使用`In the form of attestation`。
8. **真实身份与日期**：由不可变事件字段排字，不让生图模型生成数字或文字。

### 当前可用正式陈述

> The learner answered every question correctly in the assessment preserved with this record. This first attestation concerns that assessment alone.

此陈述仅在真实正式事件存在时使用。它没有声称测试具有全量知识覆盖，也没有把永久保存的认证误写为永久记忆。

### 内容审阅与失败处理

- Codex先看原章及语义关系，再写纪念段；维护材料保留原句/用法的依据位置，过程提示词、来源路径、内部编码不印入正文。
- 检查事实、语言、适用范围、主题象征及全文朗读节奏。禁止伪造学者、授予机构、旁证人名、签名或冠冕头衔。
- 约65—85词的正文是当前版面预算，不是为了凑字数的硬性语义指标。长题名、长词或字形造成溢出时，修改纪念段和句式后人工复核；不删认证事实，不缩字到不可读，不拉窄字形或压扁整个文字层。
- 语义或身份不明就保存草稿，报告具体缺口；不把未颁发数据静默降为假正式证书。

- 印文为`The Second Language`及`Attestation`；与正文同用已加载的Aboensis。不得在机构名、章序、页脚或印文悄悄换入现代字体/另一套Uncial。字体失败应停止制作，不以系统默认字体继续输出正式原件。
- 墨色以纸上正文棕黑色系为基础，印压转移稍浅，有细微而固定的压力不均；不加不透明圆盘底、不用发光、高亮塑料边或明显现代橡胶章轮廓。

## 六、皮环、刚性扣件与卷展

第七版“整张贴片抬离后平移”的方向已被用户明确否决：它没有解决皮环前后空间与上下遮挡。本节取代原路径规范。

- 以原有已获认可的皮革/铜扣资产供材质；按语义拆分皮环、暴露皮革、刚性金属扣件。图源原有的假后环像素不直接盖在卷轴前面，后环有真实深度。
- 用Three原生`BufferGeometry.morphAttributes.position`定义收紧/略松两个端点姿态，按控制进度插值。只让皮革和环径改变，金属扣面尺寸保持；不用弹簧惯性、随机摆动或果冻变形。这里表现松环，并未声称解舌扣机械全过程。
- 相机正面朝向保留，使用真实PerspectiveCamera，距离12，FOV随视口维持原页面近似几何。前后缩放来自透视投影，不能用把上半贴片压在后面/下半贴片提到前面来代替空间关系。
- 皮环轴线与纸卷轴线保持一致。收紧内壁半径为完整闭卷半径+0.058−0.009；略松为+0.13−0.009。松环的中心深度只前移0.045，留出包络余量；沿卷轴轴向退出期间不侧倾，不让后环穿过纸身。
- 总进度0..0.24为皮环阶段，r=p/0.24：r0..0.27松环、0.27..0.82沿轴向滑至左端以外、0.82..1离场。先完全离开纸端再前移/转角，r0.89后淡出；反向严格同轨迹。
- 皮环阶段纸张保持闭卷，之后才按v6连续函数展开。所有皮环部件启用深度测试与合理深度写入，由纸张正确遮挡后环，不强制高renderOrder把整环压在纸前。
- 小尺寸艺术资产仍是有UV参考的局部2.5D/三维混合道具，不宣称全360°写实模型或物理求解。艺术验收看实际连续帧，而非只看路径坐标。
