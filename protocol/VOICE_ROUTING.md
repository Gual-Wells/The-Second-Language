# 第二语言声音选择与分配

用户于 2026-10-04 确定本协议，并补充所有非听力场景使用 Bella。可执行清单为 `voices.mjs`，版本 `kokoro-owner-20261004-v2`。Kokoro 男声调音实验由用户全部判不合格，不提取新反馈，不继续采用这些处理参数。已有试听页保留作历史对比，不因此删除。

## 主力

所有合成使用 `hexgrad/kokoro-82m`。不为听感边际收益自动切换其他供应商模型。口语原声回答分析的 Whisper/Gemini/Qwen/GPT Audio 链路继续承担分析，不是这里的朗读模型选择。

- 非听力：词汇、派生词、短语、例句、文章点句/未来全文朗读、口语考官提问与任何其他朗读均固定 `af_bella`。
- 听力女声：Alloy / Aoede / Bella / Heart / Jessica / Kore / Nova / Sarah / Sky，分别是 `af_alloy,af_aoede,af_bella,af_heart,af_jessica,af_kore,af_nova,af_sarah,af_sky`。
- 听力男声：Eric / Michael / Liam / Puck / Fenrir，分别是 `am_eric,am_michael,am_liam,am_puck,am_fenrir`。

男性标准按用户最新决定接受“正常且不刺耳”，不能拿前次词汇淘汰名单覆盖本次明确授权。排除 Adam / Echo / Onyx / Santa，女声排除 Nicole / River；旧试听评价只作历史记录。正常原始语速与原音色，不施加已否决的 EQ、降噪、升调和变速实验。

## 听力的有约束随机

先按雅思情境定稿四段脚本、人物、性别与连续性，再为每个实际人物建立全卷稳定 `speakerId`。不同人物不能因为显示名相同而视为同一人；同一人跨段再次出现仍使用同一个 ID。每个片段含 `purpose:listening,speakerId,gender`，由 `sceneId` 或最终组装段 ID 表示同场关系。

`practice-audio.mjs cast` 对完整计划一次分配并将 `voiceAllocation` 写回原计划；`synthesize` 在付费调用前也先执行该步骤。按照人物全部台词字符量估计讲话量，长角色优先，在同一性别池内优先选择已分配台词量较少的音色，再以 setId 为随机种子打破并列。同场不同人音色必须不同；跨场不同人可复用。所有人物绑定一次固定，续作读取冻结结果，不重随机。后台也将 setId/speakerId/gender/voice 原子固定，拒绝同一人物改声。

均衡的是整份材料可分配的人物与台词量，不是每句话轮换。单人讲述不得中途换声；不能拆成多个虚假人物为了平均。人物数量少于音色数量时无须把全部音色塞进一份试卷。长讲述自然会占较大份额，只能在其他独立人物之间改善分布。男女出现比例、对话人数、交流顺序与四段情境由题目标准决定，不按 9:5 池大小改变，不强制男女交替，不擅自把同性交谈改成异性角色。

不同 setId 重新随机分配；同份计划不变。更换已冻结声音或脚本需要新版本与新资产编号，不覆盖旧练习册及旧尝试。声音来源、角色、脚本文本和版本写入持久语音身份；字幕 speaker 来自稳定人物 ID/显示名，而非推断音色性别。

## Bella 点读

PWA 点读范围按 READER_INTERACTION.md 固定：第一部分已登记词汇标题对应音标；第二部分标题复用第一部分读音、例句整句；第三部分整句。标题旁“点读”为规则说明入口，不切换任意点词模式。高光句保留用法跳转优先级，释义、杂文、译文及原有控件不申请声音。第一部分不同义项读音按各自音标，不能以同拼写冒充同读音。口语 Part 1/3 提问按原协议持久生成 Bella 音频，Part 2 卡片保持可见，参考答案仍为默认隐藏文本。

`POST /api/practice/pronunciation {text,kind:word|sentence}` 按模型、Bella、纯英文文本和策略版本计算摘要，原子领取。成功 MP3、完整请求/返回保存在 OneDrive；PRACTICE_DB 的 `pronunciation_results` 保存不可变紧凑摘要索引，章节关联使用 `chapter_audio_scopes/chapter_audio_clips`。重复点击复用声音；客户端最多保留三十段已解码声音，已有章节音频包按 STORAGE.md 的开关预下载。`GET /api/practice/pronunciation/<摘要>` 取状态，`.../audio` 私有读取并支持 Range。短词/句音频最多 1 MiB；`pronunciation_audio` 仅承载在途请求与永久归档失败时的保留副本，补归档不调用 TTS。永久原件暂时不可用返回明确状态，不能将其当作未生成重新收费；不写章节 KV、不要求 R2。

OpenRouter 请求只由 Cloudflare 发出，浏览器不拿密钥。只读 Chat 凭据不能申请收费生成。生成结果未知保留状态、不自动重付；等待余额时保存进度，到仅在用户充值后明确要求继续时处理，不自动跨日重试。已经缓存的声音不依赖充值仍可播放。失败不静默换回系统机械音或其他模型，给出可理解状态。初次生成需要联网，文字课程及阅读位置不受影响。

切章、切部分、打开练习、离开页面、退出账号时停止播放；退出时清理解码缓存。不自动播放，不缓存私有 API 到 Service Worker。默认仍按需生成；用户可按 AUDIO_CONFIGURATION.md 一次性选配章节三类点读音频。指定标题读音使用经实际路线对照验证的 Kokoro 音素覆盖；不支持的读音需核对，不静默按拼写覆盖。生成请求被取消播放时已发出的服务器工作可完成并缓存，下次复用。所有效果改善仍以用户实听为依据，不把 TTS 输出当严格 IPA 发音校验。
