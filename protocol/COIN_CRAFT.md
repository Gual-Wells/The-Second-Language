# 精品纪念币制作与把玩协议

版本1.0 · 2026-10-10。状态：制作标准，仇视之龙尚未建模、渲染或获采用。研究依据见 `../research/dragon-coin-production-standard-2026-10-10.md`。

## 1. 目标与权威边界

USER-DECISION：取消动态展厅及图书馆纪念日历展柜，集中制作单枚完整精品纪念币。认证章节有入口，将币调到页面中央直接把玩；无场景背景、无遮罩、无模态隔离，币以外页面正常操作。旧页、资产及反馈保留。此前全部样品均未达到用户要求的高标准，不作为艺术基准。

认证规则仍按 `CERTIFICATION_RESEARCH.md`：独立随机、不限次重测，首次通过唯一永久认证及币身份，认证后仍可测。正式通路尚未启用；仇视之龙为独立样币，不伪造它属于现有某章，不写正式认证。此次仅研究与制定标准，不修改正式读后记录或产品。

标准以完成作品的造型、工艺、听感和手指体验验收。脚本、面数、贴图尺寸、PBR、特效数量不能替代艺术质量，任何综合平均分都不能抵消核心造型失败。用户最终采用决定优先。不把自定预算称作行业标准，不因使用专业工具声称达到收藏品级、电影级或顶级游戏美术。

## 2. 完整币与造型层级

正面、背面、侧缘、厚度、浮雕、越界结构、断裂、材质和动效共同设计，服务同一主形和动作。币基座仍可读，不能只剩悬空头像、摆件底座或奖杯。圆盘上压扁现成雕像的方案已经失败，不再用作主体。

制作顺序：主形/轮廓/比例/姿态 → 次形/眼眶/颌/掌指/受力 → 鳞片/刻痕/微磨损。主形失败即停止追加细节、材质和特效。程序可辅助重复刻纹、对称、网格、烘焙与导出；龙头、表情、爪掌、抓握、断裂必须逐处定制造型，不以球体、管道、尖锥及未经改造的素材凑出成品。手工不等于逐个手写顶点；必须真实说明制作方式，不虚称已经手工雕刻。

穿越币缘的指爪有背面延续、接触与压痕。正侧背裂口一致；除刻意漂浮碎片，不出现无意缝隙、穿插、悬空掌指和粘贴接缝。允许部件分网格，视觉与受力须连续，不为拓扑整洁强行并成一网格。

纹理可承担微细刻痕；改变剪影、倒扣、厚度、接触阴影的头颌、重要鳞缘、角、爪、破口必须有真实几何。二维高度图不能冒充口腔、包到背面的指爪或完整可绕看的雕塑。

## 3. 仇视之龙的具体制作任务

用户指定不可丢失：龙头向右转，放大的左眼仇视观看者；主位置龙头；左上/右下爪抓币缘，可跨到背面；左上爪捏碎币缘，有漂浮碎片；爪旁黑色魔气；口中红光；眼部高亮暗红光。

以下为待打样的设计提案，不宣称用户已经批准最终比例、材质和构图：

| 区域 | 需要制作的关系 | 拒绝的表现 |
|---|---|---|
| 转头 | 先固定龙自身左右、近侧左眼和镜头；鼻吻/颌指向另一侧，头颈转势贯通 | 混淆屏幕左与解剖左；正侧脸完全看不到眼；通用对称头像 |
| 仇视眼神 | 眉嵴压低、眼眶倾斜、上眼睑遮挡、颧部紧张、瞳孔有指向；近眼通过构图/透视/局部比例变大 | 单纯放大眼球卖萌；无瞳孔红灯球；靠标题解释仇视 |
| 头颈 | 颅、眉颧、鼻吻、颌、角根、颈有体块和承接，低浮雕向高浮雕自然过渡 | 管子长嘴；任意插角和牙；独立龙像压扁贴币 |
| 两组爪 | 初案左上、右下各一只，斜向夹持；掌、指节、皮褶、爪尖、指腹压力完整，侧背能看出包绕 | 等长尖锥梳子；复制镜像；穿币无受力 |
| 左上破口 | 局部压陷/折曲→不均匀撕裂；裂纹有终止，断面有厚度；悬浮断片与缺失区域吻合 | 随机圆洞；等大碎片；亮点粒子代替碎裂 |
| 币缘 | 边刻连续，高点磨亮、凹槽古银，局部破损打断节奏；侧缘有工艺厚度 | 完美圆环叠加；厚饼；无设计的圆柱侧壁 |
| 背面 | 包绕指爪和受力压痕优先，其余克制的鳞脊/龙印，身份信息小而清楚 | 复制正面；平板；大字标牌代替雕塑 |
| 色材 | 初案古银/深色金属，局部磨亮；暗红聚焦眼与口，黑雾只靠近爪 | 全黑吞轮廓；全币自发光；统一粗糙度和噪声 |

初案归一化直径D：主体厚度探索0.04–0.07D，最高浮雕0.12–0.22D，默认屏幕占宽约60–70%。它们只用于试样；侧面看成奖杯/饼即改，不因达到数值而保留。暂不擅选完整中式/西式全龙模板，不增加双翼、全龙身或额外人物稀释眼与爪的动作。

## 4. 制作阶段与交付

### A. 构图和实体主形

准备正/侧/背及剖面关系草图，确定近眼、爪和破口位置。二维概念只能作为参考，不当模型完成。原作素材可研究工艺与结构，不把现成龙雕塑贴币作为主体。

建立可编辑主形；关闭纹理、发光、烟、粒子，用灰泥材质和固定柔光输出正面、左右45°、侧、背和慢速整周转台。先内部审查轮廓、眼神、夹持和币的整体性；失败继续雕塑。不能把漂亮概念图当成灰模验收。

### B. 次形和细雕

落实眼眶、颌、手指解剖，统一接触/裂口。鳞片随体块流向、区域大小和弯折变化，眼睑/嘴角/指关节使用适合弯折的细纹；不均匀噪声铺满。细分与雕塑层允许返回修改主形。

保留高模与源工程，再制作实时拓扑/UV/烘焙。检查烘焙射线、cage、切线、接缝，尤其眼睑、角、指间、破口和币缘。自动简化不能改变关键剪影/接触，不以导出成功当作烘焙成功。

### C. 材质和照明

分区域制作基色、金属/粗糙度、法线和必要遮蔽。高点、凹槽氧化、断面、爪、口内、角、牙、眼有材质区别；磨损沿实际夹持/凸起/摩擦位置，不用全局噪声刷旧。氧化/污迹与裸金属不能无差别强设相同金属度。

用显出斜面与浮雕的工作室反射条件评价，不需要可见展厅。内部环境参与反射，画布仍透明。物体转动时高光改变，不把高光烘死在基色。口腔有深度，眼有角膜/虹膜/瞳孔/眼睑层次；不能被AO烧黑或镜面冲白。

### D. 局部动态和声音

静态雕塑及材质通过后才加入低幅眼口红光、爪旁局部流向黑雾、缺口附近少量对应碎片。效果随币本体坐标变化并遵守遮挡，碎片保留缺口关系。不要用眼球跟踪镜头代替静态仇视表情。默认无无人操作的整体自动转动。

雾不盖指爪和断面，红光不变均匀霓虹，关效果仍是完整作品。减少动态状态保留造型。声音独立点播，表达威胁吐息/喉部紧张及夹碎金属，非故事朗读或通用提示音；拖动不连发音。原始录音有权复用/自制，分轨、配方和成品永久保存，试听无突然尖叫/削波。声音尚未制作。

### E. 运行资产与原页体验

主路线：Blender定制造型/细分雕塑/UV/烘焙/导出，现有Babylon.js9.30.0透明展示。编辑源、高模、运行网格分开。本机实际安装与雕塑/烘焙能力仍待验证，不因查到文档声称已经能产出精品。未获授权不新增订阅。

整币造型与材质先达到标准，再建设独立把玩测试页和正式认证通路。内部审查可自主反复修改，不给用户连续发送明显不合格的球管占位品。提供阶段成果须标明构图/灰模/材质打样/最终样币。

## 5. 透明显示与手势合同

无暗幕、毛玻璃、展台、背景平面或不可见全屏输入阻塞。原页几何、2008风格及未遮挡区域不变化；内部反射环境不是可见背景。单币默认支持竖屏，不强制横屏。

| 操作 | 语义 |
|---|---|
| 币实体开始单指拖动 | 虚拟轨迹球直接旋转币本体四元数，可翻背/倒置；照明和镜头是稳定参照，不继续绕相机冒充揉转 |
| 松手/再碰 | 有限惯性自然停止，再碰立即接住，不持续自动转 |
| 币实体开始双指 | 捏合缩放、扭动平面内转，范围能找回，有复位和收回入口 |
| 独立点播 | 播唯一绑定声音并复用原件，不把每次摸币解释为发声 |
| 币外开始 | 既有滚动、点读、双击/长按答疑、导航语义继续，不能暂停整页手势 |
| 收回/切章/离页 | 清理手势、声音、运行资源，不改变认证、阅读位置、草稿或资产 |

`touch-action`在手势开始前声明，仅用于币输入区；不能先整页阻止滚动再合成click冒充兼容。第二指从币外加入、同时币外滚动及透明孔隙点击必须真机验证；未通过不得悄悄扩大阻塞区。后台暂停、上下文丢失与返回可恢复；只加载当前币，复用成功资产和声音，不逐帧写后台或即时调用模型。

## 6. 验收与返工门槛

质量逐项放行；用户最终采用优先。默认手机尺寸审阅主形，放大审阅缺陷。程序不能判定仇视和精美程度。

| 关口 | 检查材料 | 必须返工 |
|---|---|---|
| 灰模 | 正、45°、侧、背、慢转，不靠标题 | 无眼神/转头/真实夹持/币形；侧背崩溃 |
| 主次层级 | 默认尺寸和放大 | 均匀鳞噪声；装饰夺走主眼；只有放大才认出主题 |
| 结构 | 侧光近看与剪影 | 锯齿、气球体块、粘贴缝、穿插、断面/碎片不匹配 |
| 金属 | 两套中性反射、多角度 | 铬塑料感；全黑/全白；统一粗糙度；固定画上去的亮斑 |
| 动效 | 开关对照、正侧背、浅色正文背景 | 烟光遮丑；无瞳孔红灯；矩形烟图；透明边白黑线 |
| 原页把玩 | 实体内外的所有原手势 | 币外不能滚动/点读/答疑；模型无法翻背/收回；残留阻塞 |
| 真机 | iPhone17 Safari/PWA连续把玩 | 持续降帧、发热、输入滞后或后台不停；模拟器不能替代 |

有意义的技术检查涵盖文件引用、法线/烘焙、身份复用、恢复、透明合成和输入边界；不制造自动艺术合格报告。

初始探索预算：单币约12–25万三角，区域2K/4K贴图，运行包约10–25MiB，正常把玩目标60fps；记录持续数分钟帧时间及体感。这些均未实测，不是高标准统一面数或硬上限。眼爪边缘可增预算；优先减隐藏面、过绘和重复纹理，不先砍用户关心的造型。压缩前后比较眼/鳞边/粗糙度/烟梯度。不能自动降成图案币掩盖无法兼顾画质和运行。

发布前保存无特效灰模、材质多角度、动效对照、原页透明图、真实手势录像和反馈；未制作不得写“已通过”。
