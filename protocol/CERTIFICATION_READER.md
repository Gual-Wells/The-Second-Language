# 认证阅览：纯享卷轴接入规范

修订：2026-10-21。本文件记录本轮用户选定的产品方向与实现要求，不代替发布、真机或声音听审证据。

## 1. 产品范围与真实身份

- 用户已否决藏馆方案。取消场馆、藏柜、观卷案、取卷／归藏转场、场景切换配乐及其入口；不把这些流程换名后带回纯享页。
- 唯一入口为**设置 → 认证阅览**。目录只列实际已有作品的章号，不从章节总表或测试成绩推导出占位作品。
- 当前仅有**第一章、第五章两个真实制作样品**：第一章采用v12文书／纸面，章来源为`2026-10-02`；第五章采用v14文书／纸面，章来源为`2026-10-12`。两者均为`issued:false`，没有真实首次通过事件，不冒充认证通过或正式颁发。
- 用户尚未考试，本轮不建设历史成绩回溯或补领。正式章节测试仍执行`CHAPTER_TESTS.md`；打开、开合、播放声音或返回不提交测试、不写成绩、不授予认证、不触发模型制作或收费任务。
- “认证阅览”是入口名称，不是两份样品已经获认证的证据。作品内原有样品身份、固定样品时间及记录保持真实，不改成当前时间或虚构通过时间。

## 2. 设置目录与纯享空间

1. 设置窗口新增“认证阅览”，沿用原生蓝银设置行及同窗前进／返回关系，不增加顶栏按钮。
2. 目录每项**只显示“第一章”“第五章”等章号**。不附章名、英文题名、日期、缩略图、藏位、分数、认证徽标、制作状态或宣传说明。没有作品的章不出现在列表，不增加锁定卡片。
3. 点章直接进入独立全屏纯享卷轴。展示覆盖可用视口并适配iPhone安全区，保留器物本身；不带网站标题、馆景、章节卡、说明栏、进度装饰、取放按钮或第二层展台。
4. 全屏指独立的视口占满体验，不强制依赖浏览器Fullscreen API；不改变正文纯净模式的几何与原手势规则。
5. 只保留可自隐的**返回、声音**控件。短暂显现后约三秒隐藏，触碰或键盘操作可恢复；声音面板使用期间保持可操作，不能在调整音量时突然隐藏。隐藏控件不可继续接收点击或焦点。
6. 返回直接回章号目录，再可回设置；不是“归藏”，不要求等待收卷或播放退出仪式。返回和声音控件的点击不得穿透成卷轴开合手势。
7. 载入、失败、重试与必要的静态回退只在对应状态出现，不成为常驻说明。关闭或改选后，晚到的加载结果不能重新打开旧作品或发声。

## 3. 器物、动作与雾染

- 每次进入默认**闭合**；轻触卷轴切换开合，纵向拖动控制展开／收起。支持中途反向；拖动、取消与按钮操作不能多触发一次轻触动作。
- 沿用已接受的连续纸膜与残余卷曲、v17真实皮扣机构及可逆解扣、v19皮革／铜件原做旧材质、v20雾染。第一／第五章各用自己的真实排印与纸面，不能把第一章文书覆盖第五章身份或反过来。
- 皮扣仍是有两个端部的连续皮带、独立框针及真实穿孔关系。保留松孔、越针、退带、移离后展开、反向扣回；不能恢复闭死圆环加装饰扣、单轴拉伸、透明淡出或拼贴放大。
- 保留纸张轮廓、折痕、污损、古旧色差、墨迹、低高光与清晰度。旧不等于霉变；不要重新做成现代光滑纸、过曝白纸或满页均匀脏斑。
- 雾染沿用区域流动、聚散与真实动作速度的有限耦合，仍是画面近似，不冒称完整三维流体。不能只在展开态稳定，不能靠关雾掩盖开合错误，也不恢复全场均匀小漩涡或喷气式脉冲。
- 先准备最终材质、上传与预热，再开放交互；首次解扣不临时编译新材质。前后台、反向、上下文丢失、恢复重预热与减少动态模式按实际运行器处理，保留可读静态回退。
- 馆景低精度代理、浅托和取卷姿态不得混入纯享页。可以为传输移除GLB内被替换的旧贴图，但必须保留机构、UV／材料坐标、形态与动作能力，并核对实际派生物。

## 4. 音乐与拟音

- 背景音乐只使用**A New Town (RPG Theme)**，作者The Cynic Project／`cynicmusic`，既有CC0完整录音。来源、字节摘要与拟音许可见`web/labs/certification-reader/AUDIO_CREDITS.md`及其资产清单。
- 取消馆内／近景／取归等音乐分段与切景；不为开合、选章、拖动切换乐曲或重启播放。该曲是当代创作素材，不冒称历史录音或中世纪考据结论。
- **音乐、拟音各有独立开关与音量。**初始均关闭，已保存偏好可沿用；调整一方不能隐式启用另一方。记住的是用户偏好，不能把系统暂停误写成用户关闭。
- 音乐保留当前播放位置；暂停或关闭音乐后再开启可续播。开卷、收卷与反向不重置位置，也不重建一份音乐资源。完整录音自然结束并保留尾音后再重播；不把当前处理宣传为无缝循环或自适应分轨音乐。
- 拟音复用既有Kenney真实录音，按皮带／针框接触、纸张位移及速度触发。不是所有动作铺同一种循环声，也不通过倒放声音冒充反向动作；已经取消或过时的异步拟音不应晚到补响。
- 需要声音时，在真实用户手势中解锁AudioContext；声音载入或解码失败不阻塞卷轴显示。视觉可用不代表声音已播放，解码成功也不代表音色、大小和艺术听审通过。
- **离开阅览停止，进入后台／锁屏暂停。**返回前台只能在阅览仍打开、偏好允许且浏览器许可时恢复；不能在设置、目录、正文或退出后被异步回调复活。暂停保留音乐位置，不留后台重播定时器。
- 学习点读、雅思听力及麦克风录制优先，不让纪念音乐接管全站学习音频。切入阅览前停止冲突的学习播放；返回后不擅自重播旧学习音频。

## 5. 后续作品与存储边界

- 新章依旧需要独立提炼意象、文书创作、图文排版及纸张／墨迹细节设计。可共享工艺、模型、动作和母材，不能镜像第一章、换标题、换色或随机噪声就冒充新艺术作品。
- 每份已采用作品读取固定正文、身份、样品或真实事件时间、纸面与资源；打开时不重生成、不随机重排、不刷新纪念时间。共同运行器升级与作品正文／原件变更分开处理。
- 当前阅览只接已有封存素材。未来正式通过、制作申领、独立艺术审阅、私有读取与永久归档仍需真实工程闭环；本轮不能因目录入口可用就宣告这些后台能力已上线。
- 继续沿用OneDrive永久文件基座、D1紧凑索引及既有未知计费保护。手机缓存只是副本，不成为唯一原件；不为纯享入口增加存储订阅或逐章复制共用音乐、扣具及引擎。
