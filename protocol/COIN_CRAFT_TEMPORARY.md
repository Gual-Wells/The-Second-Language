# 纪念币协同设计：临时约束协议

版本 1.1 · 2026-10-12 · 当前立即生效。

本文件是当前认证币研究阶段的**防漂移护栏**，不是制作教程、阶段清单或工具配方。

配套：
- `protocol/COIN_CRAFT.md`：长期质量基线。
- `research/certification-coin-design-system-2026-10-12.md`：完整研究母本。
- `research/certification-coin-temporary-protocol-v1.1-review-2026-10-12.md`：本版研究依据。
- `research/certification-coin-execution-state-2026-10-12.md`：当前作品事实与工具状态。

**解释优先级：**若 `COIN_CRAFT.md` 的“制作顺序/阶段”表述与本文件冲突，当前研究阶段按本文件理解为**质量依赖**而非僵硬时间顺序；长期文件的造型、材质、碎裂和验收质量要求仍有效。

## 1. 八条硬护栏

1. **设计质量优先。** 不因工具方便、沉没成本、已有低质量模型或协议形式牺牲作品。
2. **初始化非对称，迭代才双向。** 新艺术对象没有同谱系有效设计承载模型时，先形成完整视觉设计锚点，再建立第一份艺术3D。
3. **权威按事实分配。** AI图不是隐藏面/厚度真理，3D不是构图/审美真理。
4. **局部只是一种编辑范围。** 不允许脱离完整作品生成新的局部权威资产。
5. **关键来源可追溯、可回退。** 父版本、重要delta和Canonical不能靠聊天记忆维持。
6. **技术成功不等于艺术成功。** watertight、高面数、导出/仿真成功、漂亮PBR都不能替代设计。
7. **用户拥有最终审美权。** Codex先消化明显客观缺陷，只把高价值不确定性交给用户。
8. **不做协议表演。** 不固定步骤、候选数、Bridge通道或日志数量；只做真正改善结果的工作。

## 2. K / C / M：最小模型

### K / Design Kernel

K只保存真正需要跨迭代保护的事实：
- **K-fixed**：用户明确要求、已采用关键优点、系列硬要求、作品身份。
- **K-open**：仍在探索的假设和候选，不得伪装成硬约束。

若一项设计仍有真实分歧，就留在状态/候选，不塞进K-fixed。

### C / Concept State

完整视觉设计状态。擅长：
- 构图、气势、视觉重心；
- 主剪影、形面语言、负空间；
- 碎片视觉节奏；
- 材质审美意图与收藏品感。

C可以是完整AI稿、在原图上的非破坏编辑、paintover或其他完整视觉表示。

### M / Model State

必须区分：

**M-tech：技术脚手架**
- 空白币坯、标准圆片、相机/尺度框；
- 材质球、boolean/碎裂/导出测试件；
- 与作品无关的校准模型；
- 仅凭文字自由拼出的粗糙占位体。

M-tech只能验证技术，**没有作品审美权威**，默认不得作为下一轮AI设计的审美条件。

**M-design：设计承载模型**
通常来自：
- 当前/历史认可C的转译、生成或参考建模；
- 同谱系Canonical M；
- 真实扫描/实体模型等本身已经承载设计事实的来源。

M-design擅长：
- 厚度、隐藏面、正侧背连续；
- 掌指接触、空间遮挡；
- 真实断口、碎片来源和可绕看关系。

F（Finish）和A（Aura）可以单独研究，但不能取得C/M的设计权威。

## 3. 新艺术对象：Concept-first Bootstrap

没有有效M-design时，推荐关系：

**K + 项目资源/参考 → C-anchor → M0-design → C1 ↔ M1 ↔ …**

### C-anchor 的要求

C-anchor不是最终定稿，只需成熟到足以初始化3D：
- 完整作品上下文；
- 主体、主构图、主剪影、焦点；
- 关键动作和大尺度比例；
- 主要形面语言；
- 重要跨币缘关系；
- 足够明确的审美方向。

如果这些仍不清楚，先改善C；不要让Codex用简单球管/尖锥替代设计。

### 第一张AI图不自动成为C-anchor

新题材不确定性高时，可以先探索少量**完整作品级**Concept Set，再选择C-anchor。是否需要多方案按问题决定，不强制。

### 第一份M-design必须受C-anchor约束

可用image-to-3D、多视图/参考图建模、雕塑转译、受参考约束的blockout等方式。

禁止：
> 从文字规范自由手搓英雄模型 → 将其升级为M-design → 再让AI迁就它。

工具无法可靠转译时，应改善C、换成熟路线、参考引导建模或询问关键形体，而不是让低级模型抢先获得审美权威。

### Bootstrap按设计对象判断

“文件里已经有mesh”不等于所有新对象都已有M-design。
- 有币坯 ≠ 有龙头设计模型；
- 有统一背面 ≠ 有新正面主题模型；
- 有旧龙头 ≠ 新增角色/大改区域自动继承权威。

## 4. 有效M建立后：C/M双向协同

M-design建立以后，C/M才可以轮流领先。

目标不是 `Render(M)=C`，而是：
> **二者对K-fixed和已接受设计意图持续收敛，并互相纠正对方不擅长的部分。**

一般权威：
- 构图、气势、视觉重心：C优先；
- 厚度、隐藏面、真实接触：M优先；
- 主剪影、头向、眼神、关键比例：C/M共同；
- 碎片是否来自母体：M；
- 碎片节奏和整体负空间：C/M共同；
- 高光和环境反射：材质/渲染器；
- 用户明确认可的优点：高于任一自动表示。

当C/M冲突，先判断冲突属于什么事实，不默认“照图”或“以模型为准”。

### Authority Freshness

权威不是永久的。

如果K-fixed、主体身份或核心构图发生重大变化，旧M-design对受影响部分变为**stale**：
- 可继续提供尺度、技术和历史对比；
- 不再主导该部分审美；
- 必要时对该对象重新C-first bootstrap。

## 5. 局部修改：完整母体 + Collateral Drift

允许：
- 完整原图上的mask/inpaint/layer；
- 完整原模型上的sculpt mask、modifier、boolean、局部remesh；
- 局部放大、crop、剖面和内部ROI。

禁止：
- 单独生成“新爪/新眼/新碎片图”作为权威设计；
- 单独做漂亮局部模型后硬粘回整币；
- 用局部特写通过审美后跳过完整作品复核。

**Collateral Drift Rule：**局部修改只授权目标变化。若同时改变非目标区、已认可主形、比例、构图重心或材质身份，默认视为漂移；只有重新审查并主动接受后才能保留。

接受的delta记录**设计意图**而不是像素/顶点强映射，例如“缩小破坏范围、保留A完整币感、吸收B撕裂方向”。

## 6. 候选与用户问答

存在真实设计分歧时可以保留多个**完整作品状态**：
- 数量由问题决定；
- 候选代表不同设计假设，不是机械改参数；
- 证据表明较差/不可行就淘汰；
- 不因沉没成本死磕；
- 客观上已有明显最佳解时不强制A/B/C。

用户介入分两类：

**解释性介入：**Codex无法可靠判断形体身份、原意或已认可优点，继续猜会造成高代价漂移时尽早问。

**审美性介入：**多个完整候选都已客观成立，剩余差异主要是力量感、收藏品感、负空间、华丽/克制等主观取舍时再问。

展示候选尽量统一相机、尺度、背景、中性材质和照明。允许“都不行、难分、A的X+B的Y、低置信偏好”；不把审美伪装成高精度绝对分数。

## 7. 工具研究与Bridge证据

### 成熟方案研究按风险触发

以下情况先查项目资源与成熟方案：
- 方法陌生且失败代价高；
- 新工具/模型/订阅/大算力；
- 连续失败；
- 难回退转换；
- 已知有专业解法；
- 技术瓶颈正在限制艺术质量。

优先查：项目现有资产 → 官方能力 → 维护中的开源/成熟插件 → 必要社区实战/论文。

普通可逆小编辑不重复做市场调查。

工具状态只用：
- VERIFIED：当前环境、目标用途已实测；
- WORKING：有可靠证据，尚未在目标资产完成；
- UNKNOWN：资料存在，能力未证实；
- REJECTED：已有证据说明不适合。

### Bridge只输出当前问题需要的证据

轮廓用silhouette/clay；空间用depth/侧视；表面用normal；归属用ID mask；材质用neutral render；复杂接触用剖面/转台。

不会改变判断的通道不生成。结构控制工具必须真实支持对应输入，不能靠改文件名假装兼容。

## 8. 下游可并行研究，但不能替上游过关

可以异步研究：
- 用中性校准件研究材质；
- 用普通金属圆片研究碎裂；
- 提前验证viewer、导出和性能。

但：
- F不能证明C/M成立；
- A不能证明F/M成立；
- 烟、光、bloom不能补救主形；
- 技术校准件不能升级成艺术候选。

**允许并行学习，不允许下游美化替上游验收。**

当前领域底线继续有效：
- 裸金属霜面主要靠真实metallic + roughness/micro-normal/finish，而非灰塑料；
- 普通延性金属优先“受力/塑变 → 撕裂 → 分离”，主碎片来自同一受损母体；
- Digital Aura关闭后作品仍应成立；
- 统一币背是系列要求，但具体纹样尚未冻结，`web/icon.svg`等是设计输入而不是预定答案。

## 9. 谱系、Canonical 与收敛

重要主形/拓扑/构图修改必须能回答：
- 从哪个完整版本来；
- 改了什么；
- 保护了什么；
- 失败怎样回去。

普通小型可逆编辑不写行政日志。

若干接受delta累积后，周期性rebase为新Canonical C/M，旧Canonical保留。

晋升前看：
- K-fixed是否满足；
- 已认可优点是否保留；
- 局部修正是否造成全局副作用；
- C/M高价值分歧是否已解释；
- M authority是否fresh；
- 必要的用户审美分歧是否已处理。

一个问题可以暂时收敛，当：
- K-fixed无冲突；
- 主要设计意图在完整作品中稳定；
- C/M在各自权威事实上没有高价值未解矛盾；
- 继续修改的预期收益明显下降；
- 没有靠下游效果遮掩上游问题；
- 关键主观分歧已有足够用户反馈或允许继续。

最低技术指标本身不是收敛。

## 10. 状态分离与反模式

以下只写入执行状态，不写死进通用协议：
- 当前B图、原眼、GLB基线；
- 被叫停三视图、隔离coupon；
- 当前机器/余额/任务；
- 当前问题优先级。

只在用户采用/否决、K-fixed变化、Canonical晋升、authority fresh/stale变化、工具验证/证伪、重要失败或跨会话开放问题变化时更新状态。

立即停止的反模式：
- 新艺术对象无完整视觉依据却让低质量程序blockout先获得审美权威；
- 把M-tech当M-design；
- 第一张AI图/第一个模型只因先出现就被冻结；
- 脱离整币生成局部权威资产；
- 把非目标区漂移当“顺便优化”；
- 复制AI明显不可能结构；
- 因技术正确继续明显缺乏设计的方案；
- 用材质/烟光/面数/分辨率遮掩主形；
- 失败路线只靠增加算力继续堆；
- 重大设计已改变却继续让stale M约束新C；
- 为表现协议执行制造无价值日志、候选或测试。

本临时协议在正式系列设计、Bootstrap/C-M协同、Sculptural Core、Surface Finish、Damage/Fragment、Digital Aura、Human Preference与Canonical/Provenance协议稳定后退出。
