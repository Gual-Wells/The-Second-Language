## 2. 资源核查先于方案和操作（硬约束）

陌生或高难度步骤执行前必须先完成：

- **项目内资源**：找出相关现有图标、图形、模型、参考、设计稿和成功版本，实际查看内容；记录可复用部分及身份关系。
- **行业现有方案**：查可用工作流、工具、模型、平台、代码、许可、依赖和硬件要求；区分官方能力、社区扩展、本项目实测。
- **选择依据**：说明已有资源如何进入本次输入；明确剩余缺口与本次具体目标。

只有找到实证缺口，才决定定制。读取了文件但没有在实际设计/输入中使用，不能写成已经复用。

当前统一币背的必须检查资源：仓库 `web/icon.svg` 的现有开卷图形。它是实际品牌设计资源，不是仅供一句文字概括的主题。设计稿必须以其轮廓、书脊、页势及内部线条为具体研究起点，明确保留、转译和舍弃哪些部分及原因。不能让 AI 或程序随手另造一个通用书本替代它。

本机 ai3d-design-research 工作区已有固定快照：`production-feasibility-2026-10-12/sources/project-icon.svg`。项目归属与版本见同目录 `project-pin.json`。未来使用前核对是否有新版；不额外复制凭据。

## 3. 设计稿先于造型实现（硬约束）

涉及审美形态、符号、雕刻对象、纹样、铭文排版或其组合，必须先有以现有资源/当前完整作品为依据的 AI 视觉设计稿及清楚设计目标；不能仅凭文字规范由 Codex 原生程序造型。

- AI 设计稿是必要的视觉指导，**不因此获得几何真理权**。
- 现有用户已认可的 B 正面可以继续作为设计依据，不要求为满足“先有稿”重新生成。
- 建模前必须列出具体接受的视觉特征、对应对象、受保护部位与尚未确定的关系。
- 一张图的背面、隐藏指、实际厚度不能由“看起来像”认定。它们属于待解释的三维设计问题。
- 程序、原生曲线/布尔、成熟工具用于实现视觉设计和确定性工艺；不能把可解释几何或技术导出成功当作艺术设计。
- 统一币背的图稿要由既有项目图形和实际符号职责导出，不进行纯提示词凭空 logo/书本生图。

对应研究：第36–44节。此前“无可靠AI图就按工程约束自己做”的路线已证明不适用，禁止再次以较简单、先验证、可行性试样等理由绕过。

## 4. 完整作品与双表示协同（硬约束）

编辑范围可以是局部；设计上下文、候选与最终审阅对象必须是完整作品。

- AI稿与模型共享稳定设计内核；二者对不同事实分别提供依据。
- 真实模型的 clay/depth/normal/剪影/区域/固定视图反馈到设计稿；接受的设计增量再转译到模型。
- 内置图像工具未证实硬遮罩、ControlNet或像素保护能力；不得将提示词要求写成已实现能力。
- 只对关键剪影、动作、眼神和认可区域强对应；高光、固定阴影及幻觉细节不作为几何约束。
- 不生成脱离币体的新爪、新眼或新碎片后作为局部权威粘回去。
- 不重启用户叫停的AI三视图。原模型真实侧背渲染可用于检查，但不能伪装为B新三维的一致性证明。
- 原件与父版本保留；改变拓扑使用完整版本分支，不能覆盖唯一母版。

对应研究：第37–49、54节。

## 5. 制作顺序与质量边界（硬约束）

设计内核/完整视觉稿 → 真实结构 → 材质工艺 → 局部光/雾/粒子 → 运行与完整作品验收。

- 灰模以真实几何渲染核对；AI灰图仍是图稿。
- 金属损伤表达受力、塑变和撕裂；主要碎片来自受损母体，不能撒随机石块。微屑才适合粒子。
- 材质由工艺分区和真实光学实现；不把全图噪声、固定亮边、滤镜做旧视为手工工艺。
- 光/雾不遮丑；不能加大量特效绕过主形失败。
- 币是符号作品，不为生物解剖形式完美破坏构图。原眼保持；嘴、牙、角的旧破坏性修改不得凭旧报告复活。
- 用户已认可B；报告新建议不撤销该认可。B是正面视觉成品，仍需明确其与真实模型的差距。
- 内部淘汰明显失败；允许用户早期帮助解释设计，不能让“内部QA”遮蔽Agent误诊。候选比较用完整作品、相同条件。

对应研究：第7–35、50–58节及附录F/G。

## 9. 设计状态、职责与可进入阶段的条件

后续工作围绕三个持续保留的状态：完整概念 **C**、完整三维 **M**、不属于某张图或某个模型的设计内核 **K**。M0–M3是职责名，不能混成模型版本号。

| 层 | 必须输入/产物 | 本层可决定 | 禁止替代 |
|---|---|---|---|
| K / G0 | 主象征、动作、视觉焦点、硬不变量、保护特征 | 同一作品身份、优点保护、哪些省略是有意的 | 一张图的所有细节自动成为内核 |
| M0 / 视觉设计 | 基于现有资源/完整作品的AI图稿、对象边界与认可增量 | 构图、剪影、形面语言、主次、跨缘设计意图 | 无稿原生程序造型；宣传图被当作全部几何真理 |
| M1 / G1 | 对应完整三维、真实正/45°/侧/背、必要剖面和接触 | 厚度、隐藏面、接触、来源、结构连续与几何实现 | 技术正确等于审美正确；增加完整动物解剖抢走符号主题 |
| M2 / G2–G3 | 基材、工艺分区、微结构、老化、照明参考、运行验证 | 确实能交付的材质/光学行为 | AI高光直接反演为正式PBR；全局噪声刷旧 |
| G4 / 施彩 | 颜色承担的不可替代语义、完整器物设计 | 需要的施彩/覆层 | 用“更酷/更像森林”等泛理由替代雕塑与工艺 |
| M3 / G5 | 已成立静态器物、局部来源、空间实现及效果开关 | 光、雾、微粒、数字动态 | 烟光、bloom、粒子修补造型或主碎片 |
| 交付 | 源工程、高模、运行包、依赖、版本与同条件审阅 | 技术运行资格、完整作品比较 | 文件能打开、面数/分辨率达标等于作品获采用 |

进入下一阶段前，必须有本阶段相应的实际产物和检查结论；文档命名、工具宣传或一句提示词不算产物。概念比较只标“概念阶段”，未产生真实3D时不能用AI灰图通过M1关口。

开发可先探索下游能力，但必须使用符合第6条的既有无关校准数据，不能无稿制作带项目设计的新试样。不能把下游技术验证反馈成“上游艺术已成立”。

## 10. 二维—三维协同的强制动作

### 10.1 关键对象合同

每个本轮要改的重要对象，最少写出：`object_id`、设计意图、硬不变量、视觉依据、三维依据、对应强度、当前分歧、接受的转译。不要求为全部微细鳞片建表。

| 属性 | 依据与约束 |
|---|---|
| 情绪、气势、构图、视觉节奏 | AI设计提出、整币审阅验证；几何不能只追局部合理性 |
| 主剪影、头向、眼神、重要比例 | C/M共同保护；改变必须能解释并与保护基线比较 |
| 爪形、角形、碎片造型语言 | 图稿提出审美方向，三维解释承接/厚度/空间；不跟随图中幻觉 |
| 厚度、掌指接触、正侧背、断裂来源 | 真实模型是空间证据；无法确认就保留未知，不能自由猜造型 |
| 固定亮斑、阴影、AO | 渲染表现参考，不进入几何硬对应，也不烘成材质身份 |
| 材质意图、雾光构图 | 图稿作意图；实际材质参数/空间光源/遮挡另行实现验证 |

对应强度必须具体：剪影/认可landmark/区域可较强，认可depth/normal中强，RGB/感知相似弱，固定高光/阴影不作几何约束。禁止全图RGB误差目标逼模型复制假光和不可能结构。

### 10.2 Bridge Render Pack

修改前优先从当前真实完整模型输出所需clay、剪影、depth、normal、Object-ID/Material-ID及固定beauty；涉及空间承接时加真实侧/背/45°。记录源模型版本、相机和通道含义。

- World-space normal、原始Z-depth、对象索引不能直接假称符合某个ControlNet模型输入；实际转换/编码依该工具核查。
- 不同时强制所有通道与所有工具；必须选对本次问题确实能提供约束的通道，并证实目标模型接受它。
- 相机未校准的任意图稿不能当作多视图重建输入；高保真image-to-3D只提高传输忠实度，不判断设计正误。
- 新AI图先形成proposal；先审查负空间、视觉方向、焦点、杂乱，再解释到三维。禁止“新图好看→直接执行切模”。
- 三维执行后输出实际渲染反馈下一轮C；不能始终只修原概念图而不看当前真实模型，也不能一直修模而不再看认可图稿。

### 10.3 分歧复核

每轮将差异标为：AI幻觉、三维实现缺陷、有意转译、新提案或未解决。若差异触及眼神、主轮廓、焦点和已认可优点，先复核全局，不能用局部特写直接诊断和改动。

K本身独立保存，避免错误在C→M→C中互相强化。原眼误诊与程序圆管爪是固定反例，后续工具升级不使这些失效。

## 11. 材质、光学与“反AI质感”的执行条件

### 11.1 先解释工艺，再做参数

必须把AI外观稿中的表面意图转成：**substrate → finish regions → microstructure → aging → lighting reference → runtime validation**。先回答哪里是什么材料/工艺、为什么发生，而不是直接从beauty图估计全部PBR。

- 对裸金属，雾面主要是rough specular，保留金属反射属性；不能通过降低metallic得到灰塑料。
- 氧化/污层与裸金属区别处理，不能全币强设同一种材料身份。
- 底场、主浮雕、次浮雕、暴露高点、凹处、新断面、侧缘分别解释finish；noise只能加入合理微变化，不能产生工艺布局。
- 高点burnish、凹处patina、fresh fracture和加工方向有因果；手工感不等于过度划伤、满铺龟裂或每条硬边都发亮。

### 11.2 五尺度分工

宏观主形/轮廓/厚度/接触/倒扣用真实mesh；中尺度浅刻可高模烘焙或有限位移；微normal只应改变反射，不能读成砂粒；亚像素结构用统计roughness；anisotropy仅用于有明确加工方向的表面且核对tangent space。

禁止normal贴图冒充包背爪、口腔、破口厚度和主要浮雕。不要为每种尺度都安装一种新工具，按问题选用已有实现。

### 11.3 照明、剥离与校准

- 资产必须保留独立的中性参考渲染与艺术展示渲染；记录实际IBL、曝光、tone mapping。不得比较不同电影调色下的候选再归因于材质。
- 透明canvas仍可有不可见反射环境，不能为显金属质感强加可见展厅/幕布。
- 对真实模型依次关闭施彩（若可诊断）、emissive/bloom、雾/微装饰，再用统一clay柔光检查主形、动作和焦点。AI改出的灰图不是真实剥离。
- 符号确实依赖颜色时保留语义例外；基材本身颜色不是施彩。用户指定的龙眼/龙口光身份不因诊断关效果而被永久取消。
- 工艺参数用本项目同一校准资产、同一环境、各目标渲染器与真机校准；禁止把任意roughness值命名成行业标准。
- 慢转检查宽柔连续光流、静止阴影、高光跳点和鳞片同时抢亮。无高光不等于高级磨砂，静态截图不构成光学验收。
- Specular anti-aliasing必须A/B比较，不能默认强开后牺牲锐度；真机结果未取得就标未知。

### 11.4 母版与运行包

母版材质/无损贴图和运行GLB分开；GLB不能成为唯一永久母版。导出核对roughness=G、metallic=B；数据贴图线性、base color正确颜色空间；检查真实通道内容而非材质名称。

程序节点/OpenPBR/MaterialX不会自动等价进入GLB；需核查导出映射、烘焙与目标引擎支持。KTX2/UASTC等只在具体压缩需求出现时试，normal/roughness/finish mask优先保护；压缩前后比较梯度、微结构、霜面和转动shimmer。包体缩小不能抵消质感丢失。

专业扫描、cross-polarized、photometric stereo与BRDF库属于可选研究资源，未实取/许可/测试不得写成当前材质能力，也不强制建立新采集系统。

## 12. 损伤、来源与正侧背的执行条件

损伤属M1，断面材质属M2，微屑/雾才属M3。必须先有完整设计稿的损伤意图和夹持关系，再用成熟雕刻/变形/切分方法实现，不能以“能回拼”允许无稿原生造型。

按D0–D6最少落实：

1. **D0受损母体**：已压弯/压薄而尚未分离的同一母体；可保留局部源区域，不为验证重做整枚币。
2. **D1接触场**：指腹/爪尖/币缘与压力来源；裂纹起点有对应关系。
3. **D2撕裂网络**：主裂、克制短支裂、剪切区与终止；不全币蜘蛛网。
4. **D3来源**：主片由母体实际分离，不另造装饰多面体；保存source_patch、源/离体变换。
5. **D4断面**：真实厚度、卷曲/撕裂唇、薄韧带、必要毛刺；区别旧外表面与新断面。原侧缘只在源片本来含它时保留，禁止为满足表述凭空加边刻。
6. **D5层级**：附着瓣→主片→次片→微屑有尺度与方向；不等大、等厚、等距。
7. **D6交付**：主要及重要次级片是mesh，静息姿态确定；手机不随机重算破碎。

回拼须提供实际逆变换视图，核对互补面、缺失位置及币厚。体积守恒是辅助，不可替代形状对应；微屑/撕裂间隙按清楚容差解释。关材质/雾仍读出损伤，真实360°仍成立，才能继续断面工艺与Aura。

工具选择先核查：Houdini MPM/RBD做受力/塑变参考，定向cutter做互补切分，Blender/ZBrush做艺术细化，Interior Detail只处理新断面。不得把节点名、物理模拟或watertight结果当作艺术质量，也不为静态雕塑自动引入昂贵仿真。脆性/超自然材料行为必须属于明确主题规则。

## 13. 统一币背与要素整体协调的执行条件

统一币背必须建立真实系列身份，不能回到512Canvas贴图+大罗马数字的原型。也不能仅因元素简单就由Codex无稿做书、圆环和字。

- 起点是项目现有icon的实际形态及已研究的系列币资源；AI设计输入必须有具体参考，明确保留轮廓/书脊/页势、如何把内部线条转为镌刻、如何去除应用UI底色而保留身份。
- 每个拟加要素写清意义、显著度、数量及与其他要素的关系。主印玺、系列归属、章身份、可选微刻/日期整体组织；不能把“每项有寓意”当作全部堆上的理由。
- 40微刻的学习节律、开卷、铭文等是具体设计研究，数量/10×4/尺寸包络先试完整构图再决定。不能预定技术规则后牺牲协调性，也不能无解释删掉用户研究中的元素。
- 保留主印记/身份区域和安静外围结构场。普通S、包边W、破损F是结构情况，可重叠，非质量等级；真实跨缘爪、压痕和破口不得为了统一截掉。
- 背面默认依基材、浮雕、镌刻、finish，不施彩、不独立发光/烟雾或再讲章节主题。正面真实效果可自然跨缘但不吞掉系列身份；不生成第二幅龙图抢焦点。
- 编号应长期可读、可扩展且不占中央主焦点；UUID/hash/二维码/答卷留权威记录，不能把币做数据库标签。
- 设计候选必须看完整背面、实际正侧背衔接和正常手机观看尺寸。图稿设计成立后才允许原生几何/矢量转译；母版采用后固定版本，后续实例沿用同一系列合同。

统一性是硬要求，具体纹样未采用。当前原白模平整背面保持，直到有符合本协议的新视觉设计与结构转译依据；不借新统一规范破坏原件。

## 14. 数字Aura、静息与实体翻译的执行条件

必须能独立审阅静态器物和效果层。报告REST/AWAKENED作为制作分层保留；正式产品默认/触发尚未决定，不能自行改用户要求的眼口光或恢复自动转动。

- 静态器物/档案状态确定、可保存、无依赖烟雾/粒子/bloom的身份；主题所需且采用的施彩可以保留。
- 每个emissive有明确设计光源，关闭bloom仍可读；不能普通鳞片全发光、整币霓虹或用光修剪影。
- emitter表面发光和照亮附近牙/眼/爪是两件事，必须核查运行引擎实际光照实现。
- 雾为object-local/emitter-bound，有方向、密度衰减和真实遮挡；透明PWA不使用全局fog罩币，不以黑云图片冒充空间雾。
- 主碎片不变成particle；微粒数量/方向服从损伤，不替代来源。移动端overdraw、排序、透明边和性能须实测，未测不进入成品结论。
- 动态效果先考虑视角相关finish、微刻、各向异性或潜像；不把每种动态愿望都交给粒子。
- 数字母版与实体翻译共享K；数字可保留倒扣、包背与独立片。未来实体版本按脱模/金属流动/浮雕工艺另译，不强制把当前数字设计压成可铸STL，也不承诺现有GLB可直接铸造。

## 15. 候选、偏好、版本晋升与工具证据

### 15.1 同条件比较与内部淘汰

AI候选同完整尺度、背景、镜头与观看距离；三维候选同实际相机、中性材质、照明、转台路径和视图集合。局部crop仅解释，不晋升为独立设计母稿。

内部先排除明显断指、模型变形、接触/来源错误与高频杂乱；不让用户筛垃圾中间稿。正式审美比较通常2–3个完整成熟候选，记录相对偏好和是否可推进，允许都不行、难分、无偏好、低置信与混合贡献；不用8.7分等假精度。

用户早期参与未明形态是设计协作，不是基础质检外包。反馈须翻译为设计delta，重新在完整作品实现，不能机械拼A/B图片。单一“更好”不代表“已合格”，局部偏好不自动批准全币。

### 15.2 Canonical晋升

若干接受增量合并后，比较完整剪影、构图、保护区域、K和上一canonical。全部解释后才晋升新C/M；旧canonical永存。发现累积漂移先回父版本，不能在同一文件无限叠修。

只晋升有相应证据的层：B正面是视觉采用，不自动晋升成完整三维；材质截图不是实际PBR；技术导出不是美学完成；真机未知不能写已通过。艺术采用由用户决定，技术报告不能覆盖。

### 15.3 资源能力等级与退出

每种工具/模型/平台区分：**仅资料可见 → 代码/许可已核查 → 当前环境可执行 → 同类任务技术通过 → 本资产艺术采用**。源码/权重版本、许可证、真实硬件、可导出性、输入约束、已测成本/未知项必须可回查。

不把TRELLIS/Pixal、DreamCraft/CraftsMan、ControlNet/IP-Adapter、Krita、Houdini、MaterialAnything等名称当作已验证能力；不因论文支持思想就宣称同工作流已复现。先复用已有成功环境；模型升级、下载和付费先根据具体缺口决定。

新执行保持D盘实际存储、原件、预算与未知计费保护；运行中/未知任务不重提。先保存成功阶段和来源，失败按具体缺口续必要步骤。有限迭代仍无法得到成立的视觉/结构，就返回资源与设计研究，不能无稿手搓补位，不能无限追高分辨率。
