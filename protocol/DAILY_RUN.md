# 每日课程运行协议草案

目标执行载体：Codex 桌面端定时任务，模型 `gpt-6.1-sol`，推理强度 `max`，启用live web search。每日北京时间 **05:00开始生成**，完成全部建设与审阅后发布，不将05:00解释为保证发布完成时间。2026-10-24起50主词；所有义项、词族及实事/现实可用性/难度约定保持。允许充分使用工作时间与中间文档。一次定时触发只是唤醒；同一目标日期的新流程运行中断后继续已有输入。2026-10-23用户明确旧章内容封存且不纳正式项目，新章从第1章开始；不兼容迁移、补写或续作旧流程内容。新章执行CURRENT_AFFAIRS.md，语义教学仍由原主协议规定。

## 开始

章节发布按暂存版本的插入顺序保护当前指针：旧版本发布请求重发不能覆盖后来已发布的版本；同一当前版本重复提交不延后发布时间。修订采用新的正文摘要并重新暂存，旧正文、答疑与练习来源继续按旧摘要读取。

1. 以北京时间确定目标日历日期 `YYYY-MM-DD`。**先运行** `node scripts/claim-run.mjs YYYY-MM-DD`，读取保存的 `work/runs/<date>/control.json`。2026-10-25起默认休息；用户关闭休息仅放行下一次新领取运行，首次领取在同次数据库写入内恢复`rest_requested=1`，以`rest_revision`保护后来的安排。同日重试得到同一领取结果，不再次消耗设置。若 `rest=true`，当天整个定时运行到此结束：不建设日课、不标记 VIX、不发布日课或临时页；休息保持开启，未完成的临时需求保留到后续运行。若本日章节已发布，不重复生产。已领取的非休息运行不因默认切换倒改为休息。

Windows 定时入口 `scripts/run-daily.ps1` 在启动 Codex 前确定性地完成上述领取；休息日直接结束，不消耗模型调用。非休息日再启动 Codex，Codex 可以幂等重读同日领取结果并继续协议。
本机新增运行资料实际存 D 盘；兼容旧运行入口时可以保留 C→D 联接，但须把物理任务目录或专用父目录登记到归档运行器 `.cache/runtime-sources.json` 的 `linkedDirectoryRoots`，不能只建联接就声称工作资料已备份。优先复用已登记的日课实际父目录，按 STORAGE.md 回读快照确认。
日课默认不提前生成音频。用户可在设置为下一新章一次性选配第二部分例句与第三部分逐句Bella音频；首次发布按选配原子入队并恢复空选配，休息、领取与旧章重发不消费。按AUDIO_CONFIGURATION.md由独立服务随后处理，已成功音频复用；手动点读仍走原通路，Codex不重复合成、不等待声音才能发布文字。
2. 若领取结果带有 `temporaryRequest`，按 `protocol/TEMPORARY.md` 处理测试或复习需求，可在日课前独立发布。复习使用已发布章节作来源，不把临时页当作新章节，不标记 VIX。同日续作先查中间文档和临时页发布结果，避免重复建设。
3. 完整读取RECOMMENDATION.md的早期可用性与现行难度偏好，再读取 VIX 通用英语辅助索引、标注状态、原始词表成员关系和两份 `textbook` 文件，记录各文件的Git commit或摘要。`prepare-vix.mjs` 首次固定输入，续作只按原锁恢复，不刷新main；已固定选词却无可核验新流程输入锁时保留待查，不能重选或给旧运行造兼容锁。尚无本日期feedback.json时运行 `node scripts/feedback-snapshot.mjs YYYY-MM-DD` 保存并实际读取学习目标/反馈；已有快照先恢复，不以新反馈重选冻结词汇，没有反馈不假设用户水平。按CURRENT_AFFAIRS.md在最终选词前从来源池按需取材、读取原文，与VIX及近期现实理解/表达收益双向判断；整体挑战适度上调、不降难，以具体用法和需求判断，不能把低阶owner误当作没有高阶内容，保留本协议全义教学边界。新闻标题/摘要不冒充已读事实。主观判断不得被固定打分、主题命中或多义数量替代。
4. 初筛后、最终冻结前，读完拟选主词、真实相关派生与交叉引用的完整Collins/Oxford内容，在既有words文档保留去向与疑点，明确全义和词族范围；实用性、难度依据具体内容判断。此时不要求先写完课程，但不能只读新闻命中义或只据词表名称冻结。真实同族聚合，不以派生重复占主词名额，不按机械词形扩大词族。然后在 `work/runs/<date>/selection.md` 自由写推荐思考，在 `selection.json` 冻结 `studyDate`、`vixInputCommit`、`vixMarkLabel` 和 `mainWords`。`mainWords` 恰有 50 个主词；每项保存 VIX `entryId`、`globalRank`、`text`，相关派生词放入该项 `family` 并记录相同身份字段（教材有而 VIX 无的派生词仍记其文字，但不填 VIX 身份）。选择的是完整教学范围，不是义项子集。`vixMarkLabel` 必须记录为真实北京时间的 `YY-MM-DD`，由 `studyDate.slice(2)` 得出（例如 `2026-10-04` → `26-10-04`，年份范围 2000–2099）。标注和发布均校验真实日历日期，跨年不复用去年的标签。旧流程运行只封存，不迁移成新正式章；新运行的标签或输入不一致时停在原输入核对，不刷新main或重选。
5. **完整确定本次推荐并冻结selection后**，运行 `node scripts/prepare-vix-marking.mjs YYYY-MM-DD` 建立独立的 `work/runs/<date>/vix-marking` 工作副本；`.cache/vix/<commit>` 只读。以同一副本依次运行 `mark-vix.mjs --vix=work/runs/<date>/vix-marking --selection=work/runs/<date>/selection.json` 与 `publish-vix.mjs`（相同参数），把实际纳入且有VIX身份的主词、派生词与同词变体标注、构建并提交。工作副本绑定原输入commit和selection摘要，重跑复用、不覆盖未提交标注。publish-vix在PATCH前保存本日期vix-publication.json，回包丢失先核对同一精确提交，成功重跑不重复写入；无法核对保持预备回执。meta.vixCommit取该回执已验证的vixCommit，不填旧章或任意合法SHA，不往冻结selection追加字段。章节发布会核对回执与本次来源/选词/原输入，正文和来源均回读核对字节摘要。远端main确实不含本次提交时保留输入、选词及标注待核对，不刷新输入或重选。中断继续同一组选词和同一章节。

## 课程建设

新启动的课程运行正式执行 ETYMOLOGY.md：一级词头下一个简洁词源区块，分点说明有助理解与记忆的关系，不与用法强制一一对应；两教材释义按 CONTENT.md 融合为一套。prepare-vix取得词源资料及说明，查阅用lookup-textbooks，来源简记到既有逐词文档。新章meta.json同时设置 `contentPolicy: "etymology-fused-v1"` 和独立的 `sourcePolicy: "current-affairs-v1"`，不能用来源策略替换教学策略。章号采用服务端新正式序列；打包和暂存仍检查词源、讲解与编码结构，不能证明史实或融合语义正确。

第一、二部分对50个主词按字典序建设。**执行QUALITY_WORKFLOW与TEACHING_AUTHORING：逐词族独立补查两书原件，协同写全讲解与针对性例句，再用稳定集合建设真实取材文章组并逐篇审阅。** 冻结前可用candidate-scope准备材料，冻结后按原selection复用/补查；不能从不完整的旧lookup集合中筛选替代补查。工作文件及命令见TEACHING_AUTHORING，最终作者稿与装配稿保持一个权威关系，中断从已有原件和具体续作恢复。

同时完整读取[QUALITY_SCALE](QUALITY_SCALE.md)，将保质精简放进既有内容规划与语义审阅：观察三部分实际负担，删无增量冗余，不删教学范围，不追压缩率或用更密的句子冒充减负。没有可安全删减处允许保留原长；不新增每日多稿、评分队列或字数发布门槛。

按 `protocol/USAGE_LABELS.md` 建设各类用法标签与适用场景说明，以学完后基本掌握词汇为目标。全量覆盖造成的适度教学编排感是已接受的取舍，不能因此省略生僻或难安放义项。

最终正文有且仅有三部分；章节内关联编码与第三部分逐句译文按 `protocol/ANNOTATIONS.md` 写入。编码是不可见的结构注释，不是额外正文部分：

1. 主词按字典序排列并作为一级标题。各义项作为二级标题，Collins 义项为主轴；核实后的美式音标直接接在二级标题末尾，下一行等宽样式写双教材融合后的核心义，不加来源或音标说明字。先完整检索 Collins，再完整检索 Oxford，并建立两份内容的内容性集合。Oxford 独有义项如不能对齐，由 Codex 写成 Collins 风格二级义项。主词义项之后，相关派生词继续作为二级标题建设。这里不打印例句。每个词条、二级用法及可独立举例的细用法和短语实例使用章节内唯一编码。
2. 同主词顺序，列出第一部分抽出的全部相关例句，每句下一行等宽样式给出翻译。缺例句的用法按需生成。派生词例句纳入所属主词。例句标出对应第一部分用法编码。
3. 真实取材的文章组，篇数、体裁和长度由内容需要决定。词与词之间、同词的义项之间不按教材或USE编号排序，可以分散到不同篇；整组文章合计真实、正确使用第一部分全部二级及细用法。每篇独立有完整内容，不能把套词展台切碎充数。ARTICLE标记篇目，全章SENTENCE身份唯一，逐句译文；只有真正使用目标义项才列USE。允许承接句无USE，自然复现不限一次。现实运用在合适内容中偏重，专业/历史/少见义仍用适合的真实语境完整承载。

课程正文不介绍教材、采集流程或内部操作；文章本身所需的事实归因正常保留，不把来源工具说明塞进作品。原文链接与事实摘要在正文外的现实参考中逐篇定位。

语音朗读的扩展边界见 `protocol/AUDIO_EXTENSION.md`。它目前不参与日课的完成判定和定时任务执行；正文编码与摘要应保持可供以后独立补发语音使用，不因未来选用哪家 TTS 改写词义、文章或 VIX 标注。

## 完成与交付

按QUALITY_WORKFLOW完成教材保真、逐篇内容、全组真用和译文审阅，采用assemble-teaching输出为正式chapter.md，meta记录authoringPolicy=sourced-collection-v1。source-notes.json保留实际读件、自写事实和边界，并采用导出的articles篇目来源数组。按CURRENT_AFFAIRS先pack-current-affairs，再pack-chapter与原publish-chapter；正式正文须与已核查作者稿装配一致，来源篇目与正文一致。正文摘要与来源摘要分离，永久回读核验后才进入目录；修订重新核对，不把结构通过冒称内容质量已通过。推送只在章节可读后发送，不新增第四部分。

如果定时任务接近结束，更新 `work/runs/<date>/resume.md`，具体写清已完成内容、下一步与未解决处。不要仅因为运行窗口结束而宣称章节完成。

Cloudflare 资源不足的续作与测试隔离遵循 `CLOUDFLARE_RESOURCES.md`。KV 发布失败时保留同日期的完整产物与待发布步骤，不重新推荐、重新标记 VIX 或宣称已推送；2026-10-04 本次账户写入限额的已知恢复时间是 2026-10-05 北京时间 08:00。

## 任务末尾额度更新

执行本协议所涉及的日课、推送、练习建设、批改、声音分析或测试工作时，最后按 `BALANCES.md` 查询各方额度，携带核对时间、核实/估算状态与用户完整学习流程的用量范围，发布更新到余额页；各方仅在不足三次最大消耗任务的预留时提醒。页面显示上一次任务的记录，浏览时不实时查询。不自动付款，不安排余额不足后的跨日轮询/重试；已有材料与未知计费保护继续有效。

### 明确撤回已领取的休息

休息领取后再关闭设置不等于本次运行恢复；它只放行下一次新领取日期。只有用户明确撤回该日期的休息，运维才可在run_rest_overrides写入与原claimed_at绑定的不可变授权及理由；原run_claims行保留。领取和发布暂存共同读取同一有效状态；不能只改本机control.json或清空原休息记录。恢复只作用于指定运行，不消费后来为其他日期设置的安排。2026-10-24原休息的明确撤回仍是该日期专用历史授权，不代表以后默认开工。

### 用户明确撤回整章并要求重新生产

常规定时任务不得自行撤章或重选。2026-10-24用户明确要求撤回当日第一章、对应VIX记录、恢复序列并手动触发一次发布，这是该次冻结保护的授权例外。原件、来源绑定、收费结果与未知计费状态保留；chapter_withdrawals保存原digest、选词摘要、标注commit和撤回前紧凑状态。formal_chapter_sources排除已撤回版本，正式目录、章号、后台新处理及认证资格共同采用此作用域。原版本暂存／提交及原运行摘要重放均被拒绝，不能靠重新提交旧产物恢复。

运维核对当前指针与原运行后，先保存可恢复副本，再撤去该指针及daily_runs当前锁；保留run_claims与已有有效休息撤回授权，不消费后续休息设置。只对该章实际标注身份作VIX前向撤销提交，不改Git历史或其他章标记。原chapters/<date>移至chapters/withdrawn/<date>-<digest前8位>，原work/runs/<date>移至D盘work/withdrawn相同身份目录；该目录不是续作输入或正式章节。确认目录为空、下一章号为1、VIX撤标已回读后才唤醒正式DailyCodex。新运行在原日期重新固定当前VIX输入与选词；后续中断照常冻结续作，不因此获得无限重选权。正式发布与后台音频仍走原通路。
