# 正式章节理解测试

用户决定：先实装申请测试，认证及纪念币留接口；允许不限次独立随机重测。当前使用二十道理解题（单选与多选），目标约十分钟；不是 IELTS band、全量掌握证明或正式认证。

## 申请、出题与作答

- 标题页与第三部分末尾进入同一测试列表。选择新申请绑定正式章节原版 digest；同一请求编号重发幂等，重新申请才生成独立种子与试卷。已发布历史版本也能复习，不改 VIX、正文或雅思来源。
- 原本机答疑服务按可执行队列先后处理。空队列不调用模型；申请后以现有 Codex 账户出题。完整固定版本全文作为资料而非指令；指定二十个不同主词与随机题型，跨新语境考察用法/义项边界，有可信干扰项，不以拼写、后缀或抄原句充作理解考察。正确项分布由教师在出题时审阅。
- 结构化要求见 `chapter-test-contract.mjs`，教师指令见 `chapter-test-prompt.mjs`。每题必须提供逐项理由、正确键、解释和该主词原文中的逐字依据；服务器验证字面依据和结构。自动校验不能保证全部语义无歧义，发布前模型自审与真实使用反馈仍必要。
- 试卷准备好后进入单独作答窗口；题目滚动、提交栏常驻。答案按测试编号保存本机草稿，切换、关闭与刷新不清空。未答完不能提交；提交前明确确认。答案仅在成功提交后展示，包括逐题解释、原文依据和干扰项理由。
- 单选按正确项、多选按完整正确集合计分，每题同分，不给多选部分分。提交结果按答案摘要幂等；响应丢失时相同答卷可重交，其他答卷不能覆盖。重测不限次，每次新申请独立出题，并保留所有已提交结果。

## 存储和隔离

`chapter_tests` 在主 D1 只存状态、版本摘要、种子、租约与永久原件摘要。完整试卷、隐藏答案与答卷直接写 OneDrive 的内容寻址原件，不扩大 D1 正文存量。结果读取故障不作缺失，不重新出题或改写已提交状态。本机 `work/questions/<id>` 保存请求、章节和结构化产物，通过现有归档服务保真保存。

正式 API `/api/chapter-tests`：列表/申请；`/<id>` 读取；`/<id>/submit` 提交；`/<id>/retry` 明确重试失败出题。`/jobs/claim` 和 `/jobs/<id>/{heartbeat,complete,fail}` 仅发布身份可用；五分钟租约、每分钟心跳，过期标失败，不悄悄重新调用。原 `/api/questions/jobs` 也支持同样的监测与分流。后台持有答案，前端提交前只拿题干与选项。

`/capabilities` 声明 `testing:true, certification:false, coin:false`；结果保留 `certification:null, coin:null`，未来可扩展，不创造假的认证记录。满分当前只表示这份理解测试全部正确。认证研究和艺术实验仍独立，不能混入正式结果。

## 验证和运维

`scripts/check-chapter-tests.mjs`：版本、随机目标、来源、隐藏答案、共享队列、处理权、不可变答卷和原件故障保护。`scripts/check-maintenance-ui.mjs`：手机问答配对、草稿、提交和重发恢复。真实手机及实际题目理解质量仍以使用反馈验收。

领取器 `scripts/question-worker.mjs` 兼容答疑与测试；`--tests-only` 供明确的运维验收单独领取测试，不影响普通队列公平性。任务末尾查询余额并排入永久归档，无新增订阅或第三方出题 API。
