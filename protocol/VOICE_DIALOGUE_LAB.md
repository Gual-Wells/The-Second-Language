# iOS ChatGPT Voice 对话试验设施

状态：用户于2026-10-24授权建设可试用设施，尚未升格为正式口语评测或认证。入口为`/labs/voice-dialogue/`，独立试验页；不增加阅读器常驻按钮。该设施准备材料与回收反馈，实际语音对话在用户选择的iOS ChatGPT中进行。

## 1. 来源与目标

- 正式来源仅取登录后的`GET /api/chapters`现行目录，按同一`id + digest`读取完整原文。目录和正文使用新鲜查询参数，避免Service Worker在离线时用旧缓存冒充当前资格；生成前重新核对，摘要不符、撤回、封存或历史版本均拒绝。
- 保留`chapterId + bodyDigest + USE`身份；同词不同义、固定短语和细用法各自记录。抽取完整用法及父二级标题的共同释义、语域/领域、句法限制、对应例句和原文语句，不能只拿词头字符串。
- 正式目录为空或未登录时，明确提供原创`voice-demo-v1`：5主词、7用法。该素材不是旧章或在写稿，不占正式章节、VIX或认证资格。不能在正式读取失败时悄悄替换成示范。
- 旧训练原件和回导报告可保留。原正式版本退出当前目录或无法联网核验后，不再导出其训练指令/背景；通过独立“刷新目录”复核后才能继续导出，避免复制/分享时等待网络丢失iOS用户激活。已发送外部服务的副本无法远程撤回。

## 2. 训练组织

核心模块`web/labs/voice-dialogue/core.js`承担读取、抽样、训练指令装配和报告结构处理；不请求模型。默认每轮4个用法，试验上限6，可按实际体验调整，不能转化成教学全义数量配额。

到期、尚无独立产出证据的用法优先，优先级内按种子随机，并尽量保持词汇多样性。同词其他义项仍在池中，不因词汇多样性而被删除。默认引导语让Voice围绕兴趣与用法创造信息差、共同决策、解释或协商；后续跟随真实发言，避免为凑词制造不自然情节。

语义提示、形式提示、示范和纠正逐级使用。模型自己近期给出目标表达后，用户复用不算独立产出。用户采用其他正确表达仍是交流成功；没有说目标词不算答错。罕见、书面、历史和专业义放入合适角色、文本讨论或口述写作；不伪装成普通闲聊，也不据此削减正式教学范围。虚构角色可以用，但不能冒充新闻事实。

## 3. iOS交接

1. 选择正式章或明确选择示范，可填写想聊的话题，生成本轮固定训练包。
2. 复制英文训练指令到ChatGPT新对话并发送，再由本人开启语音。文件分享与下载为备选。指令已含所选用法完整材料，不强制另传整章；需要更多背景时自行下载并附上原文。
3. “打开ChatGPT”只访问`https://chatgpt.com/`。没有受支持的自动发送／启动Voice集成，因此不伪造跨App一键开聊、API连接或后台实时接管。
4. 分享取消保持原包，不自动改成下载或发送。剪贴板权限不可用时提供手动复制／文本下载。真实iOS分享目标、账户功能和Voice对文件/上下文的遵循需本人实机确认。
5. 结束时把会后JSON请求发回同一ChatGPT对话，再将其报告粘贴或作为本地小文件导入本页。

官方当前文档已说明Voice支持上传文件与Projects，但不据此保证所有iOS入口与账户一致：
- https://learn.chatgpt.com/docs/whats-new （2026年8月3—7日更新）
- https://learn.chatgpt.com/docs/features/voice

## 4. 报告与学习记录

报告固定`tsl.voice.report.v1`、sessionId、sourceId、sourceDigest；entries只接受本轮选中USE，不得有未知或重复身份，最大200KB。结果为`independent / prompted / imitation / alternative / error / uncertain / not_observed`，包含提示等级、本人原话、当时AI问话和解释。

独立产出缺双方原话则降为存疑，有提示则降为提示/模仿；明显AI已给目标表达亦降级。未提供的目标补为未观察，不记失败。结构检查和字符串线索无法验证真实语义或原声；所有报告始终为`external-unverified`。用户核对并明确保存前不更新练习历史，保存后报告锁定，不重复累计；先后导入不同会话后再重导旧报告也不再累计。

试验复习间隔是产品启发式：独立产出逐次约1/3/7/14天，提示/模仿约8小时，明确用法问题约2小时；未观察或存疑不制造失败、惩罚或掌握结论。只有本页后续目标选择使用这些记录，不回写VIX、正式雅思、章节测试、成绩或卷轴。

训练会话、未提交报告草稿和核对记录仅保存在本机浏览器独立键`second-language-voice-dialogue-lab:v1`。同章同版全文快照去重保存，报告按session隔离；切换训练与刷新不覆盖草稿。可导出本机资料，仅清除本页自己的键。空间不足/存储被禁用时保留当前内存与下载能力，不虚报持久保存或清除其他应用数据。此试验没有跨设备云同步或自动备份恢复承诺。

## 5. 成本与验收

本页只有已授权章节只读请求，不录音、不调TTS/ASR/Realtime/OpenRouter、不启动Codex逐轮评测或新后台任务，不新增订阅/数据库。外部ChatGPT本身仍受用户现有套餐及用量限制。

确定性验收：`node scripts/check-voice-dialogue.mjs`检查完整语义材料提取、身份、调度、提示分级与报告保护；`node scripts/check-voice-dialogue-ui.mjs`隔离检查手机布局、复制分享、原件下载、显式核对、草稿、在线资格及无收费/写入调用。模拟浏览器通过不等于真实iPhone Voice通过。

实机验收重点：能否顺畅带入同一对话、目标是否自然引出、是否认真回应本人内容、提示是否恰当、报告原话是否真实、同义表达与ASR疑义是否被正确对待，以及新情境中的独立产出是否增加。尚不能用按钮成功、格式合规或单次关键词命中宣布训练有效。
