# 完整原声采集与 Codex 口语教学协议

当前默认设计（v2）：每份录音 Whisper、Gemini Flash、Qwen、GPT Audio 各一次全量独立调用，然后 Codex 完整接管。GPT Audio 是增加的第四路主数据模型，不取代原三路。新增模型可以凭增量证据价值进入固定主链，不要求先全面胜过既有模型。

正式录音入口、私有存储、后台采集与 Codex 在线领取已经启用；当前运行入口见 SPEAKING_RUNTIME.md。没有录音的文字口语练习只评价文字。日课、VIX、休息与临时页不受本协议改变。

## 协议实体

- `speaking/contract.mjs`：模型 prompt、十二维与声音细节两种产物要求、Whisper 参数及 Codex 接管提示，是请求要求的唯一代码来源。
- `scripts/lib/speaking/collect.mjs`：请求与保真保存、结构读取、异常及来源标记，不裁决语义。
- `speaking/routes.mjs`：模型通路与额度池分别登记。当前为 OpenRouter 整体钱包、Cloudflare Whisper、腾讯 SOE；未来渠道保留接口。
- `scripts/lib/speaking/funding.mjs`：Cloudflare 侧查询余额/key 额度，核实共享钱包和 key 额度，不负责跨日调度。
- `worker/speaking/collector.mjs`：领取、四路采集、专项补听、私有保存与故障恢复。
- `worker/speaking/control.mjs`、`scripts/speaking-detail.mjs`：私有专项入队；本机只提交控制请求，模型调用在 Cloudflare 执行。
- `worker/practice_migrations/0004_speaking_live.sql`：已应用的正式口语迁移；`worker/speaking/schema.sql`、`wrangler.example.jsonc` 保留早期预建设参考，不作为当前部署入口。
- `research/speaking-facilities-engineering.md`：正式上传、私有文件、队列及上线边界。

每次运行固定 contractVersion 与 digest，专项固定自己的计划与 digest；变化产生新版本，不以新部署默默重评。供应商未公开模型快照时记录真实返回身份与未知项，不编造 pin。

## 1．接收作答

原始录音是权威。新提交产生 speaking attempt，绑定题目、来源及参考答案的当时快照，记录是否先看参考。重答产生新 attempt，不覆盖旧答卷；音频和完整模型结果不进公开仓库。

私有保存原件；兼容接口所需完整 WAV 副本记录原件/副本摘要、格式、采样率、时长。不得删停顿、改速或改句序。四路读同一副本；准备成功才排队，不在缺少编解码能力时假装支持任意 iPhone 文件。

作答独立于日课时间与休息。上传完成即可离开 PWA；未来界面状态区分处理声音、等待充值、等待教学分析、反馈可读及需处理异常。

## 2．独立全量采集

Whisper 提供原生转写、句段/词时间、VTT 及实际返回的识别统计和 usage。首轮不传 initial_prompt/prefix，不输入题目、词汇、范文、其他输出或确认稿；解码提示不是通用口语分析 prompt。当前保留 beam_size 默认、vad_filter=false，不因本轮改大 beam 的结果反而变差而盲目升级参数。识别统计用于排查 ASR，不当作发音评分。

Gemini Flash 与 Qwen 独立读完整录音，不互看输出及确认稿。两者均检查可理解性、局部语音、词重音、突出重点、节奏、语调、连读/弱读、停顿、犹豫、重复、修正、连续性。Gemini 更关注整句意群与组织，Qwen 更关注字面碎片及局部声音，不能因此忽略其余维度。

忠实转写保留填充词、重复、截断、重启与结尾；意见引用原话及自身片段 ID。允许优势、普通现象、疑似问题和不能判断，无问题数量配额。Gemini/Qwen 请求使用 json_schema 与 require_parameters，当前输出容量每款 12288 tokens；容量不是要求填满，也不冒充提供商实际 usage 的硬上限。截断保留原文，不能当作完整产物。

GPT Audio 固定首轮也读完整录音并检查十二个维度，输出自己的细节产物：逐字稿、带原话的声音线索、解释、不确定性、实际检查维度、限制。它不支持原生 Structured Outputs，只用明确的最终 JSON prompt 和本地结构校验，不发送 response_format 强制参数。要求当前响应完成分析，“稍后听一下”不算完成。三份声音观察来自 Google、Qwen、OpenAI；Whisper 与 GPT 同属 OpenAI，四次采集不说成四家独立听审。

可请求目标词、预期/听到的读音及音素解释，听不清则留空或给出合理候选。这些是解释，不是已验证测量；不得按拼写推断误音，不把口音、正常弱读及停顿自动判错，不推断背稿、心理、人格或疾病。不要求供应商没有返回的 F0 曲线、音素概率、校准置信度或 IELTS 分数。时间可选：模型估计记 model-estimate-unverified，Whisper 记 asr-unverified；不能互相覆盖或把边界合法检查当作人工对齐。模型自述访问/覆盖只能作线索，不能独自证明音频已被完整正确处理。

所有 OpenRouter 推理和运行中的余额核对在 Cloudflare 后端；本机不直接请求其音频推理接口。模型名称、实际端点与参数均保留，不把本机地区错误当作后端能力失败。

## 3．全部保真保存

每次调用保存固定要求、音频定位/摘要、全部原始返回、解析结果及真实元数据。OpenRouter 保留完整 HTTP 响应体，包含模型正文外的实际字段；Workers AI 保存完整 native 对象，并说明没有 HTTP 外壳。usage、费用、finish reason、状态及真实模型/端点均由后端记录。

结构校验只核对能否读取；错误引用、越界时间、语义不可信及格式不合格仍保留并标记。完整单一 JSON 围栏可形成解析衍生稿，注明 parseMethod，原文不改。截断/格式不合格但有实际模型正文仍可交 Codex 审阅原文，标 return-needs-review，不计作成功声音观察；没有正文的错误包不是学习证据。

索引与自动整合不裁决语义，不以共识摘要或多数票取代全部资料。一次作答可有 manifest、题目快照、原件/副本、固定 contract、四路完整材料、补听计划/返回、核对稿、Codex 笔记、反馈及 resume.md。中间文档自由增加，用于减轻对话记忆成本，不增加无用流程计数。保真只覆盖实际取得的数据，不声称获得供应商内部未返回过程。

## 4．Codex 完整接管与补听

读取全部原始返回、解析资料、题目/来源、历史反馈及独立确认稿。先判断本人实际表达，再以参考答案提供 7.5 方向启发，不逐字对照观点，不机械要求章节词汇。建立可回读工作转写，原始各稿不动；对重要分歧记录来源、暂定判断及影响。只有分歧确实影响反馈时才请本人核对，不强制每次重校全部转写。校对稿保留版本，不覆盖模型稿。

审阅流利度/连贯性、词汇、语法与发音，区分已有依据、待核对声音观察及无法判断。模型一致、自报信心或低分不是独立听审；Codex 不能从文字补造声音。接受诊断前先检查语言学前提：目标词是否确有该音素、预期重音/词尾是否正确、可接受变体是否被误判。违反前提的解释拒绝作为诊断，但原文保留。不同补听相反意见不平均消解，保留为分歧。

Qwen 可以在分析任意阶段按需要多次补听，没有固定次数配额。先留下具体目标、模型、范围及所提供上下文，完整保存每次请求与返回。独立补听不带其他结论；若提供候选/校对稿，注明条件化，不计作独立首轮证据。同一模型多次调用不是多份独立共识。

允许全录音或保留原声起点的未改速片段，片段只回答其可支持范围。专项用紧凑 detailSchema，不重复要求完整十二维产物。当前云专项队列复用完整 WAV；片段须先实现私有片段保存及原声关系校验再接入，不把本机路径当作已上传。GPT 或未来其他有价值模型也可以增加专项，增量模型不被限制只能进入专项。

先在中间文档充分分析，再给读者优势、优先改进、具体例证、练法与重答建议；完整分析保留展开，不把所有问题同时压给读者。只有覆盖及依据足够时才给教学 band 估计，不称官方分数；声音依据不足不报完整口语 band。回听位置注明来源，未经核准估计不冒充精确跳转。回写独立练习库及 PWA，反馈与重答各有索引，中断留下具体下一步。

## 5．额度、异常与代偿

四路为正常默认，单路服务异常不丢弃已取得资料。额度池分为 OpenRouter 整体钱包、Cloudflare Whisper、腾讯；不同模型/厂商/池分别记录。本阶段不为了缺钱扩大账户池，未来渠道只留接口。

遇到 HTTP 402 或确认钱包/key 额度不足，停止新增收费调用。保留已有材料和未知计费状态；取消北京次日恢复及每小时轮询，等待本人充值后明确要求继续。按 BALANCES.md 末尾核对并提醒，余额无法确认不按零处理，缺少必要声音依据的反馈不能标为最终完成。其他无语音依赖工作继续。

腾讯不足且 OpenRouter 可用时，用 Qwen 多次补充定性声音观察；这不产生腾讯音素分值、校准重音或精确边界。OpenRouter 同时不足则按上述挂起。Whisper 失效时保留其他原声模型转写与观察，明确缺失 ASR 时间，不造假时间。

服务/地区/格式/能力错误完整保存，不盲重试。只允许实际验证的备用通路自动代偿；便宜、HTTP 200 或 Schema 合格本身不证明教学质量。Gemini 2.5 Flash Lite 及本轮若干候选存在改词/虚假纠错，保持排除，见研究报告。正常端点故障转移也必须满足参数。

已完成路不因另一路失败重跑。请求先登记，完整返回先存私有文件，崩溃后恢复文件/状态；未知是否收费标 outcome_unknown，核对后再决定补调，不宣称跨供应商 exactly-once。新专项产生新 job，复用原声和成功返回，也保留旧失败/未知调用，不能借新建任务绕过待查状态。task_id 与 route_id 分开，允许同一模型新目标重复调用；相同计划重复提交不重复付费。后续补全追加反馈版本，原答卷不动。

## 6．腾讯与 Whisper 的额外能力

腾讯自由说不加入常规四路：既有全录音复测识别未改善。句子专项已返回音素，由 `scripts/speaking-assess-sentence.mjs` 保存全部包、音素和原声起点；只使用本人实际原话，不用范文，也不自动把全文切成很多调用。接口用模式/参考/参数控制，不接受通用分析 prompt。

单词模式 0 与纠错模式 4 已接入 `scripts/speaking-assess-word.mjs`，可开启 F_P2L 字母映射、F_IPA 音标输出。纠错模式实际返回参考/识别音素及非默认重音。rec_mode=1 只发送一个二进制包，不能沿用流式分片。连续语音裁词会受切点/相邻词影响；越界时间保留但不形成定位，默认 false 或低分不直接定误读。各模式评分量纲不同，不混算，也不直接换算 IELTS。指定发音/多音词留开发接口，先核对词典读音再实现。腾讯密钥不进浏览器；正式云端化还须接 WebSocket adapter。

Whisper 原生 avg_logprob、compression_ratio、no_speech_prob 是识别统计，VTT/词时间帮助回听，不是音素质量。改变 beam、历史文本条件或提示须新调用单独保存；保留真实重复，不靠清洗提高表面转写正确率。

原生 iPhone 朗读独立，不给日课增加 TTS 或发布门槛。

## 测试与当前证据

测试用独立资源与忽略目录，不写正式 attempt、题目、反馈库，不标 VIX、不发日课、不自动推 PWA。原声及全部返回不进公开 Git；结束后删除测试 Worker、临时存储、触发器及密钥副本。检验目标是完整原声、实际要求、完整返回与 Codex 接管真实可用，不增加无关形式任务。

本轮增量模型与真实费用见 `research/openrouter-speech-evidence-2026-10-04.md`，历史三路试验保留原日期与旧方案。能力来源：[OpenRouter 音频](https://openrouter.ai/docs/guides/overview/multimodal/audio)、[Structured Outputs](https://openrouter.ai/docs/guides/features/structured-outputs)、[GPT Audio](https://developers.openai.com/api/docs/models/gpt-audio)、[Whisper](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/)、[腾讯单词纠错](https://cloud.tencent.com/document/product/1774/107390)。

## 任务末尾额度更新

执行本协议所涉及的日课、推送、练习建设、批改、声音分析或测试工作时，最后按 `BALANCES.md` 查询各方额度，携带核对时间、核实状态与任务用量估算，发布更新到余额页并提示低额度。页面显示上一次任务的记录，浏览时不实时查询。不自动付款，不安排余额不足后的跨日轮询/重试；已有材料与未知计费保护继续有效。
