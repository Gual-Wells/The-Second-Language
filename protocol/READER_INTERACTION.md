# 阅读器交互与状态协议

围绕 iPhone 17 标准版建设，保持既有 2008 蓝灰高光界面。用户视觉和实际操作结果是验收标准。此协议不改变选词、休息状态、雅思范围、声音路由与永久存储规则。

## 正文

常态保留标题、日期、七日条、三部分标签、紧凑译文与高光控件、状态条。答疑在顶栏快捷按钮组持续可访问；红点代表未读回复，会话按日期与摘要辨认版本。打开即清除红点并将当时全部会话回复标为已读，仍使用打开前的未读边界定位，详见下文。

双击阅读区的非英文句子区域进入／退出纯净模式，隐藏阅读外围导航，保留正文、字体、译文与高光选择。切换前后按正文锚点补偿滚动，保持文本在屏幕的绝对坐标，不额外将锚点夹入新视口。只有首尾两段因原生滚动范围无法补偿时允许自然偏移；这两段是连续区域，不限于恰好顶到顶部或底部。不加悬浮退出按钮、不使用全屏 API。单击延迟约 300 ms 等待第二击；原始手势先恢复声音上下文。第二／三部分英文句子内部的双击保留给句中词答疑，不切换纯净模式；句内空白和标点双击无动作。拖动、输入与音频控件不进入纯净模式。试卷与答疑不使用此手势。

长按约 650 ms 第一部分各级带音标词汇标题，直接申请该词汇的详细解析；长按第二／三部分英文句子直接申请整句详细解析。双击第二／三部分句中的英文词，直接申请该处词汇实际使用的全部用法解析。以原句、部分、句序号、对应词条及同形词出现序号定位，后台绑定固定章节全文与完整会话。不打开弹窗，不替用户填写或覆盖手工问题草稿，只提示提交状态。单一手势不得同时发音、跳转与提交；用法高光的单击跳转仍保留。

手指移动超过 10 px、开始滚动、切换章节／部分、离开前台或指针取消，均取消尚未完成的长按及待处理单击。长按目标禁用原生选字菜单；其余正文保持选字能力。只允许已登录的正式固定版本章节提交；离线提示联网，不悄悄排入收费任务。重复手势短时间去重；网络结果未确认时，显式重试同一问题使用原请求编号，依靠后台幂等避免重复入队。真实答疑仍使用已有 Codex 服务和任务末尾额度协议。

词条索引、第一部分例句按钮、第二部分主词标题和范文用法定位均采用稳定帧跳转：旧页面保持可见，右下角显示“正在跳转…”，目标字体和布局稳定后直接揭示目标静态位置，不做跨页滚动动画。跳转取消、打开弹窗或切换章节时清理提示与旧页覆盖。普通部分标签继续保留各自阅读位置。

章节测试紧接章节标题同行靠下对齐，取消主词数量及空白状态徽标；第三部分标题至正文间保持紧凑。

切换译文／高光以当前可见句子为锚点，不只恢复旧 scrollTop。读后记录入口由章节测试取代，历史学习反馈与笔记不删除。测试答案按独立申请编号保存本机草稿，提交成功只清理该次草稿。

点读范围固定，词汇点读因用户认定质量不可靠已正式取消。第一部分标题、音标及释义均不发音；标题长按答疑保留。第二部分主词标题单击返回第一部分对应主词标题，例句整句播放；第三部分整句播放。译文、杂文及正文补充不发音；高光开启时单击先跳转，不同时生成声音。标题胶囊只显示“点读”并说明句子规则，没有模式切换。双击／长按先取消待处理单击。已有收费音频及原始音素身份保留，但不进入新的词汇点读或预下载清单。

## 章节册

点击原日期导航打开章节册；目录／日历在同一弹窗切换，不新增 iPhone 顶栏快捷按钮。目录覆盖全部已发布正式章节，最新在前，按月份分组；标题、编号、日期与副标题本机筛选。每章只有一张可点按的标题条，保留编号、日期、副标题和方向标识，不再提供三部分导航按钮。目录、当前章入口、日历均从第一部分章首打开；阅读器原部分标签、七日条与前后章导航的续读能力保留。临时页不入册，仍按生命周期管理。

章节计数与编号的显示单位统一为“章”，历史 `number` 中的“课”仅在渲染时转换，不改正文、元数据原件或 digest。后续新章元数据 `number` 也使用“第 N 章”。内部日课工作流名称与选词协议不变。目录使用已有 `/api/chapters` 索引；不下载整册全文，不生成或批量下载音频，不增加索引数据库副本。

## 设置与答疑

设置分阅读、学习安排、服务与账户；编辑在同窗返回。余额／安装说明只打开一个模态窗口，关闭返回设置。编辑草稿不能被前后台或联网刷新覆盖；显式保存成功只清理对应字段。已有音频自动下载为默认开启的单一本机开关，不自动合成。

余额仅显示上次任务记录，任务选择筛选完整学习流程估算，不查询账户。未核实不当零。断网优先重新连接，不能引导重新登记通行密钥。

答疑发送绑定章节、摘要、幂等身份与当时文本。发送期间允许继续写下一问；成功只清理仍匹配提交文本的草稿，不清空后来输入或别的章节。每个用户问题与其 `replyTo` 答复形成一组，按提问顺序排列；回复无论何时抵达，都只插入对应问题下方。安全排版不执行模型 HTML、脚本或远程资源。轮询不把正在阅读旧回复的人强制拉到底部。

打开答疑使用 `/api/questions/open` 的一次数据库事务：读取当前未读快照，选定目标会话，再将全部现有回复标记已读。当前章有未读时优先当前章，否则进入有未读的历史会话；都没有时保持当前章。按提问顺序定位第一条包含未读答复的问题，而非按答复抵达顺序定位。该问题上方显示临时“未读消息”分隔线；此次打开内轮询或切换会话保留对应边界，关闭后清除，下次打开重新计算。事务以后抵达的回复仍是新未读，不能被这次确认吞掉。入口即时清红点，丢弃此前尚在途的未读汇总响应；网络失败保留错误提示并恢复真实未读状态。加载期间不能切换目标或提交，但输入草稿保留。

## 雅思

书架、新申请、题目检索分层；仅完整／微缩两种四科申请。书架每套只有一个入口，从听力初始位置打开，不附科目快捷导航；题目检索仍直达目标题。进入试卷后保留固定标题、科目标签、当前控制与提交入口，卷面独立滚动。科目顺序听读写说；写作两个 Task、口语三个 Part。同 Part 多题用上一题／下一题定位，不挤满标签。目录从起点打开不清空答卷、原声草稿或已有计时。原后端题量、题型、揭示和计分规则持续适用。

切换保留答案与位置；正在录音时结束并保存草稿，已开始的听力记录实际中断。阅读文章／题目各存位置；写作两个 Task 共用同一截止时间，重新打开与“继续当前计时”不重置。Part 2 计时独立于播放器，开始录音不停止。

所有文字作答按题目保存本机草稿；提交只更新该题，不重建其他答案。原声上传期间禁止重录与替换文件，成功只删除提交身份匹配的 IndexedDB 草稿。关闭／切换保留原声；已提交文件永久保存。

参考答案及原文仍由服务器控制和记录辅助条件，收起只改变显示；按钮与显示状态一致。听读来源在解析开放后作为复习导航，写作／口语来源在提交或揭示后开放，避免未记录辅助。参考答案不是绝对评分模板；文字补充不冒称原声发音分析。

## 验证与发布

`scripts/check-reader-position.mjs` 验证四种正文状态下首尾边界及绝对坐标、稳定帧跳转与标题布局；`scripts/check-maintenance-ui.mjs` 验证打开清红点、旧响应竞态、问题定位与临时分隔线。`scripts/check-reader-ui.mjs` 验证手势、草稿、历史回复、并发输入、四科题量、跨题保持、计时与上传锁定，所有接口隔离。后端权限、隐藏答案、不可变提交和计分继续运行现有闭环检查。目视检查常态／纯净阅读、设置、答疑、听读写说和缩短视口。

静态 URL、模块、图标与 Service Worker 同版，新增模块加入预缓存。模拟视口与假麦克风不能替代真机触摸、键盘和后台行为验收。发布后核验同源 JSON API 和私有认证，任务末尾按 BALANCES 更新真实额度。

## 章节音频设置（2026-10-09）

设置 → 音频配置沿用本设置弹层的前进/返回语义：下一章一次性保存无二次确认；已有章节先报价，再明确确认不可撤销。每项旁显示人民币估算，确认前不合成。预下载仍只下载已有原件，不能把下载开关改成自动收费生成。详情见 AUDIO_CONFIGURATION.md。
