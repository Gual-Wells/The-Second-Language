## 正文

2026-10-30读后修订：单正文按iPhone实际媒体样式收紧留白，正文外内边距6px、用法水平6px；同一用法的解释与英文以约6px间距及字体区分，例前不画横线或另加框，保留用法间浅分界。译文用低对比雾面蓝灰底与不等长合成印迹遮蔽，不模糊真实中文字、不加闪动或提示字；显隐保持同宽同高，最小44px点击目标，原复制／无障碍／身份隔离保护不变。常态和纯净模式使用同一正文几何。

新正文使用`FORMAT:usage-context-v1`，按主词与具体用法连续阅读，不使用空第二／三部分占位。主词下集中词源，各USE按CONTENT的词形／音标／词性／快释、一次完整解释、英文及整块译文组织，不再例后补讲；每个真实语义用法取优1–5份语境，多份须有不同的实际收益，3份不是默认配额。共享仅自然允许，不主动追求；自然共享仍在对应USE旁呈现相同context，读者无需到远处找例证。结构与身份以ANNOTATIONS为准。

每份context可含多句、多段英文及说话者标签；只在句子上保留实际承载的USE身份。正文撤去逐份类型／来源／标题／导语层，已有参考窗口与后台证据仍可核对，不新增抓取或轮询。去掉displayContext显示前核必要事实与指代，确有依赖则修正文英中语境，不删掉历史时间、辖区或归因后冒充现行通则。关闭参考窗口后保留阅读位置。

每份context只有一个完整中文译文块，可保留段落，不逐句配译。译文始终占位并默认马赛克隐藏，点击显示、再次点击隐藏，切换保持该块高度。隐藏文本不进入复制结果或屏幕阅读器名称；显示后可选择复制，选择文字时不误触隐藏。状态按已认证用户、不可变章节digest与稳定context身份保存；不同用户、内容版本或context互不继承，自然复用同一context的各处及同用户标签页同步。缺少稳定用户身份时只保留当次内存状态；本机存储失败时仍可反复切换，不回退到浏览器共享偏好键。

常态保留标题、日期、七日条、词条索引与状态条，取消标记用法控件、高光及其跳转分支；迁移旧highlight偏好时不清理译文／字号等其他偏好。新单正文显示“词汇与语境”，译文各自在语境下切换，无可视显隐提示或原生title教程；历史章保留三部分标签及其原译文控件。答疑在顶栏快捷按钮组持续可访问；红点代表未读回复，会话按日期与摘要辨认版本。打开即清除红点并将当时全部会话回复标为已读，仍使用打开前的未读边界定位，详见下文。

双击阅读区的非英文句子区域进入／退出纯净模式，隐藏外围导航，保留正文、字体及译文状态。词条索引复用吸顶工具条。纯净模式默认只显示正文，单击空白后临时显示当前工具条与底部阅读进度三秒；历史章同时显示原部分标签，操作这些控件重新计时。复用原控件与事件，使用固定浮层而非占位或复制按钮，显示／隐藏不改变正文绝对位置。句内点读／答疑、译文按钮、拖动和选字不得误触临时层或模式切换。切换前后按正文锚点补偿滚动，保持文本在屏幕的绝对坐标，不额外将锚点夹入新视口。只有首尾两段因原生滚动范围无法补偿时允许自然偏移；这两段是连续区域，不限于恰好顶到顶部或底部。不加悬浮退出按钮、不使用全屏 API。单击延迟约 300 ms 等待第二击；原始手势先恢复声音上下文。语境英文句子内部的双击保留给句中词答疑，不切换纯净模式；句内空白和标点双击无动作。历史第二／三部分保留同一规则。拖动、输入与音频控件不进入纯净模式。试卷与答疑不使用此手势。

长按约650 ms主词标题或带音标的用法标题，直接申请该词汇的详细解析；长按语境英文句子直接申请整句详细解析，双击句中的英文词申请该处词汇实际使用的全部用法解析。新正文以context、全章唯一句ID、USE、对应词条及同形词出现序号准确定位，手势问题附完整英文语境，不夹带隐藏译文；后台仍绑定固定digest的整章与完整会话。历史章继续使用原部分、句序、篇名及句标记定位。手势不打开弹窗，不替用户填写或覆盖手工问题草稿，只提示提交状态。单一手势不得同时发音、跳转与提交；取消标记用法后，句子单击只走正常点读；USE身份仍供答疑和质检定位。

手指移动超过 10 px、开始滚动、切换章节／部分、离开前台或指针取消，均取消尚未完成的长按及待处理单击。长按目标禁用原生选字菜单；其余正文保持选字能力。只允许已登录的正式固定版本章节提交；离线提示联网，不悄悄排入收费任务。重复手势短时间去重；网络结果未确认时，显式重试同一问题使用原请求编号，依靠后台幂等避免重复入队。真实答疑仍使用已有 Codex 服务和任务末尾额度协议。

词条索引、语境用法回看和质检原文定位均采用稳定帧跳转：旧页面保持可见，右下角显示“正在跳转…”，目标字体和布局稳定后直接揭示目标静态位置，不做跨页滚动动画；新正文的目标避开吸顶工具条。跳转取消、打开弹窗或切换章节时清理提示与旧页覆盖。新正文保存其阅读位置；历史第一部分例句按钮、第二部分主词标题及范文用法定位继续同一机制，部分标签保留各自阅读位置。

新版各用法标题按“词形＋对应音标＋词性＋本用法快释”顺序，词性同音标字号和低调字色；快释在最后一个词性后用13px普通中文同行排印，窄屏自然换行，不单独起段或框；下方只显示一份正常段落完整解释。旧章标题解析继续兼容，快捷答疑仍有完整身份。新标题与定位共用parseTeachingHeading；先发布v61快释兼容壳再发新稿，旧JS未更新的请求得到明确重开提示而非解析崩溃。章节请求声明x-reader-layout:3；后台对无快释现代标题要求能力至少2，对有快释标题要求至少3，响应Vary按能力隔离离线缓存；原固定digest不换内容。

v61是能力3首次上线的历史壳版本，后续壳升级不改变正文合同。客户端与Worker共用reader-capability.js中的能力声明；发布入口根据正文实际标题计算所需能力，在任何证据上传／stage／commit前只读核验线上Worker声明、实际HTML及其引用的关键阅读模块、样式和Service Worker字节。部署脚本复用此核验；HTML已新而关联JS仍旧也不放行，等待同版传播。publisher精确正文回读仍必要，但其豁免旧壳保护，不能单独作为普通读者可读的证明。此门槛只证明版本衔接，不代替真实页面的视觉、手势或教材语义验收。

章节测试紧接章节标题同行靠下对齐，取消主词数量及空白状态徽标；正文标题至内容间保持紧凑。

新格式逐context译文等高切换，历史章原译文控件仍按可见句子保持位置。读后记录入口由章节测试取代，历史学习反馈与笔记不删除。新正文末尾及历史第三部分末尾保留章节测试入口。测试答案按独立申请编号保存本机草稿，提交成功只清理该次草稿。

点读范围固定，词汇点读因用户认定质量不可靠已正式取消。新格式只对语境中的完整英文句子开放，点读文本不含说话者标签；词条／用法标题、音标、词源、释义、译文、来源说明和其他补充不发音，标题长按答疑保留。旧highlight偏好不再截获单击，顶栏为无交互Logo，没有点读模式按钮。双击／长按先取消待处理单击。已有收费音频及原始音素身份保留，但不进入新的词汇点读或预下载清单。

冻结历史章继续原三部分渲染、逐句译文和已存位置。第二部分主词标题单击返回第一部分对应主词标题，例句及第三部分英文句子整句播放。第三部分文章组在原工具条索引位置提供“篇目”，按标题筛选并静态定位；现实参考同窗可按篇目筛选实际来源。SENTENCE全章唯一，跨篇答疑附篇名及准确句标记，关闭窗口后保留阅读位置。新格式不据此创建额外部分、复制旧正文或重建历史音频。

## 章节册

点击原日期导航打开章节册；目录／日历在同一弹窗切换，不新增 iPhone 顶栏快捷按钮。目录覆盖全部已发布正式章节，最新在前，按月份分组；标题、编号、日期与副标题本机筛选。每章只有一张可点按的标题条，保留编号、日期、副标题和方向标识，不再提供三部分导航按钮。目录、当前章入口、日历均从正文章首打开；历史章从第一部分章首打开。七日条与前后章导航的续读能力、历史章原部分标签继续保留。临时页不入册，仍按生命周期管理。

章节计数与编号的显示单位统一为“章”，历史 `number` 中的“课”仅在渲染时转换，不改正文、元数据原件或 digest。后续新章元数据 `number` 也使用“第 N 章”。内部日课工作流名称与选词协议不变。目录使用已有 `/api/chapters` 索引；不下载整册全文，不生成或批量下载音频，不增加索引数据库副本。

## 设置与答疑

设置分阅读、学习安排、服务与账户；编辑在同窗返回。余额／安装说明只打开一个模态窗口，关闭返回设置。编辑草稿不能被前后台或联网刷新覆盖；显式保存成功只清理对应字段。已有音频自动下载为默认开启的单一本机开关，不自动合成。

余额仅显示上次任务记录，任务选择筛选完整学习流程估算，不查询账户。未核实不当零。断网优先重新连接，不能引导重新登记通行密钥。

答疑发送绑定章节、摘要、幂等身份与当时文本。发送期间允许继续写下一问；成功只清理仍匹配提交文本的草稿，不清空后来输入或别的章节。每个用户问题与其 `replyTo` 答复形成一组，按提问顺序排列；回复无论何时抵达，都只插入对应问题下方。安全排版不执行模型 HTML、脚本或远程资源。轮询不把正在阅读旧回复的人强制拉到底部。

打开答疑使用 `/api/questions/open` 的一次数据库事务：读取当前未读快照，选定目标会话，再将全部现有回复标记已读。当前章有未读时优先当前章，否则进入有未读的历史会话；都没有时保持当前章。按提问顺序定位第一条包含未读答复的问题，而非按答复抵达顺序定位。该问题上方显示临时“未读消息”分隔线；此次打开内轮询或切换会话保留对应边界，关闭后清除，下次打开重新计算。事务以后抵达的回复仍是新未读，不能被这次确认吞掉。入口即时清红点，丢弃此前尚在途的未读汇总响应；网络失败保留错误提示并恢复真实未读状态。加载期间不能切换目标或提交，但输入草稿保留。

## 雅思

书架、新申请、题目检索分层；仅完整／微缩两种四科申请。书架每套只有一个入口，从听力初始位置打开，不附科目快捷导航；题目检索仍直达目标题。进入试卷后保留固定标题、科目标签、当前控制与提交入口，卷面独立滚动。科目顺序听读写说；写作两个 Task、口语三个 Part。同 Part 多题用上一题／下一题定位，不挤满标签。目录从起点打开不清空答卷、原声草稿或已有计时。原后端题量、题型、揭示和计分规则持续适用。

切换保留答案与位置；正在录音时结束并保存草稿，已开始的听力记录实际中断。阅读文章／题目各存位置；写作两个 Task 共用同一截止时间，重新打开与“继续当前计时”不重置。Part 2 计时独立于播放器，开始录音不停止。

所有文字作答按题目保存本机草稿；提交只更新该题，不重建其他答案。原声上传期间禁止重录与替换文件，成功只删除提交身份匹配的 IndexedDB 草稿。关闭／切换保留原声；已提交文件永久保存。

参考答案及原文仍由服务器控制和记录辅助条件，收起只改变显示；按钮与显示状态一致。听读来源在解析开放后作为复习导航，写作／口语来源在提交或揭示后开放，避免未记录辅助。参考答案不是绝对评分模板；文字补充不冒称原声发音分析。

## 验证与发布

`scripts/check-context-reader.mjs` 用新格式自写夹具与真实浏览器检查单正文、整块译文默认遮蔽／复制和无障碍边界、等高切换、用户与digest隔离、自然共享与多标签同步、无身份／存储失败回退、整句点读、完整语境答疑、纯净坐标、USE与context定位、来源及新旧音频范围，并读取冻结历史章回归。截图与结果存入`.cache/context-reader/`；402×874及320×620为Chromium触控模拟视口，不是实体iPhone Safari测试。

`scripts/check-reader-position.mjs`继续验证历史章首尾边界及绝对坐标、稳定帧跳转与标题布局；`scripts/check-maintenance-ui.mjs` 验证打开清红点、旧响应竞态、问题定位与临时分隔线。`scripts/check-reader-ui.mjs` 验证手势、草稿、历史回复、并发输入、四科题量、跨题保持、计时与上传锁定。上述UI检查所有接口隔离，不启动收费TTS或模型任务。后端权限、隐藏答案、不可变提交和计分继续运行现有闭环检查。目视检查常态／纯净阅读、设置、答疑、听读写说和缩短视口。

静态 URL、模块、图标与 Service Worker 同版，新增模块加入预缓存。模拟视口与假麦克风不能替代真机触摸、键盘和后台行为验收。发布后核验同源 JSON API 和私有认证，任务末尾按 BALANCES 更新真实额度。
