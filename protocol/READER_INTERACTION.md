# 阅读器交互与状态协议

围绕 iPhone 17 标准版建设，保持既有 2008 蓝灰高光界面。用户视觉和实际操作结果是验收标准。此协议不改变选词、休息状态、雅思范围、声音路由与永久存储规则。

## 正文

常态保留标题、日期、七日条、三部分标签、紧凑译文与高光控件、状态条。答疑在顶栏快捷按钮组持续可访问；红点代表未读回复，默认当前章，窗口内可直接进入历史新回复，按日期与摘要辨认版本。

双击阅读区进入／退出纯净模式，隐藏阅读外围导航，保留正文、字体、译文与高光选择及当前文本位置。不加悬浮退出按钮、不使用全屏 API。单击原行为延迟约 300 ms 等待第二击；原始手势先恢复声音上下文。拖动、长按选字、输入与音频控件不进入纯净模式。试卷与答疑不使用此手势。

切换译文／高光以当前可见句子为锚点，不只恢复旧 scrollTop。未提交读后笔记和难度按章节摘要保存本机草稿，正式提交后清理，不冒充完成记录。

点读范围固定，不再切换任意点词／点句模式。第一部分只响应已登记的各级词汇标题，以各标题对应音标发音；主词标题采用首个同形义项读音，具体义项保留自己的读音。释义、标签、正文补充、短语说明、列表中的英文不产生发音请求。第二部分主词标题全面对应第一部分，复用同一读音；例句只能整句播放。第三部分只能整句播放。译文、非词汇标题、跳转控件和选中文字保持原交互。用法高光开启时仍优先跳转，不同时生成声音。

标题旁原胶囊保留位置和视觉，改为“点读”说明入口，点击提示当前规则；不再显示可切换的按下状态。双击仍进入／退出纯净模式而不发起单击生成。标题不支持的音标须提示核对，不能降级为无音标的自动猜读。

## 章节册

点击原日期导航打开章节册；目录／日历在同一弹窗切换，不新增 iPhone 顶栏快捷按钮。目录覆盖全部已发布正式章节，最新在前，按月份分组；标题、编号、日期与副标题本机筛选。标题和“继续阅读”恢复该章上次部分与位置，三个目录按钮分别打开对应部分并恢复各自位置。临时页不入册，仍按生命周期管理。

章节计数与编号的显示单位统一为“章”，历史 `number` 中的“课”仅在渲染时转换，不改正文、元数据原件或 digest。后续新章元数据 `number` 也使用“第 N 章”。内部日课工作流名称与选词协议不变。目录使用已有 `/api/chapters` 索引；不下载整册全文，不生成或批量下载音频，不增加索引数据库副本。

## 设置与答疑

设置分阅读、学习安排、服务与账户；编辑在同窗返回。余额／安装说明只打开一个模态窗口，关闭返回设置。编辑草稿不能被前后台或联网刷新覆盖；显式保存成功只清理对应字段。已有音频自动下载为默认开启的单一本机开关，不自动合成。

余额仅显示上次任务记录，任务选择筛选完整学习流程估算，不查询账户。未核实不当零。断网优先重新连接，不能引导重新登记通行密钥。

答疑发送绑定章节、摘要、幂等身份与当时文本。发送期间允许继续写下一问；成功只清理仍匹配提交文本的草稿，不清空后来输入或别的章节。回复安全排版，不执行模型 HTML、脚本或远程资源。轮询不把正在阅读旧回复的人强制拉到底部。

## 雅思

书架、新申请、题目检索分层；仅完整／微缩两种四科申请。固定标题、科目标签、当前控制与提交入口，卷面独立滚动。科目顺序听读写说；写作两个 Task、口语三个 Part。同 Part 多题用上一题／下一题定位，不挤满标签。原后端题量、题型、揭示和计分规则持续适用。

切换保留答案与位置；正在录音时结束并保存草稿，已开始的听力记录实际中断。阅读文章／题目各存位置；写作两个 Task 共用同一截止时间，重新打开与“继续当前计时”不重置。Part 2 计时独立于播放器，开始录音不停止。

所有文字作答按题目保存本机草稿；提交只更新该题，不重建其他答案。原声上传期间禁止重录与替换文件，成功只删除提交身份匹配的 IndexedDB 草稿。关闭／切换保留原声；已提交文件永久保存。

参考答案及原文仍由服务器控制和记录辅助条件，收起只改变显示；按钮与显示状态一致。听读来源在解析开放后作为复习导航，写作／口语来源在提交或揭示后开放，避免未记录辅助。参考答案不是绝对评分模板；文字补充不冒称原声发音分析。

## 验证与发布

`scripts/check-reader-ui.mjs` 验证手势、草稿、历史回复、并发输入、四科题量、跨题保持、计时与上传锁定，所有接口隔离。后端权限、隐藏答案、不可变提交和计分继续运行现有闭环检查。目视检查常态／纯净阅读、设置、答疑、听读写说和缩短视口。

静态 URL、模块、图标与 Service Worker 同版，新增模块加入预缓存。模拟视口与假麦克风不能替代真机触摸、键盘和后台行为验收。发布后核验同源 JSON API 和私有认证，任务末尾按 BALANCES 更新真实额度。

## 章节音频设置（2026-10-09）

设置 → 音频配置沿用本设置弹层的前进/返回语义：下一章一次性保存无二次确认；已有章节先报价，再明确确认不可撤销。每项旁显示人民币估算，确认前不合成。预下载仍只下载已有原件，不能把下载开关改成自动收费生成。详情见 AUDIO_CONFIGURATION.md。
