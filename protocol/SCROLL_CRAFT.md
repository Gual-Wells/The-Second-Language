# 纪念卷轴制作工艺规程

版本 `craft-1.0`，2026-10-22。[CHARTER](CHARTER.md)管产品身份、创作、资格、任务和封存；本规程管制材、排印、装配及返修。实际制作必须同时读取，不能只读总协议的提要。规程可供执行者使用，不表示自动创作／颁发服务已上线。

## 0. 依据与分工

纸张依据[第一章完整制作重建](../research/project-scroll-redesign-2026-10-21/first-chapter-process-reconstruction.md)及其[固定来源索引](../research/project-scroll-redesign-2026-10-21/first-chapter-source-index.json)，不是复印第一章成品。扣具采用v17结构、v19多道做旧，雾染采用v20。历史实现统一可从 `17acb31e0241180b5f0c19b463492cc6ef756c80` 恢复；现有项目成品在 `web/labs/project-beginning/`。第五章纸张、退稿项目作品及v40循环拟音不具有母版资格。

分三类工作：按件创作主题、文图、构图与材料使用史；离线制备图像、排字、墨印与烘焙；运行时加载冻结资产、卷展、解扣、受光、雾与拟音。复用已验基座，不逐章重建皮扣或求解器；开卷不再生图、抽版式或生成声音。

执行前检查仓库原件、成熟资源、许可、工具实际能力和可得输出。陌生高难度转换或连续失败，先查官方方法与可运行实例，再选复用、适配或定制，不先拼粗糙替代物；日常小改无需重做市场调查。

## 2. 无字皮膜：裁制、使用史与年龄

### 2.1 先定整张形体

1. 根据文图构图定纸幅比例、书写区、主要折藏方向与暴露端，不先把字塞入固定格。
2. 选择已有许可母材的恰当派生或新无字图像。图像工具不画正文、姓名、日期、哈希或正式印文。
3. 外轮廓以长段近直手裁边为主体，夹少量不对称斜角、短裂、浅缺；保留厚薄和轻微不直。不要四角统一圆角、等距波浪、整圈焦边或破布式撕烂。
4. 先看无字整张与透明剪影。成对缺口让纸像拼条、损伤碰穿字区、剪影比例拉扁时回母材修，不留到排字遮盖。

### 2.2 分层设计年龄

| 工序 | 位置、形态与输出 |
| --- | --- |
| 材料底色 | 皮膜自身色差、局部薄透、细密纹理；大面仍可书写。基色／必要alpha，不是织物、均匀黄纸或满页云斑。 |
| 制作与卷藏痕 | 主要折线／卷向、浅褶、厚薄变化进基色；需要空间起伏的另立几何，不自动把每条线挤出。 |
| 暴露与接触 | 手持角、卷外端、长期接触处的暗润、浅擦与不等磨耗，基色／roughness协调，不全纸均匀变脏。 |
| 旧水损与沉积 | 少量不对称浅潮线、折谷沉积、宽窄变化的接触边界，以基色为主。排除菌落、黑霉和活跃腐败，也不把所有潮线擦净。 |
| 磨薄与边损 | 暴露端／折端／旧短裂附近少量不等磨损，保留大段完整边。alpha／局部色泽，切口明确，不靠扩散毛糊掩盖结构。 |
| 多尺度协调 | 整张色差、局部年龄网络、近看细纹分别可读。远看庄重完整，近看有层次，不用锐化／高光假装细节。 |

这是新件可执行配方，不声称第一章最终跑过同名滤镜栈。第一章采用v4→v6图像编辑分支；v2程序年龄层、v5过净稿和v6霉变候选没有一起叠进成品。v19复杂节点烘焙属于扣具，不能补写成第一章纸张历史。

每轮明确改什么、保留什么，保存输入和结果；变差可以回较好母材。去霉不等于去全部旧痕，去污不等于新纸。改主折线／裁边同步检查背面、alpha和构图，不能单镜像／换色后称独立制作。正背可共用连续剪影，但不冒称已模拟真实羊皮毛面／肉面。

输出：无字原件、实际尺寸／有效alpha范围、正背派生、提示词或处理脚本、采用／拒绝分支及许可。保留足够续作资料，不保存含凭据整段聊天。

## 3. 微表面、卷膜与显示保真

### 3.1 通道职责

- 基色／正文颜色用sRGB；normal、roughness、relief是线性数据。旧水斑、纸色、图中阴影不能直接转成整张高度。
- 第一章用Poly Haven Leather Red 02的OpenGL normal和roughness作为低幅羊皮微结构艺术近似，不是本纸实测扫描。两图SHA在重建报告；后来的纸图高频导出法不能冒称原工艺。
- 经验证起点：RepeatWrapping、repeat `[1.4,2.1]`、normalScale `.035`、roughness表达式 `.88+.10*g`、印压bumpScale `.0045`。它们是该基座调校值，不是不可更改的材料物理常数。
- 第一章原折痕主要画在基色；新几何折痕须与本件图像对应，说明是新增适配，不照搬第五章专用折线。
- v17/v19异步准备会覆盖采样和normalScale。必须等完整 `environmentReady` 链结束后核**实际材质**，不能只看构造器。对应保护见 `project-beginning/scroll-object.js`。

### 3.2 连续卷展

复用Paperlab卷绕和v6连续GPU膜。残余卷曲、非均匀起伏及新折痕的同一位移表达式同时用于顶点、有限差分切线／法线和深度；最后一圈分支不能突然丢掉位移。改纸幅、厚度、裁边、折线后重看闭卷、最后一圈和反向，不只看完全展开图。

主要折藏可进几何，扫描微纹理只影响受光，章印压痕独立。三者不互相顶替；不冒称有限元、全体碰撞或制造公差验证。

### 3.3 实装保真

保留v6为近正面器物的实用取舍：NoToneMapping／曝光1、纸sheen0／specularIntensity0／envMapIntensity `.07`、中性灯、低反光；正面最大45%原diffuse色保护，卷曲部仍有动态明暗。不能再套ACES或抬高高光洗掉年龄，也不改成无光照平面。

分别保存：①冻结PNG与解码纸面一致，证明身份／未重排；②**实际GPU器物**与相同UV纸面区域对照，证明受光后旧痕、折谷、擦伤、字迹仍可读。整页／细看、静态／卷曲都看；统计只诊断漂白／压平，不代替审美。源纸好而实装洗白回显示，源纸本来过净回第2节。

## 4. 真字、旧墨与藏记

完整英中、纪念对象与构图先成立，再用实际加载的Aboensis等已验字库排印。缺字库不得回退现代系统字。纸幅、字号、分行、边画、留白和归属一起设计，不把缩字、不相交或固定第一章布局当成功。

先清晰字芯，后少量固定种子干笔／微擦，只作用墨层。第一章v12参考2048×2868、2300个约 `.6×.8px`／alpha `.075`擦点；不是每页必须达到的数量。不能整层blur或磨成残字。

默认小长方 `The Second Language / In remembrance`，复用v12印模身份，不恢复现代徽标或大权威章。实际顺序：

1. **印模mask**：略不完美的稳定母版、少量固定划痕；不每次随机变章。v12约8.5px轮廓，裁784×360，以小比例入纸。
2. **吃墨**：v10 `transferMasks()`的宽接触场、细粒、少量局部缺墨／针孔调节密度；不靠统一透明度。
3. **浸晕**：halo先减原模再叠芯，避免回填缺墨。第一章起点blur2px／alpha `.25`。
4. **余墨**：独立肩墨mask允许超出章纹；不能只沿线扩一圈。已有原件可复用，尺寸、角度、密度适合本件，不逐章重生同一污滴。
5. **纸上墨色**：深褐近黑，`opticalInk()`密度合成保留底纸；墨深于纸色。不是不透明贴纸，不冒称铁胆墨化学模拟。
6. **压痕relief**：中性128背景，按**印模**浅压，不依缺墨挖坑。v12参考 `#303030`／alpha `.52`／blur `.7px`。
7. **实际shader**：normalMap可能盖掉bump；在 `normal_fragment_maps` 后真正叠 `perturbNormalArb`，保留扫描normal。只赋bumpMap不算完成。

输出独立mask／sealInk／relief与合成纸面。字迹、模具、接触、压力分别可恢复；不让图像工具画假字再模糊。

## 5. 皮扣结构与离线多道做旧

### 5.1 结构／适配

采用v17连续两端皮带、折返包边／铆件、框、完整针轴及孔。活动带从右框杆后进入、左前方伸出遮包边；针左段被带遮、右端穿孔搭右框。不改闭环＋前扣装饰，不吞带尾，不把框嵌皮。

适配先核纸卷外径、带宽厚度与间隙，必要从原生材料路径派生环周长，再整件等比缩放。参考30mm环径半径／18mm带宽／2.5mm厚度，禁1.8倍单轴拉伸。金属刚性、皮革沿材料坐标变形。松孔→越针→退带→归置针→移离→开纸，收起反向；不淡出、放大贴片或轴向滑脱冒充解扣。

### 5.2 皮革工序

按v19原生节点分区制材：①旧皮艺术基色＋许可扫描粒面；②实际折返／扣框轨迹／尾端的手持暗润和压磨；③不连续边缘／带尾粒面磨穿、暖褐纤维；④屈折区细裂和短横压褶；⑤克制手工刻带／尾端小纹随磨耗减淡；⑥粒面、切面、孔壁分别取样，联合color、normal、roughness。

不能全带同强度鳄鱼纹、新带光滑感、随机黑斑迷彩、全物同粗糙度或在孔壁铺外表压纹。旧扣贴图只提供材质／风格，不连同旧结构／孔洞／动作错误回退。

### 5.3 铜件工序

①旧铜基色＋扫描微坑；②浅压平／修锉痕；③沿曲面简单刻槽；④遮蔽／接触部稳定棕暗氧化、少量低饱和灰绿；⑤凸部及常触处局部磨亮。color、metalness、roughness和normal对应同一使用史，不像皮革，也不大块金黑迷彩。

烘焙leather／bronze各color、ORM、normal共六图，保存Blend节点工场、PNG母版、源纹理／许可。WebP核真实RIFF/WEBP头、解码、色彩空间及误差，不只改PNG后缀。color设sRGB、数据图不设，沿材料长度UV使用，释放替换纹理。微痕不改变针框接触／工作截面，真正缺损几何属另次结构修改。

## 6. 雾、预热与拟音

### 6.1 雾和运行维护

采用Pavel压力／平流核心及v20驱动：缓慢转向宽域＋独立节奏狭长活动区，少量局部细卷；浓度生灭与速度分开。不固定左→右、双端喷气、全场等量小涡或静态死雾。真实纸缘／皮扣投影速度耦合与有限值／屏外／跳变保护一起保留，不能修自然感时关掉互动。

参考输入限幅±.32、65ms滤波、纸缘5.8／皮扣4.6、涡量补偿.38；96速度网格／512染料，雾30Hz留余量最多追赶三步，纸面按屏幕刷新。是二维场景艺术调校，不是三维空气力学。改动先同种子同时间比较开／关耦合，再看真实开合、反向、静置；两段随机天气不同不证明互动。

环境／模型／最终材质就绪→上传纹理／编译→隐藏实绘关键姿态→开放首次动作。失败给释读／重试；隐藏暂停、排除后台时长，恢复重置输入；不为雾降纸面清晰度。

### 6.2 声音工序

历史v41执行在[拟音重制](../research/scroll-craft-and-audio-2026-10-22/README.md)，用户随后明确否定其节奏和音质。最新[社区资源与动作音轨研究](../research/scroll-foley-study-2026-10-22/README.md)为独立待听审候选，尚未替换正式声音。声音须有独立来源、选段、事件表和实际播放证据，不能在排印结束临时拼附件：

1. 分真实行为：皮革弯折／退带／滑离、针框轻触、纸卷开合；没有弹簧锁、落地／放书动作不配这些声。
2. 查可再分发的干净录音，保存真实格式、作者／许可／字节SHA及选段。干竹叶等替代拟音如实著录，不冒称古羊皮实录。
3. 保留自然包络、瞬态和衰减，只做必要低频处理、短淡入出、有上限增益；不同正向表演用于开合，不倒放，不按同一RMS把所有材质抬一样响。
4. 有限表演绑定真实纸进度／材料路径，停手、离场、反向分别收音；轻触按明确接触位置触发并防抖，不因切phase敲一遍。
   不用全局进度线性映射录音offset后反复seek／漂移重启；先用实际动作分轨编排。文件起点不等于声音接触点，选段须标起音／主瞬态锚点，再与画面联合校准。
5. **不再沿用被否定v40**：短段tanh压缩、十余倍增益、持续循环和随速度变调。标“实录”、无报错、非零能量都不能证明好听。
6. 隔离拟音审材质／动作，再与器物开合和音乐合听。技术检查只判解码、无削波、时序、停手安静、释放、首次解锁；没有听审能力时如实写待试听，不宣称听感通过。

声音默认开，无声音设置。真实动作解锁WebAudio，后台暂停／退出清理，晚到解码不得复活。音乐独立续播，不每次开卷重启；不加夸张风声／幻想重击掩盖不真实。

## 7. 返修、证据与冻结

依次看无字母材→真字平面→多通道材质→GPU受光／卷曲→皮扣动作→雾／声音→整件iPhone视口。源纸过净回母材，源纸好而实装漂白回显示，章印贴片感回墨／压痕，不默认重生整页。

保存足够有用的整页／细看、闭卷／关键运动／展开、GPU保真和必要接触／声音证据。改声音不重建未变机构或原稿；改纸幅／折痕则重看卷绕／适配。Chromium模拟不冒称真机Safari；波形、哈希和脚本不冒称艺术或听感认可。

冻结 `front/back/ink/relief/sealInk/sealMask`、原稿、方案、字库、原生工艺／核验过的固定引用、运行器／参数、许可、阶段结论和字节清单。内容SHA与纸面SHA分开；时间／身份不随重开或改呈现器刷新；成功原件永久复用。发布核依赖闭包，母版仅在缓存而未回读归档时如实报告。

外部网页只保留必要可见著录，脚本／嵌入令牌不入Git。秘密不进协议或研究。新增数据、依赖、缓存、原生工程、日志实际存D。未接线步骤留可恢复工单，不能用“已协议化”冒称后台已自动生产。
