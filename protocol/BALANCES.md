# 每项任务的额度收尾

适用于本项目所有日课、临时测试与复习、雅思练习建设、各科答卷分析、口语原声采集与补听、声音实验以及工程发布。它是原任务的最后一步，不产生新的学习内容任务，不更改休息安排、章节选择或 VIX 标签。

## 查询、携带、发布

任务结束时执行 `node scripts/check-balances.mjs`。脚本从本机受忽略凭据读取腾讯服务额度状态、从 Cloudflare 账户统计读取当天 Workers AI 免费 Neurons 余量；发送归一化报告到 Cloudflare 后端，后端查询 OpenRouter 的共享钱包与本 key 的剩余额度。OpenRouter 的查询和推理都由 Cloudflare 发出。浏览器永远不持有这些密钥。

报告包括各池、核对时间、币种/计量单位、核实状态及对应任务估算。归一化数据写入后端余额记录，作为本次发布携带的服务状态，随任务交付更新到 PWA“设置 → 查看余额与用量”。余额与正文分开更新；不为余额变化重写章节正文或摘要，不误称二者是同一数据库事务。余额页只读最近一次任务记录，打开页面不实时查询。当天统计、旧记录及估算要清楚区分。未核实不等于零；腾讯现金不等于口语套餐次数，套餐未核实必须明说；统计可能延迟。

`publish-chapter.mjs`、`publish-temporary.mjs`、`delete-temporary.mjs`、`practice-job.mjs` 的发布与反馈完成命令、`speaking-practice.mjs complete`、`practice-audio.mjs synthesize/verify` 和腾讯评测脚本已接入末尾核对。日课与雅思定时入口在实际模型工作结束后也执行核对，覆盖失败退出。无工作队列的空转不额外查询。手工实验、补听、其他工程或发布任务由执行 Codex 在本任务末尾调用同一命令；测试只更新真实额度记录，不写伪造正式教学数据。

若内容已成功发布但额度查询失败，不撤回内容、不重复生成收费资源；记录核对失败并明确报告。之后的任务收尾再次核对即可。程序读数不包含 Codex/ChatGPT 订阅额度，此处没有可靠接口，不虚构数字。

## 提前提醒

OpenRouter 可用余额取共享钱包和本 key 限额的较低值；低于 $5 提醒，作为下一次原声分析的宽裕预留。Whisper 按账户每日 10000 免费 Neurons 管理，查询当日已用量并显示剩余；预计任务消耗同样以 Neurons 表示，不能混作充值钱包余额。余量低于 2000 时只提醒当天免费额度不足及北京时间每天 08:00 自动刷新，不设计 Whisper 充值或付费升级。腾讯按有效口语套餐剩余计费次数管理，少于 100 次提醒补充套餐；同时显示套餐有效期，现金只作补充，不因现金为零提醒套餐耗尽。阈值属于项目提醒规则，不是服务商封禁条件。

腾讯 9.9 元套餐为 10000 计费次、一年有效的预付费包，没有每日自动刷新。`DescribePidOrders` 是官方控制台的套餐查询操作，但目前验证的公开 API 版本尚未取得套餐数据，返回 InvalidAction；不能把一次失败上升为“腾讯没有接口”或“密钥没有权限”。当前余额页显示套餐余量待核实及已查现金，套餐未知时不发不足通知。待核对控制台实际查询方式后接入真实次数与到期时间，不用本机请求数估算整个账户的剩余额度。

任务末尾返回提醒文本，并为已开启提醒的设备排入额度通知；连续低余额不反复推送，恢复后再次降低可重新提醒。没有推送授权时仍可在余额页查看。旧记录和未核实结果不显示为当前已确认告急。任务估算按当前声音策略、调用范围和字符/时长假设给出，不承诺实际账单金额；新增模型要同步估算和来源。

## 不安排额度不足的跨日任务

取消原先“北京次日恢复、未充值每小时轮询”的额度调度。余额不足停止新增收费调用；已有录音、成稿、成功返回、音频缓存及未知收费状态保留原样，不新增跨日保存/自动续作工程。

用户充值后明确要求继续时，Codex 可使用 `node scripts/speaking-practice.mjs retry-credit JOB_ID` 重新入队已有口语任务；它只允许等待余额的任务，复用成功调用，只重试明确 HTTP 402 的未成功调用。点读由用户充值后重新点按触发；练习声音由明确执行的生成命令触发。已缓存声音始终直接播放。不要把时间到了、打开余额页或账户变有钱视为续作授权。未知收费结果仍禁止自动重复付费。额度不足不发布缺音频组件的整套雅思练习，也不阻断无语音依赖的文字日课。

- 腾讯：[新版计费](https://cloud.tencent.com/document/product/1774/107342)，后付费 ¥0.005 / 计费次；段落与自由说每 20 词计一次。[余额 API](https://cloud.tencent.com/document/product/555/20253) 的金额单位为分。
- OpenRouter 原声多路分析预留为预算估算，含 Gemini、Qwen、GPT Audio 的音频输入与长 JSON 输出，不以 Whisper 的费用替代多路成本；补听按实际次数另计。真实返回的 usage.cost 保持在口语材料中。
