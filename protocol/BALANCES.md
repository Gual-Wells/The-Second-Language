# 每项任务的额度收尾

适用于本项目所有日课、临时测试与复习、雅思练习建设、各科答卷分析、口语原声采集与补听、声音实验以及工程发布。它是原任务的最后一步，不产生新的学习内容任务，不更改休息安排、章节选择或 VIX 标签。

## 查询、携带、发布

任务结束时执行 `node scripts/check-balances.mjs`。脚本从本机受忽略凭据读取腾讯服务额度状态、从 Cloudflare 账户统计读取当天 Workers AI 免费 Neurons 余量；发送归一化报告到 Cloudflare 后端，后端查询 OpenRouter 的共享钱包与本 key 的剩余额度。OpenRouter 的查询和推理都由 Cloudflare 发出。浏览器永远不持有这些密钥。

报告包括各池、核对时间、币种/计量单位、核实状态及对应任务估算。归一化数据写入后端余额记录，作为本次发布携带的服务状态，随任务交付更新到 PWA“设置 → 查看余额与用量”。余额与正文分开更新；不为余额变化重写章节正文或摘要，不误称二者是同一数据库事务。余额页只读最近一次任务记录，打开页面不实时查询。当天统计、旧记录及估算要清楚区分。未核实不等于零；腾讯现金不等于口语套餐次数，套餐未核实必须明说；统计可能延迟。

`publish-chapter.mjs`、`publish-temporary.mjs`、`delete-temporary.mjs`、`practice-job.mjs` 的发布与反馈完成命令、`speaking-practice.mjs complete`、`practice-audio.mjs synthesize/verify` 和腾讯评测脚本已接入末尾核对。日课与雅思定时入口在实际模型工作结束后也执行核对，覆盖失败退出。无工作队列的空转不额外查询。手工实验、补听、其他工程或发布任务由执行 Codex 在本任务末尾调用同一命令；测试只更新真实额度记录，不写伪造正式教学数据。

若内容已成功发布但额度查询失败，不撤回内容、不重复生成收费资源；记录核对失败并明确报告。之后的任务收尾再次核对即可。程序读数不包含 Codex/ChatGPT 订阅额度，此处没有可靠接口，不虚构数字。

## 提前提醒

额度估算单位是用户申请的一次完整学习流程，包含内容建设、首次需要的声音资源、核对、一次作答及反馈；不是脚本执行一次、API 调用一次或 Codex 一轮操作。Codex 订阅不计入这些额度。日课、日课加完整雅思、日课加微缩雅思、独立完整/微缩雅思、复习、内容测试、音色试听及口语测试各有范围。雅思新申请仅两个全科规格，完整四科或听读微缩而写作/口语完整。

权威可执行估算在 `task-quotas.mjs`，后端直接导入。2026-10-25起日课默认不提前生成音频；新单正文仅主动选配contexts整句，旧格式可选two/three，二者不隐式转付费授权。规划范围仍为0–75000字符（50主词按原40词范围比例上调的规划预留，不是正文上限、新格式实测账单或保证足额；不选配或已成功复用可为零；不是词汇音频）。已有定稿按实际文本报价，下一章看实际样本并注明不确定。完整/微缩听力20000–40000 / 15000–30000字符及27–33 / 16–20分钟Whisper全量核对；考官提问1500–5000字符。口语以本轮九次实际账单和既有完整原声账单校准，GPT/Gemini按每份时长插值，Qwen按含思考的实际扣款范围，不以max_tokens作为预计输出。默认研究情景为14/18/22份、净回答7/8.5/10分钟，加考官和一分钟准备后总计11/13/14分钟；这些不是官方题数、强制出题数量或录音上限。真实时长列表可交给speakingCostFor重新估算。经验波动余量之外，预留每份一次Qwen补充、四次专题Qwen、一次两分钟GPT补听；不自动触发，不限制必要取证。腾讯专项0–20计费次，不固定送全部回答评测。具体证据、模型单价、条件与限制见 `../research/ielts-model-consumption-2026-10-05.md`。

声音缓存复用不重复消耗。阅读、写作及文字教学接管无这些外部音频模型费用。Kokoro 按 $0.62/M 字符路线规划；实际供应商回退可能改变单价，需要按返回账单修正，不能声称保证最低价。估算仍不是整套实测账单或严格费用上限；首次正式全流程结束后再校准。价格变化、额外重答、更多问题或大型自定义测试要更新范围，不把各方不同计价单位混算、不限制模型完成教学。

分别以每个服务在这些用户任务中的最大预计消耗上端计算三倍预留。仅当该服务剩余额度严格小于此预留时，显示/推送低额度提醒；等于门槛不提醒。不按钱包现金或各 API 零散操作另设告警条件。当前默认最大流程为日课加完整雅思：OpenRouter 规划上端约 $1.3861、Whisper 2144.98 Neurons、腾讯 20 计费次；预留分别约 $4.1584、6434.94 Neurons、60 计费次。数据与公式同源，不在多个位置手写门槛。

Whisper 为每天 10000 免费 Neurons，按同单位估算/提醒，北京时间 08:00 刷新，不设计充值。OpenRouter 共享钱包与 key 限额取较低值。腾讯现金只作补充，不用于套餐告警。未知余额不当零，过期记录不冒充当前核实。

腾讯 9.9 元包为 10000 计费次、有效一年。2026-10-05 用户控制台截图显示已用 22，剩余 9978，有效日期至 2027-10-02；截图没有完整时刻，不补造精确到期时刻。公开调用再次尝试 DescribePidOrders 返回 InvalidAction / ActionNotFound，未接通官方实时查询；不能称无此接口或权限不足。以截图核对值建立后端基准，后续三种腾讯执行脚本统一经过 `scripts/lib/tencent-quota-ledger.mjs`，调用前写本机不可丢失的身份记录，完整成功按模式计算单位，收尾同步到 `service_quota_usage`；服务端按基准之后的记录累积扣减。单词/句子模式每份完成评测一次；自由说依据服务返回的词数每 20 词向上取整。音频分片、原始消息、重读已保存的返回和重复上传同一记录不再计次；用户明确重新评测的新实际调用有新身份并计次。

未完整确认的调用为待核对，不擅自作为已扣费或未扣费；返回不足以算词数也保留待核对。页面以“估算”区分官方查询值，并显示未决数量。查询失败仍保留基准与已有用量，不覆盖成零或随现金刷新假装核实了套餐。当前代算仅覆盖本项目脚本；账户中外部调用、其他项目、控制台试验、补购与退款需以新控制台数据或未来可用查询重新校准。截图历史已用的 22 不重复扣减。不通过反复真实评测验证计数。基准到期则估算可用套餐为零，新的有效包需要重新核对；不擅自按现金开启后付费。
任务末尾返回提醒文本，并为已开启提醒的设备排入额度通知；连续低余额不反复推送，恢复后再次降低可重新提醒。没有推送授权时仍可在余额页查看。旧记录和未核实结果不显示为当前已确认告急。任务估算按当前声音策略、调用范围和字符/时长假设给出，不承诺实际账单金额；新增模型要同步估算和来源。

## 不安排额度不足的跨日任务

取消原先“北京次日恢复、未充值每小时轮询”的额度调度。余额不足停止新增收费调用；已有录音、成稿、成功返回、音频缓存及未知收费状态保留原样，不新增跨日保存/自动续作工程。

用户充值后明确要求继续时，Codex 可使用 `node scripts/speaking-practice.mjs retry-credit JOB_ID` 重新入队已有口语任务；它只允许等待余额的任务，复用成功调用，只重试明确 HTTP 402 的未成功调用。点读由用户充值后重新点按触发；练习声音由明确执行的生成命令触发。已缓存声音始终直接播放。不要把时间到了、打开余额页或账户变有钱视为续作授权。未知收费结果仍禁止自动重复付费。额度不足不发布缺音频组件的整套雅思练习，也不阻断无语音依赖的文字日课。

## OpenAI 共用 API（2026-10-30）

增加OpenAI独立池，仅接同系列问答与课表识别，不替代章节Codex生产。由本机配置读取已核发放/剩余/有效日证据及实际Responses usage；输入、输出、缓存token和响应次数以原返回登记，不把发放减本机消耗当官方余额，也不拿Codex额度混算。没有可靠剩余接口时显示未核实，不由估计发放推送告急。共用usage记录只有项目、任务身份和用量，不含密钥、问题、截图或答案。任务末尾更新，页面不实时查厂商。

## 云端用量分来源（2026-10-31）

0025将用量完整快照按local-shared、cloud-language、cloud-algorithm、cloud-schedule、cloud-ledger分别保存；查看时汇总，不能让本机下一次上报覆盖云用量。旧余额快照中的本机usage仅作尚未建立新来源记录时的兼容值，不再重复加一次。本机只累积已收到的Responses usage回执，不据此声称覆盖全部账户调用或所有未知计费。

各项目只读自身runtime累计表，通过窄Service Binding RPC上报`inputTokens/outputTokens/cachedInputTokens/responses/unknownCalls/inProgressCalls/revision/checkedAt`，无task、provider请求/响应ID、问题、答案、原始流、章节或图片。本项目内部函数写cloud-language；`AlgorithmUsage/ScheduleUsage/LedgerUsage.report(snapshot)`各硬编码其来源，不接受客户端source，不提供HTTP或读取接口。系列时钟只可调用`LanguageAPIExecutor.run()`，不持跨项目数据库绑定。Cloudflare入口在`worker/src/entry.js`，普通`index.js`保留可独立测试的原fetch/提醒Cron。能力划分依[Cloudflare命名RPC入口](https://developers.cloudflare.com/workers/runtime-apis/bindings/service-bindings/rpc/)实现。

接收端验证完整字段、非负安全整数、缓存token范围、核对时间和累计版本；以CAS按单来源覆盖、幂等接收与拒绝乱序。相同回执revision可在更新checkedAt下改变unknown/inProgress，不得无新回执改变token总量。累计token/回执不能倒退。一次已知incomplete/failed只要有真实usage仍计入累计，未知计费单独显示，不当作零费用或已确认扣款。

本机目录读取失败或任一usage原件损坏时，collector报告usageComplete=false、不发送部分值或零；后端保留本机旧快照并标记本次更新未完成。云RPC仅更新该source用量快照，不能写余额、发放或额度核实字段。余额是否为旧证据只看creditCheckedAt，用量使用usageCheckedAt及各来源时间；云端不断上报不能把旧钱包余额刷成刚核实。无记录不填零，失败保留旧值。已有余额页仍只读本项目保存的记录，不实时查询厂商或其他项目私文。
