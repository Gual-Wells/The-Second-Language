# VIX 与实事来源协同：兼容边界及接线设计

状态：2026-10-23，**来源池和离线工具已准备；生产接线未启用**。本文件的范围保护立即适用；下文工作流是以后建设的设计，不能因读到本文件就自动重做日课或启动采集。现行日课继续从 [DAILY_RUN](DAILY_RUN.md) 开始。

目标：让英语学习更常接触值得理解的现实世界、当前变化和生活运用，保留现有全词族、全义项教学产品。不是建立新闻门户、缩短课程、制造新闻热度榜或改变考试/认证系统。

## 2. 来源池的权威范围

资源在 [resources/current-affairs](../resources/current-affairs/README.md)。它只回答“去哪里找什么材料、该发布者处于什么角色、本次入口观察到了什么”，不能凭入库就认定报道事实或自动授权转载。来源数量、检索命中数、媒体排名均不代替判断。

- 编辑媒体：区分新闻、评论、商业内容和转载；大牌、公共广播也不自动等于无立场。
- 官方机构与服务方：适合核实“它发布/修改/声称了什么”；不能把商业宣传或政府、机构自述直接当独立成效证明。
- 科研：追溯具体论文/数据，读清方法、样本、预印本、限制、更正及新闻稿的夸大；官网不代替科学结论核验。
- 统计、服务与技术：区分观察期、发布时间、更新、执行日期、地区、平台、版本及草案/稳定状态。不能把全球指标换成当地事实，把计划换成已上线。
- 倡议组织：保留归因、方法和观点；多个同源转载不制造独立共识。

访问受阻可换同一事实的另一可靠原始出处或换材料；不能用搜索摘要冒充读过正文。实际需要多少材料由事实与创作需要决定，不设一刀切的来源数量、固定地区配比或必须多新。仍有效的生活材料可与新事件并用。

## 3. 以后如何协同选词与创作

这是新运行接线方案，不回写现有 selection、教材讲解、历史章节或已颁发资产。

1. **先恢复运行身份。** 按DAILY_RUN领取，检查休息、已发布及已有工作资料。已经冻结或标注的40词继续原组；实事只可辅助既有文章，不能刷新选词。新运行记录VIX、教材、学习目标等输入版本。
2. **双向探索。** 在未最终选定时，既从VIX候选观察有学习价值的词/真实词族，也从来源池寻找用户值得此刻理解的事情。让两者共同启发材料和候选，不要求报道原文包含全部40词、全部义项或同一主题。原有词表倾向和用户反馈继续参与。
3. **确定选词，保留完整教学目标。** 40主词及实际纳入词族确定后，按DAILY_RUN原时点标注；完整教材与课程建设继续原流程，不要求全部教学成稿后才标注。现实材料不是缩减集合的筛子：不能因义项多、跨度大而自动降权或换成便于写新闻的词。内容建设中发现疑点沿原纠错和续作处理。
4. **用稳定集合设计第三部分。** 全义集合稳定后，形成简短创作意图。现实内容提供信息、问题和推进；较难共处的意义可以通过合适的历史背景、专业说明、对照或明确虚构的情境承载，也可重构全文。不要求每句话都有新闻依据，不要求所有义项都对应同一事件；不篡改真实事实来强行用词。
5. **区分事实与创作。** 报道中的可核实事实保持归因及范围；原创人物、对话、解释性比喻不伪装成真实采访、专家表态或用户亲历。未知之处保持未知。无需给每句加“虚构”标签，但整体框架和具体事实不能误导。
6. **沿现有审阅与发布。** 先审教材去向，再审逐义真用、英文整体及连续中文译文；结构脚本不代替语义。增加的事实核对服务于正文正确，不增加强制生活作业、题量、打卡或日课等待用户选分类的步骤。

现实反馈的验收问题是：“读完后，我对世界中的哪件事情理解得更清楚，或多能理解/表达什么？”这个目标与全量教学一起验收，不能以链接、日期、标签、新闻数量或文章变短冒充实现。

## 4. 工程接线空间与成本控制

当前没有新生产代码。未来优先复用现有 `selection.md`、`article-plan.md`、`continuity.md` 和 `resume.md` 留必要材料，不先造新数据库、全站爬虫、向量库、常驻监控或每义项审计台账。

采用某篇材料时，留下可恢复的**原文URL/发布者、标题、实际读取日期、发布/发生/适用时间（能确认的部分）、自己概述的关键事实与限制、事实与创作边界**。无需穷尽每个字段；日期未知不补造。需要冻结事实输入时保存简短来源包及内容摘要，不用只指向随时会变的主页。版权/访问条件允许的必要短摘录才保存，不批量复制新闻全文或图片。版本摘要用于确定本次输入，不证明事实正确或时效永久。

大的工作材料及允许保存的来源快照实际在D盘，永久文件继续按STORAGE归档；生产D1只在确需接线时保留小状态与引用。来源池为静态Git资产，不自动占D1/KV。今后公开参考入口的样式、字段及归档需跟实际实现一起确认，本轮不改章节schema。

取材按需路由，扩大材料不足的主题或地区时再检索大型目录；不逐日全扫描几百站，不用目录中数万来源制造请求和模型费用。付费墙不触发新订阅或账户购买；没有合适新消息时可用仍有效的生活资料，不以“必须实时”停课。原计费未知结果、余额与生命周期保护继续有效。
