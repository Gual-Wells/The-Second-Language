# 章节答疑

前端入口及异步草稿遵循 [READER_INTERACTION.md](READER_INTERACTION.md)：顶栏入口持续可见；历史新回复按日期与版本直接定位；发送成功不能清空等待期间输入的下一问；模型文本安全排版，不执行返回的 HTML。

正文标题上方的章节答疑入口提交问题；默认携带当前章的固定摘要身份。服务端从该身份读取整章原文，全部会话交给本机 Codex。历史会话保留原版，不随改章漂移。答疑不参与 VIX 标记、日课推荐或雅思申请。

独立 Windows 任务每分钟由普通脚本检查队列，没有问题不启动模型，也不查询收费服务余额。有待办时隔离工作目录 `work/questions/<message-id>/` 保存全文、会话与回答；Codex gpt-6-sol/high 只读分析，不读取发布凭据，不采用用户配置中的外部连接器。确定性脚本负责续租、幂等回推；已生成答案优先回推复用，不再次生成。

本机通过 OPERATIONS.md 所述无窗口启动器运行，不创建可见 PowerShell 控制台，不为每次空检查发通知。异常写入私有日志并保留非零计划任务退出码；实际答疑失败仍由产品展示重新处理入口。个人全访问配置不改变这个只读教学进程的隔离范围。

整章与完整会话直接随本次分析输入提供，不依赖模型额外读取文件。生产 CLI 使用 HTTPS 传输，避免本机 WebSocket 连接失败的长时间回退；按 JSON schema 提取回答，过程资料与结构化结果在任务目录保留。

同章问题按提交顺序处理，后续问题包含已完成回答。中断或失败保留所有资料并显示重新处理按钮，不安排额度不足后的跨日自动尝试。每个完成或失败的实际分析任务末尾按 BALANCES.md 更新额度；纯队列检查不消耗模型额度。

回复永久保存，前台检查新回复并显示红点；打开会话后按已收到回答序号确认已读。离线草稿保存在当前设备，重复提交用固定请求编号去重。账户退出清空页面会话；重新登录后可再读取。设备需开机、Windows 用户会话可运行、网络及 Codex 登录有效；云端排队不等于本机始终在线。
