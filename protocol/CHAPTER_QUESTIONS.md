# 章节答疑

前端入口及异步草稿遵循 [READER_INTERACTION.md](READER_INTERACTION.md)：顶栏入口持续可见；历史新回复按日期与版本直接定位；发送成功不能清空等待期间输入的下一问；模型文本安全排版，不执行返回的 HTML。

正文标题上方的章节答疑入口提交问题；默认携带当前章的固定摘要身份。服务端从该身份读取整章原文，全部会话交给独立本机 API 运行器。历史会话保留原版，不随改章漂移。答疑不参与 VIX 标记、日课推荐或雅思申请。

新默认 `usage-context-v1`／`authentic-context-v1` 是单正文。词汇标题长按、英文语境整句长按、句中词双击均走原答疑通路。句子问题携准确原句、词条标题、contextId、SENTENCE身份及实际USE引用，并附所在英文语境；句中词额外指明同形词第几处，要求解析所有实际使用的相关用法，不附会未使用义项。每份语境的中文是一个整块译文，不虚构逐句中文配对。无需新增上下文数据库或在请求中再复制整章：后端已按固定digest核对并提供全文与完整会话。无弹窗、无自动改章、无额外确认；仅提交状态提示，回复继续通过既有入口及红点读取。

已冻结的旧三部分版本继续按原格式定位：第一部分词汇标题长按、第二／三部分整句长按及句中词双击；多篇第三部分保留篇目标题、全章句序及SENTENCE标记。共享语境不把同一文本的所有出现当成同一词义；新旧格式都交付完整固定版本，不截成某个词族、不重指到新版。旧章封存及任务资格仍按CURRENT_AFFAIRS，不因保留旧格式读取而恢复封存任务。

快捷提交不复用手工编辑器状态，不改变未发送草稿或当前会话选择。并发提交同焦点受保护，成功后短时间去重；失败或失联保留该问题的幂等编号，仅用户重做同一手势才重试。切章前发起的请求保持原章身份，不受后来页面切换影响。不对临时页、演示、未登录或离线情况自动提交。

独立 Windows 任务每分钟由普通脚本检查队列，没有问题不启动模型，也不查询收费服务余额。有待办时隔离工作目录 `work/questions/<message-id>/` 保存全文、会话与回答；问答通过 OpenAI Responses API 的 gpt-6.1-sol／xhigh 分析，使用同系列共用密钥路径而不复制密钥，不读取发布凭据，不采用用户配置中的外部连接器。2026-10-30用户暂调API问答为xhigh；Codex出版及其他任务档位不变。确定性脚本负责续租、幂等回推；已生成答案优先回推复用，不再次生成。

本机通过 OPERATIONS.md 所述无窗口启动器运行，不创建可见 PowerShell 控制台，不为每次空检查发通知。异常写入私有日志并保留非零计划任务退出码；实际答疑失败仍由产品展示重新处理入口。个人全访问配置不改变这个只读教学进程的隔离范围。

整章与完整会话直接随本次分析输入提供，不依赖模型额外读取文件。问答使用 HTTPS Responses API，不提供工具，不发送发布凭据；新客户端以本机已确认密钥调用；按 JSON schema 提取回答，过程资料与结构化结果在任务目录保留。

同章问题按提交顺序处理，后续问题包含已完成回答。中断或失败保留所有资料并显示重新处理按钮，不安排额度不足后的跨日自动尝试。每个完成或失败的实际分析任务末尾按 BALANCES.md 更新额度；纯队列检查不消耗模型额度。

回复永久保存，前台检查新回复并显示红点；打开入口即按同一事务快照确认全部会话当时的回答已读，并保留原未读边界，定位第一条未读问答的问题，显示临时“未读消息”分隔线；事务之后的新回复仍未读。离线草稿保存在当前设备，重复提交用固定请求编号去重。账户退出清空页面会话；重新登录后可再读取。设备需开机、Windows 用户会话可运行、网络及 API 凭据有效；云端排队不等于本机始终在线。

## 配对与共用监测（2026-10-10）
接口显式返回 `replyTo`，前端按提问顺序逐组展示，每条答复插入它所回复的问题下方；不按全部消息到达顺序堆叠。晚到回复保持读者当前消息锚点、未读状态与手工输入。
原答疑领取通路也监测章节测试，按可执行申请时间先后领取。`kind=chapter-test` 走独立出题 schema 与完成接口，不能写成聊天答复。版本全文、工作租约及任务末尾额度/归档保护保持。对应协议 CHAPTER_TESTS.md。

## API 接手问答（2026-10-30）

question-api-worker.mjs仅领取questionsOnly；服务端API_QUESTIONS_ENABLED启用后，旧共享运行器不再领取普通问题，仍处理原章节测试、口答核对和质检。日课、雅思建设、质检与认证出题继续既有Codex流程，不随本次改为API。旧运行器的工作树及既有成功结果保留；固定原件与完整会话一致时可复用旧答案。新任务目录work/questions-api仅保存本任务原件、请求、响应和结果，不入Git。

所有新API调用先落盘不可重复的发送标记，保存原始返回及usage，成功回答先保存后回推；网络中断、服务端5xx或不完整返回不自动重发。明确4xx拒绝只在用户重新处理后允许新的调用，不做SDK重试或跨日续跑。API额度登记发放与已核余额分开；本机token记录不是官方钱包余额。没有任务仅查询自有队列，不调用OpenAI。

2026-10-30故障修复：本机API运行器使用Node 24.14或以上。代理配置在任何请求之前调用Node官方setGlobalProxyFromEnv，重新配置fetch及HTTP/HTTPS代理；仅在进程启动后修改环境变量不足以更新已经初始化的请求分派器。失败只保存安全错误码、阶段和耗时，不记录凭据或原始网络异常。网络结果未知仍停止自动重发；更换档位不绕过发送标记。
