# 章节音频配置

用户决定（2026-10-25）：音频选配默认不生成，取代2026-10-12的默认满配。2026-10-27起新默认 `usage-context-v1`／`authentic-context-v1` 为单正文，选配项目改为 `contexts`：全部明确编码的英文语境完整句，固定 Kokoro Bella。词汇标题、词源、释义、解析散文、来源说明及整块译文不生成。手动点读仍按既有操作生成或复用，下载开关仍只下载已有声音；不影响雅思题音、卷轴音或其他明确申请。

旧冻结三部分正文保持 `two` 例句／`three` 范文完整句范围。保留旧格式读取和原任务身份，不把旧选配静默解释为新语境音频授权；封存旧章仍不能借此恢复新合成。

## 每日日课与一次性调整

- 新正式章节首次 commit 时，只有非空且与该固定正文格式一致的一次性选配，才在D1同一个发布事务中创建该digest的音频申请；默认空选配不入队。独立音频服务在正文发布后处理，文字课程和 VIX 不等待声音，不因音频故障回滚。
- 设置 → 音频配置 → 下一章日课只提供 `contexts`，默认不勾选，可在发布前选择，直接保存，不额外确认。首次发布原子消费该次设置后恢复 `[]`，后续章继续默认不生成。旧存two／three在读取时列为不适用选配，不自动转换；即使新章首发时存在旧值，也不据此创建新格式音频任务。
- 休息、领取运行、临时页及已有章节重发不消费下一章设置，也不重复入队。当前章已经发布后调整仅影响下一新章，不静默追加当前章费用。
- 迁移0021将现有下一章设置恢复为空选配并递增revision；0015保留为历史迁移，不代表现行默认。正在运行的任务不会仅因修改默认而自动中止。

## 已有章节申请与执行

- 已有章节选择项目后，后台读取不可变正文并核对 digest，按该格式返回可选项目：新版contexts，旧三部分two／three；跨格式选择拒绝。创建十分钟有效计划/报价，页面显示范围、预计费用及确认后不能撤销；确认以前不合成，确认以后无撤销接口。同一 quote 重复确认不生成第二项任务。
- 用户在对话中明确要求补齐已有章时，Agent 可按其范围查询、报价并确认，不重复请求相同授权；通过原申请通路留下计划和进度，不绕开生成账本。本次补齐以当前已发布章节版本为准，完成后逐章核对全部合规句子及下载清单。
- `SecondLanguage-AudioPreparation` 用无窗口 BackgroundTask 每分钟检查队列，本机运行且联网时执行。普通 Node 脚本，不调用 Codex 推理；与答疑、日课、归档独立并有单实例互斥。电脑关机时不承诺执行。
- `scripts/audio-worker.mjs` 用发布身份领取任务，经 Cloudflare `/api/practice/pronunciation` 调用既有 Bella 通路；OpenRouter 不由本机直连。队列只有固定版本、状态、游标与计划位置，完整计划及终态记录在 OneDrive。
- 恢复的是处理租约，不是重复付费权。成功音频复用，正在调用等待状态；HTTP 402 等待充值，仅用户点击继续或明确要求恢复时入队，不自动跨日重试。未知计费、明确失败等进入核对，不借新申请绕过原声音账本。
- 用户明确中止当前生成时，运维先保存任务和生成账本，再将该任务置为`needs_review`、撤销claim/lease并注明用户中止。已发出的收费调用允许保存原返回，下一次进度提交因处理权失效停止后续合成；不强杀在途调用、不删除已购音频、不自动恢复该任务。此操作不是给其他已有申请新增无授权撤销入口。
- 每个成功音频关联固定章节 digest。归档服务将已生成句子打包供预下载；原件暂不可用不当作未生成。不批量写 KV，不建设新的音频数据库。
- 原声已进入永久索引或 ready 故障副本后，后续章节关联/排队报错不能降级成功结果或覆盖其计费元数据。真正没有成功原件的未知调用继续暂停；历史误标只能核对原身份、原字节与完整解码后恢复，不借恢复重新合成。

## 单元与复用

`web/audio-plan.js:audioUnits` 按FORMAT分派。新版只提取CONTEXT块中SENTENCE之后的完整英文句，遇整块TRANSLATION即停止提取，CONTEXT_REF不复制句子。旧格式仍只取第二部分EXAMPLE及第三部分SENTENCE后的英文句；其词汇标题与第一部分不发音。去除显示强调语法，不朗读中文、说明、说话者标签或编码。

同一文字、模型、音色、音频格式与声音策略共用既有生成身份；语境／例句共享、跨正文格式和跨章节均可复用，不因新的位置或contextId重复计费。旧重复EXAMPLE仍表示所属用法，不虚构唯一例句编号，不改正式章及摘要。全量提前生成与按需点读使用同一身份，不建设第二套音频原件。

章节请求核对固定原件及完整句子；碎片、杂文、单词请求在进入收费身份前拒绝。现行预下载范围为 `pointAudioPolicy=chapter-sentences-only-v3`；它扩展单正文语境句白名单，不改变付费资产身份。打包与浏览器按固定正文的实际白名单筛选Bella完整句，历史清单也须通过此筛选，不能仅凭旧策略名重新放行词汇。清洗只重建清单及包指针，已付费原件、完整生成记录、旧包及不可变成功关联保留。

历史词汇/音标描述、Misaki 音素转换和旧 hash 继续用于读取历史付费资产；它们不再构成新词汇生成入口，也不作为满配的一部分。旧申请里的词汇单元由执行器跳过，不重新收费。原高光跳义项、长按答疑、非英文区双击纯净模式、切章停止、私有读取与 Range 保持。

## 费用与完成

新版设置标注语境句人民币估算，旧章已有版本按two／three分别报价。已有章节按定稿文本、真实合成输入及已成功缓存计算，共享句联合去重。下一章无定稿时，从最近三章候选中仅使用新格式样本的字符范围估算，明确为样本而非硬上限；无匹配样本显示待定稿，不拿旧P2/P3规模冒充新语境报价。

`audioPrice` 使用当前路线规划区间 $0.62–$0.99 / 百万字符、7 元/美元预算换算，不冒充实时价格或汇率。实际收费与异常核对以提供商结果为准；不购买新套餐、不自动充值、不重复收费。复播和传输不调用 TTS。

任务完成按 BALANCES.md 更新额度与存储用量，排入既有永久归档。音频原件 ready、章节关联及合规清单全部覆盖后才宣称补齐；入队不是完成，待核对不是完成，界面/原声质量的人工验收也不能被计数取代。
