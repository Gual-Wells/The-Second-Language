# 章节音频选配

用户决定（2026-10-09）：设置增加音频配置；选择下一章日课或已有章节，选配第一部分一、二级标题词汇，第二部分各例句，第三部分各句。全部使用 Kokoro Bella。它是既有点读的提前准备，不是连续全文朗读或新的正文部分。

## 申请与执行

- 下一章选配为一次性设置，直接保存，不额外确认；可在新日课发布前修改。休息、领取运行、临时页和已有章节重发不消耗选配。新正式章节首次 commit 时，D1 原子创建固定 digest 的音频申请并复位设置；声音故障不回滚正文或 VIX。
- 已有章节选择项目后，后台读取不可变原件并核对 digest，创建十分钟有效的计划/报价。页面再明确显示范围、预计费用和“确认后不能撤销”。确认以前不合成，确认以后无撤销接口。重复确认同一 quote 不产生第二项任务；修改范围需重新报价。旧版本仍按申请时固定原件执行。
- `SecondLanguage-AudioPreparation` 用无控制台的既有 BackgroundTask 运行器每分钟检查队列；本机运行且联网时检测到即执行，不调用 Codex 推理。它独立于答疑、日课和归档，单实例互斥。不能承诺电脑关机时执行或服务端推送零延迟。
- 队列只保存一行状态、游标和计划位置；完整计划与终态报告在 OneDrive。`scripts/audio-worker.mjs` 使用发布身份从 Cloudflare 领取任务，调用现有 `/api/practice/pronunciation`；OpenRouter 不由本机调用。实际 paid call 身份仍由原发音账本原子领取。
- 运行租约可恢复 orchestration；成功音频复用，正在调用等待状态，不重新支付。HTTP 402 等待充值，仅用户点“充值后继续”或明确要求恢复时入队；不自动跨日重试。未知收费、明确失败或不支持的读音进入需要核对，不能借重新申请绕过原账本重复付费。
- 每项成功音频均关联固定章节 digest；原归档服务打包后供预下载。原件暂时不可用不能视作未生成。不批量写 KV，不再建音频数据库。

## 单元、发音与复用

现行点击范围按 READER_INTERACTION.md：第一部分只读带已登记音标的词汇标题；第二部分标题复用第一部分音标，例句整句；第三部分整句。选配范围仍是第一部分词汇、第二部分例句、第三部分逐句，没有加入解析散文或任意单词。章节请求在后台核对固定原件、完整文字、类别和音素后才允许关联及生成，违规请求不占用调用身份或额度。

章节预下载清单以 `pointAudioPolicy` 记录范围版本，打包前根据固定章节正文筛选 Bella 标题读音及完整句子。清洗重建可变清单与包指针；原始音频、完整生成记录、旧包以及不可变成功/章节关联行均保留。合格旧原件可追加到内容不变的其他章节版本，音素不同不互相冒充。没有合法声音时发布空清单，不能继续沿用旧的杂文包。浏览器对旧缓存清单也执行同一筛选。

共享提取器 `web/audio-plan.js:audioUnits` 从正式三部分标记读取纯英文。一、二级标题去掉中文用法标签、词性说明和音标显示文字；一级词形采用其首个同形二级标题读音，具体二级义项保留自己的读音。第二部分标题在阅读器中读取对应第一部分的一级词形，不另做音频；第二部分的选配只生成例句。

例句取现行 EXAMPLE 后的英文原句，第三部分取 SENTENCE 后英文原句，不念译文或代码。重复 EXAMPLE 仍表示所属用法，不把它冒充唯一例句 ID；本功能以纯文本和合成参数摘要作声音身份，不需要改变正式正文编码。

`audioDescriptor` 对未指定发音保持旧请求结构及旧 hash 完全兼容。指定读音时先将可支持的美式词典 IPA 转为 Misaki/Kokoro 音素，在 input 中使用 `[word](/phonemes/)`；完整转换版本和文字保存在 descriptor.pronunciation，参与 hash。相同文字、音素、模型、音色与策略共用一份原件，跨词义、部分、章节、申请均可复用；同拼写不同读音不能共用。英文句子保持自然上下文处理，不自动给正文每个点词附会音标。

已验证当前 OpenRouter Kokoro 路线执行音素覆盖：同样写 record、分别覆盖 hello 和 goodbye，返回 MP3 经 Whisper 转写分别为 Hello hello / Goodbye goodbye。此对照证明覆盖生效，不等于所有标题均通过严格语音学听审。IPA 有不支持的符号或结构时拒绝此项收费生成，报告核对需求，不静默忽略。

浏览器内存及已下载清单用文字 + 音素区分。旧清单没有 phonemes 时按普通文本点读继续读取；新清单同时保留显示文本、音素和真实生成 ID。点按标题音标使用对应词形与音素发音，不朗读音标符号；原高光跳义项、双击纯净模式、切章停止、私有读取和 Range 继续有效。

## 费用

各项目旁显示人民币估算。已有章节按实际定稿文本、请求中实际输入字符（含音素覆盖语法）、已成功缓存计算；选中项目联合去重，不直接加三个上界。下一章尚无定稿，按最近三章同项目的字符范围估算，明确是近期样本而非硬上限；无样本显示待定稿。复用费用为零，传输/复播不调用 TTS。

`audioPrice` 采用 $0.62–$0.99 / 百万字符作为路线规划范围，人民币用 7 元/美元预算换算，不冒充实时汇率。模型/供应商价格变动、真正账单与额外核对不保证被此范围覆盖，参见研究报告。不新购买套餐，不自动充值，不为同一声音重复收费。任务末尾按 BALANCES.md 查询额度，排入原永久归档服务。
