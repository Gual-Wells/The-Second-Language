# 皮扣结构修正

这是一份独立机构样品，未替换正式卷轴。皮料是有两端的一体带坯，固定端绕左框杆折返并铆接，活动带从右框后穿入、向左前伸出；完整针轴、扣框、铆钉分别建模。皮带已绑定骨架，但完整解扣动作尚未完成。展平只用于检视。

材质资源：

- [Poly Haven / brown_leather](https://polyhaven.com/a/brown_leather)，Rob Tuytel，CC0，2K颜色、粗糙度与OpenGL法线。
- [cgbookcase / Bronze03](https://www.cgbookcase.com/textures/bronze-03)，CC0，作者公开1K材质；高度由Blender标准烘焙生成切线法线。
- [Three.js](https://threejs.org/)，MIT，项目现有r186运行库、GLTFLoader、OrbitControls与RoomEnvironment。
- [Blender](https://www.blender.org/)，本机5.1.2，用于带坯厚度、打孔、弯曲、装配、UV、PBR烘焙和蒙皮。

没有将厂家实物照片作为项目贴图。照片只用于理解针扣机构。可见的表面陈旧程度和美术效果仍待用户检视。

研究和可恢复源：仓库`research/scroll-keeper-physical-2026-10-19/`及`scripts/keeper-physical-build.py`。
