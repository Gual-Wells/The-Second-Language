# 月度动态展厅：第三轮独立研究与样件

## 判断与范围

用户要求研究、实现并真机评价月度动态展厅；纪念日历明确暂缓研究/实现，未来无论动态厅成败都要建设。当前工程只加入 `/labs/monthly-gallery/`，不改正式日课、认证、章节册、雅思、声音路由或旧样件。正式种子/认证/资产生成/申领/演化版本链尚未接入生产，不能把静态样件当作已完成的正式服务。

月厅按 study_date 创建，约三十章容量不是硬上限；每章才创建台座，首次认证唯一币，认证后仍可重测。申领时再决定是否及如何介入环境；相容可不改，种子不锁死最终场景。这些用户决定已优先写入 CERTIFICATION_RESEARCH，历史罐子和 16 题原型明确分开。

## 成熟基础与选型

- Babylon.js 9.30.0：完整成熟浏览器引擎，glTF、PBR、IBL、动画、阴影、粒子、镜头、Glow/LensFlare、HDR/FXAA/Bloom。版本固定、自托管，不运行时依赖 CDN。[官方仓库与 CDN 使用说明](https://github.com/BabylonJS/Babylon.js)、[默认渲染管线](https://doc.babylonjs.com/features/featuresDeepDive/postProcesses/defaultRenderingPipeline)。没有把选择引擎等同于美术合格。
- Zoilo 的真实扫描哥特回廊：CC BY 4.0。官方 BabylonJS Assets 保留明确原作者/原作/许可；用完整版 8K 图像源，合并及 meshoptimizer 简化约 101 万三角至 25 万，发布 4K 纹理。原手机版只有 1K，近看不足，已替换。源文件保留 D 私有工作目录，应用部署经处理版本和署名。[源目录](https://github.com/BabylonJS/Assets/tree/master/meshes/GothicCloisterCorner)。四组复用形成开放院落，不冒称原创建筑。
- Poly Haven 的蕨、铜鲸、哥特雕塑：CC0，实际模型/法线/材质，非 AI 平面币面。币板直径 1.55、厚 0.055，比此前厚饼明显薄；雕塑可以出币面及币缘，正背面均存在。三件是授权素材组合的象征研究，尚不代表最终唯一原创币的艺术验收。[许可](https://polyhaven.com/license)。
- BabylonJS Assets shark.glb：保留真实骨骼和三段动画，用原游动动画加巡游路径；不再让带底座的铜鲸雕塑充当活鱼。按照资源库 CC BY 4.0 署名，纹理缩到 1K，完整币雕塑没有缩成该低分辨模型。
- 声音直接取有权复用的叶片、气泡、钟声录音剪辑/滤波/空间处理；每个围绕单个象征，未复述章节。环境声独立、默认静音、点按开启。不是英语 TTS，没有新增模型调用/订阅。完整署名在页面 CREDITS、配方在 sound-build。

## 交互与实际实现

进入默认慢速环游，尊重减少动态系统偏好。拖动环视，点币或左右控制近看，近看停转，可拖动观察背面、点播声音、回到展厅。菜单切换空厅/三币/三十台，以及苔庭/毒雾枯庭/海底三种环境。三十台档只有三枚样币与二十七座空台；不宣称制作了三十个独立作品。初始空厅是一座台、零币。

横屏更适合完整空间构图，但 [ScreenOrientation.lock](https://developer.mozilla.org/en-US/docs/Web/API/ScreenOrientation/lock) 兼容有限，一般也要求全屏。因此只由用户触发沉浸并在实际支持时尝试方向锁定；iPhone 不支持时提示手动横屏。竖屏仍能操作，不使用 CSS 假旋转、不改正式 PWA 清单方向。切换方向适配画布，近看按纵横比例选择距离，避免把币裁掉。

菜单/反馈/后台状态暂停画面和声音；浏览器回退的 BFCache 保留恢复，真实离页才释放。静态模型、贴图、录音复用；零观赏后台写入。评价经已有认证会话写独立实验 D1，草稿/导出/同 ID 重试保留。每种模式/进度记录有限性能摘要，非逐帧上传。没有新 KV 过程日志、正式认证或收费请求。

## 发现与修复

- 扫描资产并非引擎默认 Y-up：直接导入导致摄像机看到建筑侧面。统一坐标，按实际地面而非断裂网格最低点落地。
- 模型中心化必须在无场景父变换时计算，不能先挂已移位父节点再拿世界包围盒减局部坐标。
- 四翼旋转围绕归一化后的整体中心，而非扫描原点；控制相机范围，避免近看穿过墙体。
- 蕨叶的深度压缩须在面向币面的旋转之后，通过外层变换应用，否则压扁的是币面高度。
- 放转后的币以实际世界法线对准近看镜头，不能用预定台座角度忽略币本身旋转。镜头角度走最短路径。
- 环境声音加载与按钮完成状态分开；加载期间阻止重复点击，失败可重试。异步音源/主题切换防旧声音晚到。BFCache 回来不销毁旧画面。
- 性能记录使用真实帧间隔，动画步进的 60ms 限幅不用于美化帧率。

## 验证与边界

`scripts/check-monthly-gallery.mjs` 在隔离 SQLite/路由中检查 38 项：空台无币、默认真实环游、三个音频实际解码/播放/复用、30 台保留币身份、三模式、横竖屏控件与近看中转屏保留币身份及画幅、零观赏写入、反馈失联与跨刷新同 payload 重试、草稿恢复、实验数据隔离、认证限制、无 CDN 请求及无 JS 错误。截图/完整指标在 D 盘忽略目录 `.cache/gallery-tests`。原 v1/v2 资源未修改。

Windows Chromium 手机触控模拟，874×402 / 402×874、DPR1，实际 ANGLE Intel UHD D3D11；三十台重场景 P95 约 40–48 ms，存在降帧。不是 iPhone17 实体 Safari 的性能/听感/美术验收。发布前已目视检查，最终以用户真机反馈判定。全套实验资产约 38 MiB，按同源静态文件一次加载/浏览器复用，没有加载整个历史收藏或全部未来月份；正式资产目录/缓存策略待艺术采用后工程化。

## 后续验收

用户先评价全景、符号币、单个象征声音、环境演化、横屏操作和实体手机流畅度。如果不满意，保留旧新样件和可复用资产，按具体缺陷决定修正或转向已约定的图书馆纪念日历。日历研究不在本轮偷偷开始。若动态厅被认可，再建设正式月厅/唯一币/申领介入/恢复版本链，而非让实验状态伪装正式记录。
