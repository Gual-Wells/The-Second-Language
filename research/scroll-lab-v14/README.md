# 第五章：纸胚、皮扣与空间雾染重制

制作基线：`0b5409d`，分支`codex/medieval-scroll-lab-2026-10-16`。当前作品仍为Specimen，未启用认证、未写学习记录。v12/v13原件及入口保留，新入口`/labs/chapter-scroll-v14/`。

## 资源先行的选择

先读项目现有资源重评估、CHARTER及实际v6/v8/v13实现，再查Three原生SkinnedMesh、ambientCG两组PBR、Ashima噪声与Bridson Curl Noise原论文。已有完整流体、卷绕和渲染器继续复用；不另建粒子框架，不为小道具引入新游戏引擎或云GPU。Three原生骨架/几何承担可解释的皮扣结构，图像工具承担适合位图的材质。

第一轮雾场曾出现明显大理石纹，未采用其观感：降低小尺度涡量并调整供应位置。用户补充空间中直接凝聚/消散的方向后，最终加入八个寿命14–31秒、平滑包络、不同位置和尺度的区域，再与平流耗散组合。每次新区域强度从零起，不生成离散小喷口；没有固定向右风。连续旋度场基于多尺度simplex potential的数值偏导，最后仍交给既有压力投影。动作对纸上/下缘和皮扣施加带方向的局部速度，不追加动作喷雾。没有物体边界SDF/三维湿度模型，不冒称精确流固耦合。

## 具体保持与改变

- 保持第五章实际来源、原创题辞、芦管/旧手迹/种子的小画、居中排印、Gual Wells题记与系列藏记。正文未重新创作，英文/中文见v13原方案。
- 新建羊皮纸胚，原图见parchment-source.png，非镜像。主要折痕与小幅GPU几何位移对应；色泽和边缘老化保留于基色，未把全部污痕雕成浮雕。输出纸面2048×2868，纸胚源1060×1484，不把上采样冒称新增细节。
- 新建实体皮带与独立扣具。皮环64骨节调整松弛；皮舌随释放送料缩短可见末端，铜针向镜头方向提起。随后保持环外径大于卷径，沿轴滑出画面，再隐藏。关闭精确反向。未使用弹簧果冻、平面剪贴、缩放放大或透明淡出。
- 皮扣第一轮CC0基色太接近新制品，因此保留其微表面PBR图，并参照原认可皮扣重新制作皮革/古铜基色；铜框表面微小不齐、磨损、哑光和稀疏铜绿共同呈现。动态反射由实体材质计算，不把旧扣具照片作为正面平面。

## 可恢复制作

`scripts/build-scroll-v14-assets.py`用Pillow从保存原图生成发布素材、近似微粒法线/粗糙度及艺术方案摘要。Python使用本机已配置的bundled runtime；原始CC0包位于D盘`.cache/scroll-v14/{leather,metal}`，下载地址见CREDITS。最终基色、所有运行素材和原图均已保存在仓库，不依赖缓存存在才能展示。

`node scripts/build-scroll-v14.mjs`使用项目已有esbuild打包源码入口；网页加载app.bundle.js，修改源码后必须重建，不直接编辑压缩产物。将模块发现的多轮网络往返合并，材质从HTML提前并行预取。皮扣发布贴图512平方像素，源图仍保存；纸胚与正文清晰度不降。v6材质加载新增可选地址，v14不再先加载一套无用的旧纸张贴图，也不下载已弃用皮扣照片。旧页不传参数时保留原路径。

源提示词见PROMPTS.md；资源摘要见asset-manifest.json。布局与材料方案的文件摘要参与新作品身份，旧文书摘要不被覆盖。样品使用新的制作时间，`attestation=null`。

`node scripts/inspect-scroll-v14.mjs`保存真实页面整页、开合中途和实体皮扣放大画面；不是生图效果稿。`node scripts/verify-scroll-v14.mjs [immutable-origin]`核对首轮动作阶段、动作期间程序数量、反向、雾场联动、正文/摘要、GPU上下文恢复、减少动态和旧样品身份。具体结果在verification.json及live-verification.json。

观察环境为402×874 DPR3 Chromium、本机GPU；尚无物理iPhone/Safari验证。非零扰动、骨节数量或测试通过均不代表艺术已获用户接受；还需用户判断雾的自然程度、道具质感与整件作品协调性。皮带动画是受控关键姿态，不是皮革动力学；通用PBR微表面并非最终生成色图的精确物理反演。
