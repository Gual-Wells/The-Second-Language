## 1. 这枚物品的类型：有系列身份的艺术纪念币章

项目用语继续叫“纪念币”“认证币”。工程上更接近独立艺术币章，而非流通货币：没有面值，不必伪装成贵金属投资产品，不刻假的银重或纯度。

传统币章的工艺语言仍有价值：名义尺寸、清楚币厚、币面与边缘的区分、系列徽记、铭文层级、表面处理。数字作品可以有真实倒扣、越界爪、浮动断片和动态效果；未来实体制作另做制造转译，不反过来削弱当前数字作品。

采用40 mm是一个合适的中型收藏币尺度：既接近成熟收藏币的尺寸，又易于比例计算和统一生产。不是认为40 mm在手机上天然比45 mm更大；屏幕大小另由显示配置决定。

## 2. 成熟规格与工艺调研

| 直接来源 | 已核对的规格/机制 | 用于本项目的判断 |
|---|---|---|
| U.S. Mint American Eagle银币 | 40.60 mm、齿边；2026特别版增加纪念标记 | 中型币可以保持系列造型，仅用小标记表达特别发行 |
| Royal Mint Britannia银币 | 38.61 mm；精制版也使用此直径 | 收藏品质不由扩大直径获得 |
| U.S. Mint Navy一盎司银章 | 1.598 in约40.59 mm、平边、无面值 | 币章可以使用成熟币体而不虚构货币身份；平边也是成立选项 |
| Perth Mint Kookaburra高浮雕银币 | 官方检索规格32.60 mm、最大厚6.00 mm | 同重量可以选更小更厚的高浮雕；不能把所有币都当薄片 |
| CIT Thunder Dragon | 45 mm，凹面和超高浮雕，彩色表面 | 深浮雕有实际收藏币案例；凹面可属于特定艺术方案 |
| CIT smartminting | 双面高浮雕、凹面、非圆形；示例浮雕达9 mm | 主题可以越出常规低浮雕，不以标准圆盘包络裁掉好设计 |
| Royal Canadian Mint表面工艺 | 镜面/磨砂组合、反向精制、哑光精制 | 通过主体与背景的反射分工获得收藏品质 |
| U.S. Mint雕塑工艺 | 初始模型可预带共同铭文/设计要素，艺术家负责主体 | 系列身份和基础结构可以先确定，主艺术仍来自完整图稿 |

出处见第13节。Perth页面本轮初次读取与官方检索可获得规格，后续展开超时；没有依据该页面声称逐角度观察。其他选择都是本项目的设计推导。

**调研带来的具体取舍：**

1. 不照搬银币重量/银材积守恒来限制数字币。
2. 不把高浮雕的总高度称作“币胚厚度”。
3. 不给统一身份再堆月桂、皇冠、地球、四十星、神殿等没有新职责的符号。
4. 系列品质来自稳定的造型/表面语言；特别版不需要再做一个更大更厚的饼。

## 3. 统一的内容、可变的内容

| 共用基础 | 主题可变 | 仇视之龙特别化 |
|---|---|---|
| 名义直径、基础截面、坐标与尺寸单位 | 主符号、动作、浮雕高度、轮廓越界 | 已认可龙、两组爪和捏碎动作 |
| 窄包边、基础边缘语言 | 接触压痕、局部边刻中断和实际破损 | 左上缺口与包绕爪 |
| 统一币背核心、系列铭文和身份位置 | 表面材料、主题色和效果 | 暗银主体、暗红眼口、爪旁局部黑雾 |
| 章币的身份绑定规则 | 题材取词或取义项，不必复述章节全文 | 独立诞生特别发行，不关联章认证 |
| 完整资产和三组对应视图 | 合理的实体翻译版本 | 保留特别发行身份和原始艺术源 |

“统一”不要求每枚有相同正面边框，不要求所有题材变成银龙浮雕。纸、木、石、编织等材料主题可以共用名义形制与币背身份，但允许材质本身带来的侧面差异。不要给草编或碎纸币强加车削金属齿痕；齿边是金属基础的首选实现，非金属使用对应的细分节奏或平边变体。

## 4. 首轮尺寸规格：从可开始制作的默认值出发

这里的mm是母版的实际尺度。D为破坏前名义直径。

| 项目 | 首轮值 | 用意 |
|---|---:|---|
| 名义直径D | 40.0 mm | 全系列共用尺度 |
| 币身厚度T（两个field之间） | 2.8 mm = 0.07D | 有实际厚度，保留高浮雕的层次 |
| 每面包边高 | 0.20 mm | 包边能在侧光中读出来，不变成厚框 |
| 未破损包边总厚度 | 3.20 mm | T加双面包边；不含艺术浮雕 |
| 包边径向宽度 | 0.65 mm | 可用币面直径约38.70 mm |
| 外肩圆角起始半径 | 0.15 mm | 制造圆润边缘，不做锋利锯盘 |
| 金属边刻 | 120条轴向圆底浅槽 | 细密而可辨认，方向贯穿币厚 |
| 边刻径向深度 | 0.12 mm | 形成反射节奏，避免齿轮轮廓 |
| 边刻轴向有效高度 | 2.20 mm | 上下肩各留下0.30 mm；不横跨包边切痕 |
| 齿槽周向宽起始值 | 0.40 mm | 周向节距约1.047 mm |
| 币背徽记浮雕高度起始值 | 0.45 mm | 身份可读，低于正面主题 |
| 币背铭文高度起始值 | 0.12 mm | 近看有工艺；不做牌匾大字 |

2.4 / 2.8 / 3.4 mm是技术截面比较点，首轮选2.8 mm。只有实际侧面出现纸片感或厚饼感才改，不强制先做三枚完整艺术币。所有数值可以按完整稿的空间设计协调；不是为了达到参数裁切题材。

边刻120是本项目选择的工艺频率，没有用“120”表达章节数或纪念意义。边刻底部与肩的过渡需圆润；最外轮廓仍读为币缘而非密集尖牙。平边变体保留同样截面和圆肩，可以用于铭文密集或非金属主题。

### 4.1 厚度与浮雕分开

主体低浮雕可从field突出0.3—1.5 mm；艺术主形可探索1.5—6 mm。仇视之龙先按最高主形约6—9 mm的空间规划，这只用于稿图侧面构造，图稿中的主体比例与符号表现优先。

这些并不要求把正面所有鳞甲压成同一高度，也不要求上爪贴平。假设正面从field凸6 mm，背面徽记凸0.45 mm，物体总深度约9.25 mm；仍不能称币身“厚9.25 mm”。跨背爪若更突出，记录实际包络。

### 4.2 默认field、凹面与截面

系列默认平field和窄包边，浮雕从field自然生长。局部凹面可作为题材变体；不为全系列套碟形币体，也不因为CIT有凹币就把已认可龙稿改成碗。

背面“平整”指稳定支承面和克制低浮雕，允许被正面爪/断口合理跨越。名义圆盘保存作初始规格；成品局部可缺损、压陷、弯折。缺口厚度来自实际币身，断片具有短厚的块状表达，继续遵守用户认可B式碎块的方向。

## 5. 数字母版：少量统一约定即可

- Blender母版：X向右，Z向上，币法线沿Y；正面向-Y。用mm显示尺寸，真实物理值以米保存，D为0.040 m。旧工程的可识别方位可以复用，新几何完整重做。
- glTF/GLB按米输出。标准坐标转换由正式导出器完成；不把40 mm误导出成40 m，也不为了适配viewer破坏工程比例。
- 正背顶端对齐（12点对12点），从侧面翻看不会使币背倒置。这是项目选择，不借用流通币的翻转习惯强迫把玩用户。
- 每份艺术文件记录名义币径、实际含爪/断片的边界和标准朝向；查看器按完整实际资产构图，不按圆盘截掉越界内容。
- 不要求币坯、艺术和身份最终必须焊成一张mesh；在一轮完整设计/制造中各层协同形成，保存方便操作的源工程。

这几条足够用于首轮生产；不为此新造CAD服务、分布式参数系统或复杂类别继承。

## 6. 系列身份：实际从现有开卷图标出发

已经读取并目视核对 `web/icon.svg` / `icon-512.png`。它的识别结构是对开的双页、明确中缝、双侧各三行，以及下缘的书页转折。研究包附带同一SVG原件；不再先手搓一个没有稿图的“精致书形”让AI迁就。

首轮币背方向：

1. **一个开卷徽记**：保持原图标双页轮廓与中缝，转译为浅浮雕金属；取消方形应用底板。六条行线承担现有识别，不给它们强行附会六级学习或六种能力。
2. **一组系列名称**：`THE SECOND LANGUAGE`，上弧，小型衬线大写字。
3. **一组发行身份**：普通章币为章号，特别币为特别发行名称/年份，位于下方身份区。

中央徽记初始宽16.8 mm；按原SVG约352:291的识别包络保留比例，高约13.9 mm。中缝和页线由视觉稿研究金属转折、刻槽宽度；不能简单把蓝图标贴成蓝色塑料章。

背面核心优先保证识别，工艺层次来自磨砂field与细缎面/局部抛光徽记，不靠更多环、花枝与满铺文字。正面主艺术优先；背面不再做第二张龙肖像。

### 6.1 布局的工作区域

以D40为基准，暂按：

- 中央身份核心半径约11.5 mm；开卷位于这个核心中。
- 铭文带在半径14.5—17.3 mm；上部给系列名称，下部给发行身份。
- 外部结构区约17.3—20 mm：肩、包边、爪的跨缘与破损。

这些是设计分工线，不是三圈必须出现在模型里的装饰环。身份区不被迫画额外描边。跨缘结构仍可进入外区；如果明显侵入中央，需要在完整侧背稿里协调，不切掉爪或把书缩到不可读。

文字保持真实字形，首选研究资源为OFL字体EB Garamond，中等字重，非超细线。已实际读取字体元数据和OFL。精确字号/间距待完整币背稿试排，工作起点大写高度约1.3 mm；微号约0.8 mm。中文版名称和认证信息由档案界面完整显示，不把完整中文证书挤满币背。

**铭文是制造设计的一部分。**稿图可表现浮雕位置和明暗，真实生产用确定字形校正拼写/轮廓；它不构成靠大幅手改mesh补救造型。图生三维把字猜错时，不反过来采用错字。字体转几何/烘焙时随资产保留许可。

建议采用的发行格式：

| 内容 | 本轮工作值 |
|---|---|
| 展示名 | 第二语言诞生特别纪念币 · 仇视之龙 |
| 系列 | THE SECOND LANGUAGE |
| 发行类别 | FOUNDATION ISSUE |

特别化采用**同一币背、不同下铭文和一处小纪念印记**：

- 中央仍是统一开卷，上弧仍是系列名。
- 下铭文优先试排 `FOUNDATION · 2026`。
- 小印记候选为一枚微小`I`，表示首次特别发行；采用与原开卷一致的书脊刻线语言，尺寸约1.5 mm。它属于特别发行标记，不添加一副徽章或第二条龙。

- 龙正面不再加入大标题、项目logo、水印、奖杯、皇冠或“创世故事”图案。

这里的`I`和下铭文是工作设计方向，后续完整稿可以优化其细节。赋予特别身份的是用户已决定的纪念用途，不依赖必须有多少金色、多少光或多少装饰。

材质建议：保留现有龙的暗银方向，微暖银底、凹部轻包浆、高点克制磨亮；特别版的小纪念印记可试非常小的暖金强调，其他部位不全镀金。不开光雾时依旧是完整收藏品。

## 8. 所有章节币的身份格式

视觉一致、数据简单：

- 系列名固定，开卷母版固定。
- 章币显示 `CH-0001` 一类短章号，位数是最小宽度，超过9999自然扩展。归档页使用已有真实章编号，不重排已发章节。
- 稳定身份由真实chapter_id及首次认证关系绑定；显示序号不是后台主键，不用标题散列替代它。
- 首次认证创建唯一币身份，后续艺术版本更新不重新发币，不静默改首次认证信息。已存在真实认证字段按原架构映射；本轮不新建正式数据库表。
- 无面值、假贵金属规格、假的世界限量、假的发行机构/铸币厂标志。`THE SECOND LANGUAGE` 是项目系列身份。
- 大量认证信息保存在绑定记录与资产清单，近看需要的少量文字才进入币体。不把资产UUID、日志时间、模型种子、所有分数刻成“证书背面”。

特别发行使用独立命名空间，F-001不导致第一章变成CH-0002。今后如果有周年或里程碑币，可以沿用相同下方身份区而不是再造一套币背。

## 9. 白模、材质、效果三组稿图：先确定同一个器物

用户要求包括白模全角度、上色/材质化全角度、光效/粒子/雾气全角度。这是合理的制造基准集，采用同一造型、相机编号和发行身份。

**组织为一个完整设计的三个外观状态：**

| 组 | 内容 | 要解决的问题 |
|---|---|---|
| G：白模 | 中性灰材质、柔光，无上色/发光/粒子/雾 | 主形、厚度、包缘、币背、抓握和缺口是否读得清楚 |
| F：材质 | 同一形体，暗银/细分工艺/主题色，无动态特效 | 真实金属反射、表面转折、色彩焦点 |
| A：效果 | 沿用F，加眼口红光、局部粒子/雾；同一动作相位 | 效果是否提升主题并保留形体与铭文 |

不让F重新设计一只爪，不让A追加角/人物/裂口，不把渲染光斑做成白模凸块。统一币背进入完整器物图，不另起孤立书形世界。

### 9.1 第一套角度：12个共享机位

1. 环绕8张：正面0°、右前45°、右侧90°、右后135°、背面180°、左后225°、左侧270°、左前315°。
2. 高位2张：正前上方35°、背面上方35°，检查包缘和肩部。
3. 上/下2张：俯视与底视，检查上下缘、爪背绕及整体厚度。

三组共36张，这是首套可执行视图配置，不是要求任何作品必须交36张才算好。几何组另外4张正交图（正、背、左右）用于尺寸和轮廓；抓握/断口/下爪包绕/币背各一张必要细节图。首轮约44张，不做每度360张的低价值大集。

2048方形单张作为母版工作分辨率；每张保留币外余量，附带1024预览。70 mm透视机位起始值用于自然收藏物观感，正交图用于结构；没有将不同焦距结果混为同一视图。

白模固定柔光；材质用稳定工作室反射，不烘死高光；效果额外输出开/关配对。环绕时保持灯相对世界固定，避免每面总有同一条伪高光。未来正式透明页面另做透明交付，设计审查可用中性背景。

### 9.2 在真正模型生成前，图稿如何工作

以用户已认可的完整正面为锁定锚点。它的SHA256为 `6608204082a4036120e0c2b607fad6f27b2aa16fa3122afa37a43ac94d4f967d`。先补齐完整侧背设计，包括统一币背、正面结构如何跨缘以及真实缺口厚度。

本次委托授权研究新的多角度基准集；旧被否决的三视图制作分支不再利用，不能因此把新的所有多角度探索都当成永久禁令。

先在同一个完整造型方案里做G关键角度，再用同源条件研究F/A，避免36次独立自由生成导致36种龙。每张稿图都保留完整币上下文，需要近景时另加完整视图定位。

AI补的侧背是设计稿，不是实拍真值；我们可以用它决定隐藏结构，但不把它标成已生成模型的实际视图。真实新模型到手后，用同一机位重新输出G/F/A，并将原设计稿保留。文件层面只分 `draft/` 和 `render/` 两类就够，不引入繁重审计系统。

### 9.3 一轮成型与这套基准集的关系

一次完整造型形成之前，把需要的器物关系准备好。模型生成时按完整设计建立新的M，不沿用旧网格逐爪修补。视图集用于指导和检验这一轮的整体作品，不成为无限期局部mesh修补任务。

现有TRELLIS2仍可以用最强的完整单图作为主要条件；侧背稿给设计与实际工艺提供明确目标。若采用明确支持多图的生成器，再按其输入格式提交。可以探索这两种成熟入口，不要求先证明统计保证。固定题材/身份/结构的设计包是两者共用资产。

大范围艺术造型失败时回完整输入与整轮生成设置，不因为已经出网格就追加低级爪或切削整个背面。必要网格清理、真实铭文与材料输出仍属于制造中的技术步骤。

## 10. 本轮直接可用的下一步

1. 用工作规格制作**币胚技术截面与统一币背的完整视觉稿**。技术币胚只负责尺寸；币背艺术从真实项目icon和本节身份语言形成，不恢复被否决的程序书形coupon。
2. 将认可龙正面、规格和FOUNDATION身份放进同一设计输入，先解决完整左右侧/背/斜视图。眼、嘴、角、主身体量以及已接受爪尺度仍保持。
3. 将几何关键角度落实为G，再进行F和A外观。三组始终共享造型和相机。
4. 输入新一轮完整建模，实际回收与多角度展示；源稿、材料配方、特效和最终模型永久留存。

不把“行业技术不是百分百可靠”作为停止探索的理由；真正需要避开的是已经证明会毁形的施工方式和重复没有信息增益的失败。
