本轮交付的是可绕看、可编辑的真实三维样币，不是新的AI多视图稿。已有工程装配、银色静息态与源几何；用户艺术采用尚待实物观感验收。没有晋升为以后所有主题币的自动制作标准。

## 制作结果与权威

- 共用币胚D40mm；平场厚2.8mm；包边厚3.2mm；圆肩R0.2mm。雕塑与包绕爪突出于该名义币胚，不能把整件雕塑总厚度误认为币胚3.2mm。
- 币侧实际阴刻三组THE SECOND LANGUAGE、三组短草纹；相位0/120/240°与60/180/300°，无额外齿纹。字槽0.055mm、纹槽0.045mm，字体与曲线沿用原始包。实际网格逐一探测了51个非空字的槽底。
- 特别币在共同母体上切同一个贯穿缺口，正背没有独立拼凑不同破口；铭文不因遮挡而重新排布。
- 正面来自认可完整稿的全币条件化模型。背面叶饰也由完整币背视觉条件化；隐藏包绕来自同一正面谱系，不接入独立生成的另一套背爪。适配标准厚度后，对内部/背侧空壳做了局部体积修复，正面Y<-1.45mm的外浮雕保留。
- **只有币侧严格照参数图。** 币背图05继续作为尺寸与内容参考，具体审美按完整视觉稿。实际较大的下半碑铭框、书徽、叶饰及各文字行记录在`outputs/fitting-layout.json`，不能再用旧参考排版强行覆盖。
- 书徽用原项目SVG页形，保留每页三横；立体页弧与凹刻由真实几何形成。文字全部真实字形切槽，深色是槽内局部材质，不是照片贴图。未把原SVG新增元素重新解释为别的标志。
- 启动特别币没有章号、随机码、认证时刻、顺序码或编造启动日。系列认证币资料仍独立保留，不继承龙爪与缺口。

## 预览

直接打开本页的静态视图不需要运行任何云服务。交互GLB需要HTTP：运行包内`python scripts/serve_viewer.py`，打开`http://127.0.0.1:8124/viewer/`。此脚本显式提供正确JavaScript MIME，兼容Windows文件关联。拖动翻转、双指/滚轮缩放，可切灰模与灯光。Three.js及MIT许可已随包提供，不依赖在线CDN。

## 从包内源几何重建

需要Python、包内固定版本依赖与Blender5.1.2；无需Kaggle、HF账号、API密钥或再次生成。依赖、虚拟环境、缓存和解包目录应放D盘。

```powershell
python -m pip install -r scripts/requirements.txt
python scripts/rebuild.py --blender D:\CodexStorage\tools\blender-5.1.2-windows-x64\blender.exe
```

顺序为：参数币胚及真实阴刻→源艺术网格坐标注册→正背/包绕拟合→隐藏空腔修复→微小重建残屑过滤→几何实测→Blend/GLB与真实相机渲染。参数、原图、字体、源网格和脚本均在同一闭环包。`art/*.npz`以原模型单位储存，注册后NPZ为毫米，Blender/GLB统一只转一次到米。

云生成只用于初始化艺术几何。代码与权重pin、种子、阶段、输入散列和免费额度查询记录在`provenance/`。512初始化加1024正面细化实际合计约33.08分钟免费GPU，无新订阅或付款；包内重建不再消耗GPU账户额度。授权DINO模型权重未打包或公开转存。

## 尚待判断的边界

技术检查不代替艺术验收：当前背侧掌部和有机叶饰仍有重建概括，微观手工工艺、磨耗、彩色表现以及雾气/粒子/发光不在本轮静息态内。正面与原稿的鳞纹、局部体积并非逐像素复制。GLB可旋转不意味着已通过实体铸造、强度或生产设备验证。本轮不改第二语言生产前端、数据库或正式认证记录。


正面外围18.10—19.0mm过渡带将生成模型原币缘埋入标准币胚，爪/长角跨缘区域豁免；这属于实际接缝适配，不能误解为对整条龙身进行全局磨平。另附独立parameter-blank.blend，便于直接检查未加艺术部分的标准币胚。
