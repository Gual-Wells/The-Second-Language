# 首次创作的规模—质量约束

2026-10-25。用户要求：保留既有QUALITY_SCALE的成稿约束，同时将规模意识落实到生成之前和生成途中，避免每项用法所需的平均正文体量过度膨胀。基准提交`7db4b3c4c92bb4b6918af47b7aff6f223b403ba5`；旧首章试验保持其原闭环字节，不回写测量或候选。

## 采用的设计

主路径调整为：**完整教学范围与真实材料 → 内容任务和规模预期 → 分批直接创作充分紧凑的唯一首稿 → 原语义审阅及必要修正 → 原装配/来源/发布。** 不默认先生成宽松长稿，再安排整章缩略；不要求一个模型响应写完整章，也不冻结首次文字而拒绝纠错。

仅说“简洁一点”不够。写前要确定文章究竟让读者理解什么、哪些背景/机制/人物/限定必不可少、哪些相关知识不属于这次内容任务。粗略长度预期由这些内容工作与可比作品校准，可用章节范围和关键内容组长短意图；不强制每篇精确数字、不用USE数乘固定字数。实际必要性优先，不能为追回预期损害内容。

生成时，内容工作已经讲清就推进；定义不例行复述，每个用法不自带一套背景/泛例/启示，不因读件还有知识就扩大支线。首次就写对主体、因果、时间、量纲、模态、配价和语域，保留必要无USE背景及文学节奏。受限/专业/历史义先找真实承载位置，避免最后每个缺项各扩一篇。难义仍可独立成篇，不强合题材。

成稿后的QUALITY_SCALE全部保留。前置设计减少无效扩写发生的机会；发现失义、事实错误、译文和组织问题仍正常返修，包括必要的较大修订。没有新增每日多稿任务、审批、评分队列或字数发布门槛。

## “每用法平均规模”的实际含义

详细复算和陷阱见[scope-analysis.md](scope-analysis.md)、[analysis.json](analysis.json)。这里只采用全章唯一教学身份为分母：

`第三部分正文英文词数 ÷ 第一部分不同USE数`

本章固定680项，原稿29.84词/USE，旧研究择优稿18.44词/USE。它说明同一范围可以写得更紧凑，**不是新章的系数、最优值、逐义额度或上限**。不能增加USE拆分/虚假引用或改用重复引用次数来降低比率；真正补漏改变范围须单独说明。

为何不逐篇限额：择优稿中1–3 USE的9篇平均约50.71词/篇内USE出现，却合计只有862词，占全组6.9%；它们要交代真实对象才能成立。20+ USE的14篇约14.34词/篇内USE出现，却占体量46.7%。高密度不自动优质，低密度不自动浪费。平均值用于定位需要阅读的问题，最终看具体内容。

第一部分汉字、第二部分原例/必要补例与英文、译文分别观察，不混作一种学习负担。原例全保留，补例不例行额外堆砌；选词、难度、真实词族与全义不因平均值而改变。没有个人耗时和保持实验，不能把字数等比例换算为掌握时间。

## 成熟方法调研与取舍

以下均为本轮实际阅读的原研究，不使用二手摘要作为方法权威；其任务和模型不同，不能声称已直接验证第二语言项目。

| 原研究 | 本项目吸收什么 | 不照搬什么 |
|---|---|---|
| [DOC，ACL 2023](https://aclanthology.org/2023.acl-long.190/)，读正文规划、控制及消融/局限 | 将组织工作前移，写作围绕具体内容任务，完成后转入下一内容 | 不引入其解码控制器、重排器或固定树深；原文也报告控制过强可能狭窄、重复，不能强压创造和阅读节奏 |
| [PLANET，ACL 2022](https://aclanthology.org/2022.acl-long.163/) | 规划需在实际生成中继续发挥作用，不是写完计划就放任续写 | 它涉及专门训练与潜在计划表示，不能作为现有Codex的即装插件，更不等于全部义项语义可验证 |
| [Following Length Constraints，EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1233/)，读方法、评估及局限 | 长度意图需要明确；普通提示遵循并不天然可靠，辅以真实计数 | 不外推旧模型结果到当前模型；不把其训练方法/最大词数任务当成本项目硬上限 |
| [Albers等，BJEP 2023](https://bpspsychub.onlinelibrary.wiley.com/doi/10.1111/bjep.12592)，读方法、结果及局限 | 重复须看作用，不能把所有复现都当冗余 | 实验为46名大学生与人工领域通用多媒体材料，外部效度有限；不由此删除语言学习的自然复现、译文或音频 |

据此作的工程判断是内容规划、直接创作、自然停止与途中观察相结合，而非另接摘要模型或训练一套长度控制模型。文献不能给出本项目通用“每USE多少词”的答案。

## 两次隔离首次创作探索

没有只靠改提示词就宣称有效。选A23机械25项、A31文学17项共42项用法，使用完整P1/P2教学卡及原有实际读件，让两个新上下文作者分别直接创作。[inputs.json](inputs.json)保留实际提供的教学输入与来源摘要，去掉了全部原第三部分句子；两作者均未读旧范文、缩略稿、原article-plan或彼此稿。写前先落计划，再分批写一份稿；记录见各author-notes。

| 探索 | 写前条件 | A23英文词 | A31英文词 | 合计 |
|---|---|---:|---:|---:|
| probe | 只有定性紧凑要求，作者自主选内容与长度预期 | 553 | 601 | 1,154 |
| calibrated | 明确本篇内容工作及不额外扩出的支线，并给题材相关软预期；必要性优先 | 322 | 447 | 769 |
| 原已发布相同篇目，仅作定位 | 原章文章 | 369 | 549 | 918 |
| 旧研究择优相同篇目，仅作定位 | 编辑后的研究稿 | 221 | 500 | 721 |

校准小样的机械预期300–380词、文学430–550词，来自本次具体内容范围与已有可比体量，不成为长期协议的篇幅档位或逐义配额。作者没有先生成长稿再缩短，也没有为了达到下限补字。文学仍允许更多人物、停顿和声音；机械将机制、保持/承重/弹性和换倒挡在一个解释中组织。

**观察结果：单纯“紧凑”没有阻止初稿偏大；限定真实内容工作和校准写前预期，能直接产生规模较合适的初稿。** 两作者/两篇的探索不是随机对照实验；内容取舍也不同，不据其差额宣称因果效果、固定减量率或全章可复制性。probe增加的部分技术说明确有信息，不能全叫冗余；关键是是否属于本篇必要内容。

这批稿的结构检查与具体语义问题另见[review.md](review.md)。不因769词或42项引用齐全自动宣布内容通过。原始首稿冻结保存；校准稿三处角色交换、动作概括和译文限定的问题，另存于[reviewed.json](calibrated/reviewed.json)，[local-corrections.json](calibrated/local-corrections.json)记录具体差异。修订后776词，三处局部纠错并未进一步缩略；不能用修后稿倒称原始首稿一遍全对。

来源为原章已冻结的MathWorks离合器原理、Toyota传动类型与Project Gutenberg《樱桃园》英译原件。试样作者实际读取相关正文，范围在notes；没有重抓热点、改变VIX、捏造已发生的改编或将假想教学装置冒充真实车型。

## 实际工程接入

### 写前与写作提示

`QUALITY_SCALE`新增首次创作约束，`TEACHING_AUTHORING`、`QUALITY_WORKFLOW`、`DAILY_RUN`和AGENTS同步；实际`run-daily.ps1`在第三部分生成指令之前明确写前任务/粗略规模/受限用法安放与直接首稿要求。原全义、真实材料、50主词、max日课模型、恢复保护及发布身份保持。

计划复用article-plan，续作复用已有正文和resume；不强制新增文件。每个自然写作块英文稳定后，按现行身份和逐句译文格式存入唯一articles.json，再作途中观察。不能等全章才整理JSON，也不能把未保存临时英文漏出统计后宣称体量很低。

### 途中只读观察

```powershell
node scripts/chapter-footprint.mjs --draft YYYY-MM-DD
```

工具读取冻结selection及齐全50份第一部分作者稿，以不同USE身份作完整分母；读取已保存articles.json的真实词/句、引用并集和未引用清单。文章尚未创建、为空和有内容会明确区分；分母不齐、坏格式、未知引用等报错，不猜测。

报告始终标`draft-observation`。哪怕全部USE已经被引用，也不称正式完稿或语义合格；未完成时两种比率都不是成稿效率或全章预测。统计不是给剩余义项计算字数余额。发现偏离预期，优先改变尚未写出的重复组织/非必要支线，刚写出的具体问题可局部修复。

工具不会保存chapter.md、伪造缺义句、调用模型/网络/音频或改变任务状态。原正式`assembleRun/validateAnnotatedContent`仍要求完整覆盖，打包与发布门禁未动。完整稿观察入口兼容，并附章级P3/USE及(P2+P3)/USE；这些字段只在工具输出，不写业务数据库或阅读正文。
