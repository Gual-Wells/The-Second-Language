# 第三部分独立编排与联合精简实作

2026-10-25；研究候选，未替换正式第一章。

后续追问的详细归因与两版取舍见 [growth-analysis.md](growth-analysis.md)：主要增量在早期写作已存在，七项局修没有实施跨篇重构，不能把37词当成全部可压缩空间。

本轮完成了一份全量双语新稿，并对它进行了实际联合编辑和交叉审阅。**局部存在可清理的重复、可共享的背景，但这次独立编排没有减少全章阅读量。** 不以篇数减少代替规模减少，也不把一次试验未成功写成已经证明没有进一步空间。

三者均为同一批50主词、680个原用法身份。第一、二部分逐字节不变；第二部分仍是873例、8,016英文词。计数使用项目 `scripts/lib/chapter-footprint.mjs` 的同一口径：英文正文词元，不计标题、数字、译文和内部标记；连字符和撇号连接词按该工具口径处理。

联合编辑实际减少37词，即独立底稿的0.268%。最终候选仍比正式稿多981词，即7.681%。这不是压缩成功的替换稿。全章每USE均量只是观察，不能变成逐义配额、质量分数或择词惩罚。

## 独立性如何落实

先从当前冻结的第一、二部分构造输入：50份主词及真实词族的讲解、原USE身份、对应例句，以及VIX冻结选词。教学的全义、词族、真实取材、逐句翻译和真用要求继续成立。

新规划、取材和创作不读取旧第三部分、旧篇目标题、旧用法分篇、旧来源包、旧来源缓存、旧稿体量或先前的压缩方案。全局规划先由一个独立作者看完整输入，再将语义相关的任务交给三位独立作者；没有先把680身份平均切成三个等额写作份。29个初步理解任务按材料自然拆合，最终成稿38篇；这两个数量均不是生产配额。

采用原文在本实验中实际重新获取和读取。共114个采用来源URL及相应读件记录，包括官方机构、原始作品、公开研究和技术资料。读取检查点、读到的范围、原件摘要和事实/例示界限见 [source-evidence.json](source-evidence.json)。原始第三方HTML/PDF/工具返回保存在D盘私有实验目录及项目归档通路，公开包只保存作者自述、来源链接和原件校验信息，不把全文复制进仓库。部分时间是完成读取的检查点，不冒充精确下载时刻或逐篇阅读耗时。

所有作者稿先完成交叉语义审阅，再形成联合编辑底稿。联合编辑完成并经另一作者复核后，先冻结候选，随后才开放正式第三部分作只读比较；没有把正式稿的表达或规模回灌给新稿。冻结时刻和SHA在 `results.json`；当前正式章SHA为 `4cc6a2f9edee37555418c365c1da29033b43c1f6854a3ac2dddf2aa9e03f7a78`，独立候选文章SHA为 `e4d5589d3279997debde37c1aeff62604bfd978e1ee10608b6750ccaac87f53e`。

## 做了哪些质量工作

三位作者相互审阅全部680个目标的实际语境、词性、配价、专业/历史限制、译文及采用来源。审阅中确实修正了桥牌语境中shift的名词承载、orbit的动词用法、multimedia的名词用途、专业条件和个别事实归属；也补读了真正支持陪审员替补规则的原始规则文本。标记齐全与装配通过均没有被当成语义通过。

联合编辑另有七项实际改动，涉及五篇；另一作者重新阅读这些篇章的112个英中句子、120个目标及相关原文上下文。修改前后的内容、保留的条件、删除/共享的命题和实际来源阅读记在 [editing-changes.json](editing-changes.json)。这是作者与同伴的文本判断，不是学习者效果试验，也不能据此承诺两套材料的学习效果完全相等。

## 哪些紧凑化确实成立

1. **同一对象承载多个相关理解任务。** P05把希勒《Classic Landscape》的构图与同一作品的膜层、清漆处理接起来，减少重新介绍另一件艺术品。P15、P16共用会场、工作人员与固定闭幕时间，后篇直接进入资源冲突和让步。
2. **只声明一次模型与条件。** P15把大会模型的引入和三项必要条件合成一处，全部条件仍在首次使用前给出。
3. **将重复结果改成一条因果链。** P20a保留非相干波叠加、相位变化与探测平均机制，去掉相邻句对“没有稳定条纹”的重复解释。
4. **沿用同一个具体例子。** P19让运行期内存分配与前文的文献图像查看工具相接；多媒体教学也沿用同一页面和朗读，不再另起一份读本与广播。
5. **直写机制，删除泛评。** P27a将抽象的“另一项操作问题”改为船体纵摇时固定装置约束货物；P07b删除紧接缝线/扣合条件之后“两个漂亮表面并不足够”的重复评论。

七项修改并不每项都减词：P19共享对象的句子略长，但减少读者换对象；P20a精密度段改得更具体，增加“重复读数很接近也可能有一致偏差”的有效判断。净减少37词是这一次实际修改的结果，不是全局可压缩空间的上限。

## 为何篇数少了而正文更长

冻结后另读了正式稿12篇205句与新稿12篇299句，涵盖艺术材料、表演文学、工作协商、光学电学四组。逐句证据与保留/替换的知识边界见 [post-freeze-comparison.md](post-freeze-comparison.md)。

- 新《暴风雨》三篇共905词，持续展开同一作品的改编、传感器表演与影院取景；旧对应戏剧史篇389词涉及更多作品和历史节点。新稿共用了作品背景，也增加了深入展开，不能把516词净差当成同内容重复。
- 正式文学篇是435词的《樱桃园》，新稿是923词的Irving/Dickens双作比较。作品、场面、因果与目标分配都改变了；旧Fiers、断弦声与斧声的文学价值没有变成可删除的水分。
- 同一组三个非相干义项，正式稿两句31词，新稿三句43词。新稿更显式地解释测量期间相位变化和平均过程；这是可验证的局部密度选择，不足以证明所有增量必要或都可以删除。
- 整体上，零目标句由152增至187，一目标句由253增至391，二个及以上目标句由208降至139。新稿更常让兼容形式分别承载，增加了展开和衔接；这些数值只能定位审阅方向，不能自动判定冗余。

**相同用法覆盖不等于相同知识内容。** 新稿没有保留全部旧作品、现实数字和机制链，也有新增的有效内容。本实验没有固定一个跨版本相同的事实/论证/场面清单，不能宣称“同内容无损压缩”，不能把981词精确归因于某一约束。

## 对后续生产的可用结论

可以复用的是编辑方法：先围绕真实理解任务组织，优先让兼容用法共用对象、背景和因果；逐项识别重复命题与空泛过渡；重写后检查所有实际承载、事实条件和阅读价值。不得按无USE、有派生形式、平均字数或篇数机械删减。

本轮削弱了“放开旧篇目组织即可明显减量”的预期，但没有测出全局最短体量。正式稿本来已有可读的兼容形式共载，不能预设独立重写必然更紧凑。若下一步要量化同内容压缩，应该固定某一组的事实、推理与必要场面，再比较重写，而不是先换题再把词数差称为压缩。

本次只提交研究成稿与证据；**正式第一章、VIX、章节序列、休息和音频配置均保持原状，不发布候选、不生成音频。** 不因本实验新建强制字数上限、固定篇数或每天多稿流程。没有新增外部付费调用或持续订阅成本；Codex分析仍消耗本身额度。
