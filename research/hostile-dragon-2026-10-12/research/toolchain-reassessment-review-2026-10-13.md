# 《三维样币工具链重评估》专项研究与工程调整建议

2026-10-13。性质：对新报告的实施评审，尚未成为新制作协议，未修改模型或晋升Canonical。

## 研究对象与事实边界

本轮唯一主研究对象是新提交的[《仇视之龙三维样币：工程停滞根因、工具/模型重选与可执行生产架构研究》](https://github.com/Gual-Wells/The-Second-Language/blob/e4c897404a54ea1d3bf72ae054ebaa290bcde647/research/hostile-dragon-2026-10-12/research/3d-sample-coin-toolchain-reassessment-2026-10-13.md)。新增报告提交为f8cf58ce29ce48ec69dd4990b1f0d2ab190db8d8，研究时仓库main为e4c897404a54ea1d3bf72ae054ebaa290bcde647。旧协议只提供必须保留的约束。

报告准确区分了整物生成、既有表面变形、实体结构操作、艺术雕塑和材质展示。实际旧副本仅验证了局部姿态调整与保护，尚未验证高级重雕。报告的诊断与本机记录吻合。

但“Blender具备Sculpt”到“本Agent可稳定按照批准稿完成高级雕塑”之间仍有能力缺口。增加一个工具名称不能补齐它。下面的建议专门处理这段缺口。

## 一、应吸纳的结论

1. 保留旧高价值母版，在副本做目标区域的结构修改；停止用整币重新生成替代旧资产编辑。
2. 对新稿已改变的抓握/破口，允许局部重建或局部换拓扑。保护的对象是已认可设计与有效表面，不是全币旧顶点编号永远不变。
3. 先解释网格对象归属，再施加破坏性操作。矩形范围、连通分量、空间接近各自都不足以独立认定“这是爪”。
4. 薄壳、重叠表层或无效实体不能直接交给实体布尔解决。只修复或重建当前需要操作的区域。
5. 验证一个完整母体内的抓握/破缘单元，再扩展到其他区域；材质与特效保持独立。

## 二、报告还需要补强的地方

### 2.1 操作工具通过不等于雕塑能力通过

报告给MCP的最小试验是列对象、复制、加修改器、回读/渲染。这些可证明通信与操作，却不能证明掌部、指节、爪尖和断口会被准确做出来。

应再验证：正确选择目标表面、保护周围对象、实际改变新的主形/关节面、观察结果、继续有依据地纠偏，以及恢复父版本。所有这些在灰模整币内成立，才可将“参考指导局部重塑”标为VERIFIED。

若一个连接器仅提供Python代码执行，它改变的是控制接口。雕塑过程仍需明确的视觉目标、局部选择和可回读结果；不能把MCP当作新增的三维生成模型。

### 2.2 缺口与爪需要共同求解

报告E2/E3可作执行导航，但不宜变成先把洞固定、再把爪塞进去的单向流程。

当前目标应是一个整体单元：左上掌/指节/爪尖 + 接触币缘 + 破口厚度 + 局部侧背包绕。它们在同一完整场景中交替调整。缺口大小、爪深度、遮挡和视觉居中关系继续尊重批准稿与用户决定。

### 2.3 诊断必须服务当前选择

报告列举的网格指标适合作为工具库，不能变成修改前必须完成全币自交、全币封闭性和全部修复的巨大前置工程。优先检查会影响左上操作的壳层、邻接、可视性、根部和厚度。

独立浮雕附件、漂浮碎块不必合成一个watertight整体。不同构件按其职责验收；禁止为统一拓扑破坏原有艺术表面。

### 2.4 技术基底与艺术对象边界

新币坯、切割体和代理体可以参数化，属于技术支撑。爪的英雄形、关节与形面必须受完整稿图和旧母体约束。不能因允许局部重建，又恢复无参考的球管拼爪。

纪念币是符号主义作品，只补足动作可读、体积成立、接触合理所需的结构，不擅自扩展为完整动物身体或完整解剖教学模型。

## 三、建议的最小工程架构

### 设计依据与保护

完整批准稿 + 旧母版 + 必须保护的特征 + 当前需要改变的形体。

所有分件、局部放大与计算仍在整币坐标/尺度/相机关系下进行。新局部可编辑对象不是孤立的审美候选；最终候选始终是完整币。

### 可编辑资产

- 旧母版保持不可覆盖。
- 已认可头、眼、角、嘴、主体浮雕作为保护对象。
- 左上抓握/破缘是首个共同编辑单元，可包含多个网格或选择集。
- 币缘/侧背技术实体只在必要区域承担厚度与布尔工作。
- 碎块保留真实来源，后续再处理位置与表面。

高精度雕塑母版在Blender中保持可编辑；GLB是派生查看资产。拓扑不变用修改器/形态键；局部拓扑改变用独立完整场景分支，不强塞进形态键。

### 实际工作循环

解释目标形体 → 选择真实表面/根部 → 参考指导的大形调整或局部重建 → 实际雕塑 → 回读灰模与接触结构 → 对照完整稿图纠偏 → 整币检查。

需要的观察包括当前问题相关的正面/斜侧、对象归属和接触剖面；不机械要求每次全部贴图和全部通道。

### 能力验证

先证明操作能执行，再证明它能改善当前艺术目标。保护区检查只说明没有误改；修改顶点数、SIFT误差、导出成功都不充当雕塑进度。

如果工具运行正常但造型依旧明显不成立，应改变造型方法或引导方式，不继续依赖参数微调；也不为了显得进展稳定而把粗糙中间状态作为成品交用户筛选。

## 四、工具选择的实施判断

| 工具 | 现在的用途与判断 |
|---|---|
| Blender现有版本 | 继续作为资产主引擎；局部高级雕塑能力仍待实际验证，不能沿用Lattice通过状态 |
| BMesh / Trimesh | 优先满足当前面邻接、壳层、选择和来源诊断；已有原生功能够用时不重复引入库 |
| Open3D / PyMeshLab | 需要其专用分析或局部处理时再加入，不作批量安装清单 |
| Manifold / Blender Boolean | 对确认有效的局部实体操作；无法补救误分割与错误设计 |
| 官方Blender MCP | 官方页面已核实，要求5.1或更新；是控制候选。独立版本验证，不覆盖目前4.5.3工作环境 |
| PartField | 与当前碎裂连接/分件难题有关，值得针对性测试；输出为候选分组，不能自动升格为最终语义部件 |
| Prox-E | 有input_mesh与局部编辑路线，值得研究；当前接口以文字指令为主，不能假定直接按批准稿精确改造；需单独验证依赖及T4适配 |
| PartCrafter | 分件生成候选，不是已证明的旧网格精确保真编辑器；不作为当前生产主依赖 |
| TRELLIS.2 | 保留辅助生成/后续材质研究；本轮整币重新生成已否决，不再反复采样 |

主要本地工具可继续免费使用。本轮没有安装新软件、调用GPU生成或新增订阅；报告中所有尚未实测的工具/模型保持UNKNOWN或候选状态。

## 五、独立核查的依据

- [Blender官方MCP](https://www.blender.org/lab/mcp-server/)：直接HTTP读取200，明确5.1+，主要介绍Python接口、场景分析/查询与操作示例。未给出本项目高级雕塑成功证据。现有会话工具目录也没有Blender MCP工具，不能声称已经连接。
- [Blender 4.5 Sculpt API](https://docs.blender.org/api/4.5/bpy.ops.sculpt.html)：存在brush_stroke等雕塑算子。API存在不证明已配置并跑通本项目雕塑操作与审美结果。
- [Manifold官方说明](https://github.com/elalish/manifold)：实体输入有效性是必要条件；原始非流形输入可返回错误。其可靠性范围与报告判断吻合。
- [PartField官方说明](https://github.com/nv-tlabs/PartField#discussion-clustering-with-messy-mesh-connectivities)：明确讨论TRELLIS类网格的多连通/糟糕连接，提供预处理、KMeans和空间近邻邻接等途径；也承认部分难例仍效果不好。适合作辅助分件，而不是无条件信任。
- [Prox-E官方仓库](https://github.com/etaisella/Prox-E)：已有网格输入、文字编辑、SuperDec/上一代TRELLIS及VLM依赖。它提供相关编辑机制，但没有当前样币/T4/批准稿准确转译的已验证结果。
- [PartCrafter官方说明](https://github.com/wgsxm/PartCrafter#-system-requirements)：8GB为最低硬件说明，不是本样币质量、接触连续或局部保护的保证。

## 六、下一次工程的明确任务

先解释左上真实部件与连接，建立正确选择/保护；随后在旧副本完整场景中验证抓握与破缘的联合重塑。进入侧背或其他爪之前，至少达到：

1. 关节体块、抓握曲线和负空间出现接近正式稿图的明确改善。
2. 斜侧面能解释掌指与币缘接触，破口具有真实币厚。
3. 原眼、头、角、嘴与龙身体量保留。
4. 可回退，并能在完整灰模里展示改善；不是单独的新爪或仅成功运行的修改器。

如本地原生雕塑路线仍不能达到这些条件，再依据具体失败决定引入MCP控制、AI分件或AI已有网格编辑。没有新的能力证据时，不通过升级软件版本、安装更多工具或提高生成分辨率来宣称瓶颈已解除。
