# 仇视之龙：Kaggle 试样制作参考

2026-10-11。这是已有制作经验的整理与本轮试验计划，不是通过验收的生产协议。没有任何旧样品可以作为已合格成品基准。

## 1. 作品目标

用户指定：龙头向右转，近侧左眼放大并仇视观看者；左上、右下爪抓住币缘，指爪延伸到侧面及背面；左上爪捏碎部分边缘，对应碎片浮动；爪旁黑色魔气；口内红光及暗红色眼光。完整实体仍要读作纪念币，不能退成独立龙像、奖杯、厚饼或把平图贴在圆盘上。

左右以龙自身解剖、视角和头部朝向共同确定，不能把屏幕方向机械等同于解剖方向。眼神依靠眉嵴、眼睑、眼眶、瞳孔朝向和颧部紧张成立，红灯和放大眼球不等于仇视。

当前产品方向是单枚独立完整器物，旧展厅/图书馆场景不是本轮目标。依据：`../../second-language-maintenance/protocol/COIN_CRAFT.md`。本轮先验证制作与资产导出，不改正式认证或 PWA。

## 3. 已踩过的失败路径

1. **单图背面猜错**：另一面复制出镜像龙头。再精细的贴图都不能修复错误背面；后续应重建克制的独立币背，保留跨侧爪及受力压痕，或实测有真正多视角约束的流程。
2. **上爪圆鼓**：掌指关节气球状，抓握张力不足。应先改掌、指节、指腹接触及爪尖关系，不能全体撒鳞片遮掩。
3. **眼部历史判断已经被纠正**：2026-10-12 用户明确原眼没有问题；v4 增补眼球与竖瞳改坏了整体形态，已撤回。保留原眼，先理解完整龙头朝向和浮雕表达，不再据局部凹面判定眼球缺失。
4. **画面替代器物**：全息卡、整幅生图叠碎片/烟光已被否决。碎片须独立、有体积并吻合真实缺口；烟和光独立控制、遵守遮挡，不能烘在底色上冒充动态。
5. **生成成功、导出失败**：HF 旧流程分开申请生成和导出。xlarge 按双倍预留，剩余178额度秒仍不足以接受声明120秒的导出。只保存种子和预览不能恢复已丢失的服务器 state。
6. **硬件名称误导**：两张16GB卡不会自动变成单卡32GB；512连通试验不能冒称1536高标准作品；SDPA小张量通过也不能证明所有稀疏/体素/烘焙算子可用。

## 4. 本轮制作顺序

### A. 接入与短探测

先用私有 Notebook 查询实际 GPU、每卡显存、CUDA/编译器、FP16/BF16与基础 SDPA、外网连通。查询账号额度并保存前后采样；不凭广告假定30小时全部可用。探测不下载模型，也不生成艺术资产。

实际硬件若为 L4/A100 等满足原版条件，优先试微软原模型及低显存分阶段装载；若只有 T4/P100，另行验证精度、注意力与 CUDA 扩展适配。未经验证不直接把 BF16 改成 FP16并声称等质。不使用两卡显存总和作为放行条件。

### B. 环境与首个可编辑候选

只安装确认需要的依赖，固定源码/模型版本并保存编译环境；软件安装、权重下载、第一次编译的时间与推理时间分别计。Kaggle 保存输出与临时空间分开，权重/编译中间件不能把有限的 `/kaggle/working` 永久输出额度填满。

确认能用的低档配置只用于端到端验证：输入 → 网格 → 完整 GLB → 下载 → Blender 打开。随后提升细节做质量比较，不能以技术连通降低艺术要求。首轮复用现有概念图，不再额外付费生图；背景去除的依赖/许可证与效果须明确。HF Token 仅可用 Kaggle Secrets，不嵌入 Notebook、上传数据或日志。

### C. 灰模主形

导出后立即保存原件、散列、输入散列、种子、参数、源码版本、GPU/耗时及日志。先用中性灰材质、稳定柔光检视正、左右45°、侧、背与慢转。重点是币体厚度、头颈承接、敌意、爪握持与背面连续；任何关键关系不成立，先返工该部件。

允许各部件分网格，不为拓扑整洁破坏视觉。龙头、爪、币背、破口可单独修改/替换；避免盲目重抽整枚。已成功原件与失败过程保留，不覆盖唯一原件。

### D. 材质、特效与最终评审

主形成立后再做古银/氧化/断面/爪/牙/口腔分区；反射随照明变化，避免将画出的亮斑当金属。眼口红光、黑雾、碎片有独立对象/效果，并做开关对照。币外页面和正式交互本轮不动。

高模/源工程与实时版本分别保存；简化/烘焙前后对比眼、爪、破口、侧背。是否精品由实际画面和用户验收决定，不由面数、2K/4K纹理或自动检查宣布。

## 5. 执行和恢复约束

- 本机新增数据全在本目录及既有 D 盘路径，C 盘本次检查仅约0.30GiB可用，不在本机下载大型权重或 CUDA。
- Kaggle 是计算试验场，不是永久资产基座。完成后立即下载 GLB/材质/必要中间件到 D；正式采用后再按 OneDrive 资产合同归档。
- 初次提交前写提交意图，断网或响应丢失先查原 Notebook 状态，不重复提交猜测成功的任务。
- 仅使用正常账号与免费额度，不购买套餐、不绕过手机验证、不用多账号拼额度。
- 技术结果逐步标记：接入成功、GPU探测成功、完整生成导出成功、艺术合格是四个不同状态。
- 当前另一份 HF 免费续作仍独立等待已知刷新；不得为 Kaggle 试验中断或冒充其结果。
