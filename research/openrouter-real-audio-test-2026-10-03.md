# OpenRouter 充值后的真实原声试验

日期：2026-10-03。本记录接续 `openrouter-account-and-audio-trial-2026-10-03.md` 的零余额试验。用户确认单次购买入口显示微信、支付宝，并授权继续测试；API 已确认 $5 credits 到账。未确认用户最终选择了哪一种付款方式，不由到账推断两种渠道均已付款成功。

## 选择与边界

采用 `qwen/qwen3.8-omni-flash`，实际上游为 Alibaba；两次独立请求，关闭提供商自动 fallback，没有调用 Google/OpenAI/Anthropic，没有修改账户地址或试图绕过地区限制。此前截图确认的三家模型限制没有在本轮证明解除。

本轮重新阅读免费端点页面，发现 [NVIDIA 免费入口](https://openrouter.ai/nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free)与 [Inkling 免费入口](https://openrouter.ai/thinkingmachines/inkling:free)明确要求不要上传个人声音等个人数据。因此本人录音不继续采用这些免费入口；首次 NVIDIA 音频请求停在余额网关，没有收到模型结果。不能把充值后优先上传免费音频当作既定方案。

[Qwen 官方模型页](https://openrouter.ai/qwen/qwen3.8-omni-flash)列音频输入、文字输出；请求按 [OpenRouter 音频协议](https://openrouter.ai/docs/guides/overview/multimodal/audio)发送 base64 WAV。密钥、原件、转换音频、用户确认稿和完整模型返回保存在本机忽略目录，不提交仓库。

## 真实作答：HTTP 200

使用既有 76.796 秒真实录音的 16kHz 单声道 WAV，未向模型发送用户确认稿、范文或旧识别结果；要求先逐字转写，再区分声音观察与文本建议，禁止编造音素分数、时间定位和雅思 band。

请求用时 26.433 秒，正常完成。原先需要核对的“one by one”、结尾“future career”等内容正确识别，没有腾讯结果的广泛语义替换。按先前相同的小写、去标点、拆连字符口径，与用户确认稿比较：参考 149 词，输出 153 词，词级编辑 4 次（约 2.68%）。四个差异均为额外的重复或不完整片段：`diffi`、`stay`、`pract`、`solu`。这不等于四处识别错误；确认稿可能省略口语卡顿，也不等于发音错误率。仍未由独立听审逐一核实所有片段。

同一参考口径下，之前 Whisper 为 5 次编辑（约 3.4%），腾讯自由说为 74 次（约 49.7%）。当前单样本支持 Qwen 转写有用，不宣称它对所有作答优于 Whisper。

## 声音对照：HTTP 200

为检查音频通路是否处理声音信息，建立一个本机独立对照文件：先放三声短促 880Hz 提示音，再接原件从 62 秒起的讲话；原件没有被修改。提示只要求转写并描述讲话前的非语言声音，未告诉模型有提示音或其数量。

请求用时 8.872 秒，模型正确报告三声高音电子提示音，并识别片段结尾。这为“输入不只是模型猜测的口语文本”提供具体证据，但不能据此证明音素或韵律诊断准确。片段中的转写和整段有细节变化，继续保留两份原始结果，不机械认定所有重复都听准了。

返回 usage 两次均把 `audio_tokens` 记为 0。该元数据不提供独立音频 token 明细，既不据此断言音频未被处理，也不套用 Gemini 的 32 tokens/秒估算本模型账单。以具体请求的 usage.cost 和账户记录分别保留费用证据。

## 声音反馈的质量限制

Qwen 给出了卡顿、语调较平和词尾清晰度意见，但原始意见不能直接批改：

- 将“语调较平”进一步推断为读稿或背稿，没有足够依据；不向用户作这种归因。
- 使用 stuttering 等术语，不据此诊断口吃；教学反馈仅描述待核对的重复、停顿。
- 用 developed 的“d 结尾不明显”作为发音问题，标准本身错误。该词为 /dɪˈveləpt/，词尾 /t/。[Oxford 词条](https://www.oxfordlearnersdictionaries.com/definition/english/developed)
- 本轮没有独立听审来验证具体误音、重音、音高变化，不把模型自报 High confidence 当作验证结果。

结论：认证、付费原声通路和转写的初步实测通过；非语言声音对照通过。可作为“原声 + 转写 + Codex 筛选反馈”的候选，不能把供应商原始评价全部显示给学习者。准确音素诊断、韵律评分与雅思口语完整 band 尚未验证，Azure 学生通路仍保留。

## 用户追问后的其他模型试验

用户进一步授权比较其他模型，并询问能否由供应商返回分析数据、Codex 负责教学判断。继续使用同一 WAV、相同提示、不给确认稿；新增模型输出预算为 4,096 tokens，Qwen 首次为 2,300，均正常完成的输出没有被截断。提供商自动 fallback 关闭；不把不同提示引起的差异混作模型能力差异。

| 模型 | 调用与结果 | 相同参考稿的词级编辑 | 单次实际模型费用（规划人民币） |
|---|---|---|---:|
| Qwen3.8 Omni Flash | 前述完整录音请求成功 | 4/149；四项为额外卡顿片段 | ¥0.00459 |
| MiMo-V2.6-Pro，经 DeepInfra | 成功，48.360 秒；声音意见更谨慎，但出现原话替换 | 9/149，约 6.04% | ¥0.01485 |
| Inkling 付费版 | 两次 HTTP 200，但没有模型结果；第二次保存 raw，仅 44 字节空白，无 JSON、转写或 usage | 无可比较结果 | 未收到 usage |
| Voxtral Small 24B | 两次 HTTP 429，Mistral 上游临时限流 | 无可比较结果 | 未收到 usage |

MiMo 将 learned 换成 mastered、改写 complicated problems 与结尾，还把 not only / but also 的连接转写错后据此提出语法批评。用户确认稿和较可靠的 Qwen/Whisper 在这些地方支持原来的表达；不将该意见当作学习者实际语法错误。9 次编辑也不等于 9 个发音错误。MiMo 对细微音素不确定性的表达更稳妥，仍不能因此认为它更准确。

未收到结果的两个模型只判定当次入口不可用，不判定声音质量差；Voxtral 已按上游提示短暂间隔再试一次，仍限流后停止。Inkling 在一次响应无法解析后保存 raw 复查，仍为空白；不把 HTTP 200 当成成功。本轮不为这些入口继续开账号或充值。

全部本轮 OpenRouter 请求包括 Qwen 两次、其他模型五次，共七次。实际收到的 usage.cost 合计 $0.00296717，规划人民币约 ¥0.02077；最后账户 total_usage 同样为 $0.00296717，余额约 $4.99703。未返回 usage 的失败请求不单独编造费用，合计账本与已知成功请求相符。若重复这次 77 秒完整作答，30 次/月的样本外推为 Qwen 约 ¥0.14、MiMo 约 ¥0.45；不是固定月费，也不含手续费。

模型属性依据：[Inkling 付费入口](https://openrouter.ai/thinkingmachines/inkling)、[Voxtral](https://openrouter.ai/mistralai/voxtral-small-24b-2507)、[MiMo](https://openrouter.ai/xiaomi/mimo-v2.6-pro)。真正的价格证据为本轮 usage；不从参数规模、榜单或输出措辞推断语音教学质量。

## 数据与教学判断的可行分工

本轮回读既有 Cloudflare Whisper 返回，发现 `segments[].words[]` 已有 147 个词的 start/end；都在 76.796 秒录音范围内，但未由人逐词核验。可用于近似词级回听候选，误识别词和时间边界需回听确认，不能宣称人工对齐精度。此前“无词级时间”的说法仅适用于腾讯/Qwen 本次返回，应避免扩大到整条系统。

另对未改变的 WAV 用本机 ffmpeg 作一次声音能量分析：silencedetect，阈值 -35dB，最短 0.3 秒，得到 20 段阈值静音、合计约 11.064 秒。这是声音测量，包含开头、末尾与自然停顿；不等于 20 次犹豫、不直接评分流利度。完整分段结果只在本机 cache。已建立的数据摘要见 `outputs/openrouter-model-comparison-2026-10-03.json`。

可行通路：保留原声 → ASR 转写与时间 → 本机可复算的时长/静音数据 → 音频模型提供少量声音观察及原话依据 → Codex 对照题目、已确认转写、词典发音规则与证据生成反馈。各项记录来源和是否核对，不让模型生成的“数据”冒充测量值。词汇、语法、篇章与练习建议由 Codex 判断；具体误音、重音和语调问题需要有效声音证据，证据不足时只提供可回听核对点。

当前音频模型没有提供经过验证的音素分数、词汇重音指标、基频测量或完整雅思 band。让 Codex 二次处理可以过滤词典规则错误、ASR 引入的语法假问题和过度归因，不能修复没有被正确观测到的声音事实。Qwen 暂作为转写与候选观察最实用的入口，Whisper 时间用于辅助定位，Azure 专用评测仍值得后续实测。
