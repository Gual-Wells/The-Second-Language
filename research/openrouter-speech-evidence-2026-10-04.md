## Qwen 多次补听的实际价值与限制

字面专项留下 diffi-difficult、ass-assignment、stay stay、sol-solution 等碎片；韵律专项则遗漏这些修正。片段专项先称 developed 的词尾缺失、through 的 /θ/ 接近 /s/，后续明确最终 JSON 要求的复听又认为 /pt/ 存在且属于弱化、/θ/ 可辨。这些分歧全部保留，不能用多数票或平均意见解决。

更严重的是语言学前提错误：某次报告声称 computer 主重音在第一音节、assignment 在末音节，并讨论 focus 中不存在的 /t/。另有未经测量的百分比时长变化。此类解释不能作为教学诊断；Schema 合格和模型自报高信心均不能挽救错误前提。

因此 Qwen 的作用是廉价补充不同目标的候选资料。每次保存目标、范围、上下文与完整返回；若附校对稿或他路结论，标明条件化。同一模型复听不增加独立证据来源数量。腾讯不足时可用它补充定性观察，不补造音素分值或校准重音。

## GPT Audio 的工程验证

实际首次生产要求只得到“将进行分析”的确认句，虽 HTTP 200 且产生费用，也不能计为完成。补充明确要求当前响应直接返回最终 JSON、不得确认/等待后，新的正式请求成功返回逐字稿、11 条具体声音观察、12 项已检查维度与限制；此请求约 ¥0.252。

GPT Audio 使用 `modalities: ["text"]`，不发送 response_format；最终 JSON prompt 与本地结构校验负责读取，原文保留。OpenAI 官方当前标示该模型不支持 Structured Outputs，并列为 Deprecated；OpenRouter 本轮仍实际可调用，协议保留将来迁移接口。其“低不确定性”仍只是模型判断。[OpenAI 模型文档](https://developers.openai.com/api/docs/models/gpt-audio)

它与 Whisper 都源自 OpenAI。当前四次请求包含三份声音观察，不能称为四家独立听审。主路增加依据是本样本的增量资料与可接受费用，而非它能直接给最终诊断。

## Whisper 额外能力试验

使用同一完整录音，测试 beam_size=10、condition_on_previous_text=false。转写反而出现更多错误，且没有解决既有 whenever/communication problems 分歧，因此维持默认 beam 与历史条件；不把更大解码搜索当作必然质量提升。

原生返回仍完整保存词/段时间、VTT、transcription_info、usage、avg_logprob、compression_ratio 与 no_speech_prob。后几项是识别统计，不是发音正确率。initial_prompt/prefix 是解码提示，不能要求它分析口音、语调或 IELTS。单次费用按公开每分钟价格估算约 $0.000657，Cloudflare 免费额度与实际账单另核对。[Whisper 官方参数与计费](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/)

## 腾讯新增能力与失败修正

从连续原声裁出 computer，0.66 秒。尝试 5 次：前两次沿用流式分包导致代码 4015，修正 rec_mode=1 为一次发送完整二进制包后，三个专项均获得终态成功返回。失败包也完整保留。

- 单词模式 0 + F_P2L：实际得到 8 个音素、8 个字母映射及非默认重音字段。
- 单词纠错模式 4 + F_P2L：增加参考音素、检测音素及字母映射。
- 单词纠错模式 4 + F_IPA：得到 IPA 形式参考/检测音素及重音，未返回字母映射。

这是现有模型之外的有用结构化资料，保留为争议单词/短句专项。它不接受通用分析 prompt，用评测模式、本人原话与接口参数控制。两种指令目前分别调用，组合指令没有实测，不开放组合请求。[腾讯模式](https://cloud.tencent.com/document/product/1774/107373)、[单词纠错](https://cloud.tencent.com/document/product/1774/107390)

录音边界来自尚未人工校准的 ASR，切点/相邻词可能影响结果。返回部分音素边界超过 660ms 音频，不能建立有效跳转。模式 0 与 4 的分数表现出不同量纲，必须分别保留，不能混算或直接转成 IELTS 分数，也不能依据此裁词低分判定实际误音。腾讯 API 未返回本次套餐收费明细，不把成功请求写成零成本。

## 采用的闭环与成本

默认完整录音 → **Whisper + Gemini Flash + Qwen + GPT Audio** 独立采集 → 保存全部返回 → Codex 全量接管与核查 → 按具体问题追加 Qwen/GPT 或腾讯专项 → 教学反馈与重答。Qwen 不限固定次数，但每次须有具体目的；新增模型将来可以继续成为固定主路。

以这份 77 秒录音的旧标准 Flash/Qwen 实扣和本轮正式 GPT JSON 实扣作组合预算，加 Whisper 估计约 **¥0.37/次**；较宽松地预留 ¥0.4–0.5，十份同等长度答卷约 ¥4–5，专项另计。这是跨次样本规划估计，不是已实际跑完一次新四路任务的统一账单；长答卷、输出长度、价格变化均会改变成本。不以该数字承诺完整 IELTS 多轮考试固定价格。

遇 OpenRouter 402：已完成调用落盘，声音任务 waiting_credit，首次等到北京次日。后端检查真实钱包和 key，两者可用才续作；未充值则每小时轻量核对。仅重启明确余额失败/缺失调用，不重复支付成功调用，未知收费状态不盲重试。其余日课、阅读、写作不暂停。没有因缺钱把缺资料的口语反馈标成最终完成。
