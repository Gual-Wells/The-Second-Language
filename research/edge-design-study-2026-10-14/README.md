# 币侧重新设计：真实结构与三种工艺方向

2026-10-14 · 设计研究与实际几何试样。基准main@42f31647506f9f5d03d00c1e6945796b12f2f4e4。

## 结论

旧v5图中的侧面不能作为结构依据：斜纹段、亮面段、两侧高亮边轨缺少一致的周期、槽形与截面定义；正背视图外圈的细齿又没有与侧视图一一解释。局部亮暗还可能只是反射，不能把每块亮斑都解释成一个金属构件。

本轮先把侧缘设计建立在真实工艺和完整几何上，给出三种可比较方向：
- **A 连续直边刻**：144条轴向浅槽，规律连续，币章识别最直接。
- **B 间断直边刻**：12个周期，每周期20°刻槽＋10°光面，共96条槽；推荐优先进入整币设计复核。
- **C 细缎面光边**：完整连续侧壁与窄圆肩，安静、简洁，作为保留选项。

这不是“装饰越少越正确”的宣言。斜纹、交叉纹和边铭并非天然不成立；只是当前稿没有清楚设计它们。新方案优先解决实际结构、节奏和与繁复币背的配合，不强制用户从三种中选择。

## 先定义一枚连续的器物

沿用已有工作尺度：名义直径40mm，field到field厚2.8mm，两面包边各高0.2mm，总包边厚3.2mm。它们是工作规格，不是用户已批准的永久行业标准。

正背衔接采用同一完整环截面：平场 → 面内窄包边 → 外侧圆肩 → 侧壁 → 另一面圆肩和包边。两面亮边是同一币体表面的抛光/曲率反射，不是粘贴的铁丝或两片夹壳。侧壁不鼓出半径20mm之外，没有随机大切面、浮空斜片或上下错位的包边。

新几何取面内平场半径19.2mm；包边顶平段约19.42–19.85mm；外肩以若干固定圆滑段过渡至半径20mm的侧壁。外肩约0.15mm尺度，当前是设计近似曲线，不虚称精确恒半径刀具圆弧。

## 槽形与退出方向

两种有槽方案共享单个槽形：径向深0.10mm、周向宽0.30mm，圆滑raised-cosine凹槽；相邻槽的周期2.5°，在40mm直径处周向节距约0.873mm。槽轴线沿币厚方向，而不是凭视图倾斜。

关键约束：
`r(θ,z) = min(币体截面半径(z), 20mm − 槽深(θ))`。

因此槽贯穿侧壁，在圆肩半径收小后自然终止。退出方向上没有藏在满径肩部后方的封闭短槽。早期内部试样曾把槽在两端提前封口；复盘后发现这会给普通闭合圈模的轴向退出带来干涉风险，已撤回该截面。若未来选择封闭短槽，需要明确分瓣模、铣削等路线。

这是一项几何上的退出包络检查，不是材料流动、摩擦、回弹、模具寿命或真实压印的仿真证明；量产参数仍需制造端转译。数字作品的越界龙爪、缺口等也不必为了闭合圈模削除，可分别安排铸造/后加工或保持数字表现。

### A：连续直边刻

全周144槽，无接缝槽，周期360°恰好闭合。节奏稳定、传统币感明确。风险是与币背繁复边饰叠加后略密，低分辨率显示有细纹闪动可能。模型中的槽真实存在，不能把缩小时闪烁再交给随机噪点掩饰。

### B：间断直边刻（当前研究建议）

全周12周期，每个30°；前20°放8条槽，后10°留同半径的光面。槽深、截面与A完全相同，只改变分布，因此比较有意义。光面不是任意切出的平面：它仍然是圆柱弧面，不是多边形腰封。

这给复杂币背提供有节拍的明暗间隔，也保留旧侧稿“纹理与安静区域交替”的有用意图。把原本不可解释的斜纹块替换成可重复的工艺模块。为何12周期：均匀、在不同观察角度能看到纹/光交替；不把12解释成月份、等级或用户未确定的象征。

### C：细缎面光边

无槽、无边铭，靠圆柱体、圆肩与表面粗糙度形成光线。省去重复纹，不等于低质；它的质量依赖轮廓、面差、抛光界面与环境光。适合以后木质、石质等材料的另行适配，但本轮只是银色金属候选，不假定所有材质必须同工艺。

## 表面处理设计

三版同一金属、同一摄影条件：侧壁roughness 0.27，圆肩0.18，空白场0.32。金属与粗糙度是渲染工作值，不能直接当工厂Ra数值；没有贴上“0.27μm”的错误规格。表面不加凹凸噪声、假裂缝或随机斜划痕。

最早灯光过曝，槽底和圆肩被吞掉；已降低曝光重做。全景和细节是同一几何与同组灯光。暗槽来自形体与光照，而不是一条条黑色贴图。当前缎面用微表面粗糙度表达，尚未制作方向性金属刷纹。

## 实际模型、可复核性和阶段边界

- 使用现有Blender 5.1.2和原生Cycles。这里是尺寸可规格化的币胚/侧缘技术设计，不是脱离AI稿直接用primitive发明龙、书徽或艺术币背；符合此前“先有完整视觉依据”的约束。
- 每版都是包含正面平场、背面平场、两侧包边及侧壁的完整封闭币体，不是悬空边条。两面故意用无图案平场，避免用程序伪造已选艺术。v5完整币背作为上下文对照，未重新设计或覆盖。
- `outputs/*-whole.png`：整币低角度观察；`*-detail.png`：同一币前缘细节。非diffusion概念图。
- `outputs/*-edge-study.blend`：可编辑实物几何试样；没有宣称这就是已完成艺术正背面的完整成品。
- `geometry-checks.json`记录实际网格槽数、封闭边、体积与尺寸；另行读取保存模型核对退出包络。通过这些不等于艺术验收。
- 工作坐标暂以Z为币厚轴，保存毫米转换后的真实米制网格；它不是规范艺术母版，不默默改写原canonical的-Y/+Y面向约定。接入时做明确坐标变换。
- 模型用公式构建可重复槽，引用现有成熟渲染和网格工具；没有新增插件、订阅或云GPU消费，也未接管其他Blender工作室。只启动本任务隐藏进程，CPU限4线程，配置、临时、日志和模型均在D。
- 推荐B进入整币试样复核，A/C保持可选。用户还未最终选定，不把这份工作参数立即升为全项目永久标准。

后续应将选定侧缘作为整币生成输入中的明确结构约束；正背图中的外圈投影也要与之协调。仇视之龙的爪、裂口与跨缘部分按认可艺术保留；不能为恢复规则边缘而填平缺口、切掉爪或复制侧面纹样穿过破坏区域。
