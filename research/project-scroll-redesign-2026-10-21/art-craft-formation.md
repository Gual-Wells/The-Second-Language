## 4. 素材与年龄设计：v6为什么不是“加一点旧色”

### 4.1 原始资源与程序旧化先被分开

v1 `document.js`复用cron旧纸的完整裂口／色斑／褶痕，旋转横幅作为竖纸；Aboensis另画在ink画布。细小墨损只作用于墨层，不把底材改成随机噪声。

v2 `ageSkin`进一步试出分工：位置相关的边缘／角部接触色差、靠外缘浅潮线、短不规则手持线与独立小幅heightMap。它还筛掉了“高分辨率但像织物”的候选资源。这里留下的经验是**先判断原材是什么、旧痕在哪里、什么层负责**，不是以后必须复用这些正弦线或径向渐变。

### 4.2 v3→v4：从漂亮手稿材料转向古旧文书

v3正面prompt要求象牙中央、边缘薄损、局部旧水痕、细膜纹、少量古花饰／双红界线。实际源画确实是一张彩饰边框明确、中央较匀浅的纸。用户指出过分花哨、做旧过克制后，v4编辑以**同一资产**为起点去全部花饰／界线，并重排多尺度年龄：边角深处理、旧水晕、磨薄、折谷、微裂口与厚薄。它还明确去掉会让纸像“几段拼接”的成对侧缺口。

但v4源画可见大而接近圆形的水印、明显灰褐脏角与重复的小黑点；用户随后评价为脏污。这说明具体痕迹的形态／尺度／分布需要重新设计，不等于“有水痕都失败”或“用户不要脏痕”。

### 4.3 v5：去脏指令过度，损失了年龄信息

v5的实际prompt含有明确的“REMOVE ALL ring stains, tide marks, greasy grey-brown patches, speckled dirt”要求。它保留细密皮纹、窄亮折脊与浅暖纸色，但把大片年龄色差一并删掉。实装又继承强光／ACES／非金属反射。结果在源材和显示两个阶段都趋于过洁、过亮。用户明确指出两版实际展示都削弱了做旧、纹理、折痕与污损。

所以不能只把v5的“别脏”换成“更旧”，也不能用更多边缘裂口补回被清除的色差。必须分别修材料信息与呈现传递。

### 4.4 v6：回退正确材料方向后，再逐项分辨年龄

v6第一轮输入重新取v4纸面，强调保留旧折脊、干皮纹、手持痕、旧湿痕；把咖啡圈改为不规则灰褐旧潮线，并彻底重做大段刀裁边、斜切角、小缺口／短裂口，避免等量扇贝边、圆角和整圈焦壳。该候选的深斑又产生霉变读感，用户直接说不要发霉。

最终编辑只移除黑点、菌落状灰黑颗粒与腐败读感，同时保留暖灰棕接触变色、旧折谷积尘、透明漫散旧潮线、细擦薄、深浅厚薄及明确手裁边。实际v6源图仍有大尺度不均匀旧色、多条折痕和清楚的细纹，中央并未退回干净办公纸。

| 痕迹种类 | 应设计的关系 | 历史失败及纠正 |
| --- | --- | --- |
| 旧水痕／年龄色差 | 不等尺度、不规则、局部；与边角、接触／暴露区有关 | v4近圆大水圈容易显脏；v5全部去掉又失去年龄；v6保留暖色、渐变自然的旧潮线。 |
| 手持／接触暗润与擦薄 | 暗润、变薄、浅擦相互存在，集中于合理可触处 | 均匀脏角或全页随机污点不成立；不能为中央“可读”把所有痕迹清空。 |
| 旧折痕 | 有折谷、压力、受力痕与局部微损；数量／位置服从整张纸 | 亮脊本身不等于古旧，增加折痕数量也不等于提高工艺。后续需与文字和真实卷曲一起看。 |
| 轮廓 | 大段完整刀裁边、局部不直、少量角损／短裂口 | 不是四边等量撕裂、焦壳、扇贝边或现代圆角矩形。 |
| 微纹 | 细膜纹、刮削、微薄损与厚薄变化，有完整层次 | 高频噪声不能代替材质；纹理过细或光照洗白后消失，也不等于“高清”。 |
| 生物霉变 | 从本项目艺术目标中去除 | 不是“更敢做旧”的手段；去霉须精确针对其读感，不把暖旧痕一起抹掉。 |

这些是设计关系，不是要复制v6每一条折线、每个水痕与缺口。新纸的轮廓、痕迹组织必须属于新构图；比较基准是达到相同的材料／年龄层次与显示保真。

## 5. 表面、卷曲与光照：原稿旧痕为什么会在demo里丢失

v4已有一项重要改革：不用纸的明暗／色斑直接当height。低幅许可扫描normal／roughness只提供微观肌理，不把水斑全部鼓成浮雕。它是近似工艺，不是该张羊皮的物理扫描反演。

v5提高DPR、排字画布并删除墨层／CSS模糊，仍没有解决强光洗旧。v6 `scroll-object.js`实际同时改变了以下环节：

1. `NoToneMapping`与固定exposure避免ACES对已设计底稿再分级；灯光改为中性控制。
2. `sheen=0`、`specularIntensity=0`、高roughness、低环境贡献，防止纸像亮布或被镜面漂白。
3. 在近正视区域把动态出射颜色与原稿diffuse作有限混合，最高保留45%的原稿明暗参照；弯曲卷层仍使用动态漫反射。这是为已有艺术材质做的显示保真补偿，不能宣传为完整物理标定。
4. 小幅扫描微表面与基色分工；颜色旧痕不直接驱动大几何。
5. 残余卷边／起伏在卷绕接点两侧用同一变形函数；法线与depth shadow也跟随相同位置变形。修掉了最后一圈的非连续白线，而非拿雾或高光遮掩。

已读实际关键位置：`web/labs/chapter-scroll-v6/scroll-object.js:37–80`；连续变形及法线位于同文件前半段。`check-scroll-fidelity-v6.mjs`与`fidelity.json`比较相同UV／物理面积的原稿与GPU输出，辅助确认宽尺度旧痕能否保留；它不评文学、材料真实性或美术合格。

本轮实际查看v5／v6的源材与`open-native.png`，可见两者实装年龄色差有明显差异；但源材同时也变了，不能把全部差异归因于shader或某一参数。正确流程是固定某一层再判断另一层，避免“换纸后截图更旧”就宣称某个受光算法成功。

## 6. 墨、印、字体与布局：v7—v12并没有另换一张纸

### 6.1 真实字形不等于版式自动成立

v1就使用Aboensis真实字库。v3／v4另加轻微吸墨晕染；v4把折线附近墨层磨耗与其他区域分开。v5删去全局字迹模糊，提高排字画布与实际显示清晰度。v7混用Uncial后，用户认为字体风格回退，v8恢复所有纸面字为Aboensis。

v11同样使用Aboensis且做过实际行距修订，仍因大姓名、机构标题、授予条款、章名和正方印的层级而被否决。`document.png`可清楚看见同一种材料上出现的视觉失衡。因此字库正确、纸胚正确、没碰撞，均不能独立证明整页作品成立。

### 6.2 印模、沾墨、余墨、渗晕和压痕是不同工序

v7把项目现代开卷轮廓作圆印中心，图像／字库／纸面语言不协调。v8转线刻和不均压力，增加独立印痕高度；实际还修了Three中normalMap优先导致bump看似接入却未呈现的问题。v9又加入粗细不均环线、固定印模小伤、接触不足、局部干印、窄晕与纸上压力，但用户仍指出墨浅、余墨被约束在图案内、图标现代。

v10没有继续把整个印章模糊或降透明度：古书版刻与肩部余墨分别制图；字母继续真排；余墨可以越过印圈。程序将图源取为印模／接触密度，再合成深褐近黑墨。`ink-transfer.js`的`opticalInk`按原纸颜色作密度衰减，保留纸纹；纸的压痕来自独立mask，不由实际缺墨层代替。缺墨处仍可受压。

v12小长方藏记继续利用这些工艺：

| 层 | 实际代码／素材职责 |
| --- | --- |
| 稳定印模 | 真字库写两行固定印文，手工边界与少量固定划伤。 |
| 该次接触 | `transferMasks`在冻结种子下计算局部接触和缺墨；重开不换一枚印。 |
| 肩部余墨 | 复用v10独立`ink-shoulder.png`作为材料密度，与图案边界分离。 |
| 微渗晕 | 窄晕层保留锐利核心；不整体模糊或把整印变浅。 |
| 纸上受压 | 从印模mask独立合成relief，与墨覆盖分开。 |
| 成品落印 | `impressSeal`通过opticalInk融入实际纸面，再以relief进入表面。 |

来源：`web/labs/chapter-scroll-v10/ink-transfer.js`、`chapter-scroll-v12/seal.js`。这就是多个成熟／原生工序组合成同一纸面，而非一张带旧色的PNG贴上去。

### 6.3 文书定位的纠错，比套古词更根本

v9实际文字包含河流／森林／洪灾介绍、让读者理解语境的寄语及样品说明；用户逐句否决。v10逐句重新划分通过事实、授予、印证的职责，纠正了文本不合格，但也导向v11机构证书的过度中心化。v11试图用最大姓名与具名授予形成私人联系，反而挤掉艺术主体。

用户52985随后明确：要的是测试激励下的艺术纪念品，不是权威；要与章节联动，但不能被教学剧情污染文学质量。v12研究因此重新通读完整章节、对照相邻章，选择“地图线／真实水域”关系，排除泛泛庇护／勇气格言。题辞是独立散文，姓名进尾记，小长方／圆藏记在相同纸面比较。

v12代码用真实量字、题名分行、正文底边上限与归属分行；样品日志记载看整页后缩小藏记文字、避免Chapter／I断开。最终用户53360直接肯定长方印和文书。这里成功的是来源、文学、图像、书写层级、材料和墨印的整体关系；不是仅把v11大方印改成长方。

## 7. 整条工艺链应怎样被继承

| 环节 | 必须回答的问题 | 只看成品／只抄prompt会漏掉什么 |
| --- | --- | --- |
| 素材／资源选择 | 原材是皮膜还是织物？哪些质量可以保留？哪种任务交给成熟资源／生图／程序？ | 高像素、知名库、museum-quality形容词不能保证适配。 |
| 该张纸的年龄与轮廓 | 哪些是水痕、接触、折谷、擦薄、刀裁和角损？位置、尺度和变化为何协调？ | 复制成品伤痕，或随机加旧色／噪声，均不会形成新纸的合理经历。 |
| 图文设计 | 来源关系、题辞、主体图像、留白、归属如何一起组织？ | 独立生成一张纸不保证它适合该件文图。 |
| 真排印与墨 | 实际字形、分行、浓淡／细损、藏记大小、余墨及压痕如何融入纸纹？ | 字库加载和坐标通过只是基础；现代图标、浅墨贴片与权威层级仍会破坏艺术。 |
| 表面与动作 | 哪些进基色、微表面、几何？变形、法线、投影是否一致？ | 把色斑当高度、画假褶影、接点白线都会改变纸张读感。 |
| 实装受光 | 原稿的旧色／微纹／墨层在正视与弯曲中是否仍能看清？ | 正面原图漂亮或shader有PBR名字，都不能证明显示保真。 |
| 实际艺术判断 | 同尺度的源纸、排印原件、实际展开、细看分别说明什么？用户最新否决在哪一层？ | 程序检查通过不能追认主题／艺术，更不能用一个局部改进宣布整件已合格。 |

继承的是上述判断与工序的协作。新图数量不是工艺深度指标，也不要求为了复盘机械重跑每一代失败：先识别当前候选具体缺在哪一层，再保留正确资产、回到对应环节修订。第一章最终母材用于帮助看清达到过怎样的材料层次；它不是必须克隆的成品，也不是向工具传一张reference就已完成工艺。
