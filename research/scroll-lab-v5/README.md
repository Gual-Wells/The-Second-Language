# 第五版制作与实际边界

2026-10-17；工作起点 `codex/medieval-scroll-lab-2026-10-16@5edacd1`，起点干净。仅独立样品与作用域样式。旧样品不覆盖，生产主分支不部署。

## 六项反馈的处理

1. **清晰度与帧率**：v4实物DPR上限2，闲置雾染40ms门槛，墨层0.6px低权重模糊。本版实物DPR3、2048×2868真实字体排版、去除墨层和CSS整体滤镜；GPU变形代替每帧CPU重算法线。雾染512染料场、DPR最高2，仍是低频气氛层；不为了烟雾牺牲字迹。检查记录实际画布尺寸，软件WebGL耗时不冒称手机帧率。
2. **雾染可见性**：v4没有关停求解器，但供雾距离、速度、强度导致画面过淡。v5输入移到可视边界外侧附近，持续非脉冲供雾，恢复涡流；只注入少量运动速度，不在开卷时喷更多雾。本次验证对实际舞台截图开/关作比较，而不只验证计数器和离屏染料像素。
3. **古旧而非污脏**：原大块水圈、灰褐脏角移除。以干燥细皮纹、窄压折、边缘薄损表达年久；保留正式书写区。图像仍为美术素材，不说成真实古羊皮扫描。材质像素1024×1536，字迹画布2048×2868，二者分开陈述。
4. **皮扣动作**：选择小规模Cannon-es质量弹簧而不是引入完整服装模拟/新引擎。已认可外观保持；中央铜框不随皮革网格弯折，取环时存在惯性滞后与阻尼。没有完成解扣舌、拉出带尾、皮带自碰撞等全过程，不能把这一轮称作完整物理解扣。
5. **规格与排版**：300×420mm名义规格；左右各约34.1mm；12行正文，字号根据真实行宽有界适配，正文与署尾不重叠。Aboensis仍是正式手稿启发，不声称唯一中古正式字体。现代证书式居中标题是当前纪念产品的设计选择；如果用户要严格历史复原，下一轮需先选定年代、地区和真实文书类别。
6. **长期卷藏形变**：参考鲁汶修复实践而非自行宣称普遍定律。展开时仍有上下端小幅卷边、不对称边部起伏；文字随表面而弯，不在材质上画假阴影。具体曲率是可调艺术参数，非实测。

## 资源选择

- 已在此前核对的NOQTA完整绑定道具仍未购入；其双轴结构与现有皮环不同，本轮没有假装获得现成解扣动画。
- 本轮再次核对Mesh2Rig官方扩展说明：能把变形烘焙成骨骼，但它不是优质古卷资产，也不会自动设计扣具。本轮不安装它来增加与目标无关的流程。
- Cannon-es源和官方Spring API已阅读，取0.20.0版本文件并随附MIT许可。直接复用成熟求解器；动作用途和2.5D限制见页面来源。
- Paperlab、Pavel、Three、字库、HDR、扫描表面沿用已有固定来源与许可。
