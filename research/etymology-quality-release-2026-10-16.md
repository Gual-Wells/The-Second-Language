## 用户确定的教学尺度

- 词源集中一级词头下的同一区块，简洁分点，帮助理解和记忆；不强制对应教材义项，不追求学术完备。
- 双教材同一用法统一讲解，保留互补限制、独有义项及全部相关原例句；不以融合减少教学覆盖。
- 词源不新增 USE、例句或范文覆盖任务。既有课程、收费音频、答卷和来源版本不自动改写。

正式协议：`ETYMOLOGY.md`、`CONTENT.md`、`QUALITY_WORKFLOW.md`、`ANNOTATIONS.md`、`DAILY_RUN.md`、`CHAPTER_QUALITY.md`；任务入口、章节测试提示和界面约定同步引用。

## 工程组织

| 层 | 实现 |
|---|---|
| 资料 | prepare-vix 取得词源说明及 manifest；textbook-sources 校验固定 VIX Git blob，保留原文 UTF-8 字节范围与摘要 |
| 查阅 | lookup-textbooks 按主词/相关词定位全部同名、编号及嵌套候选，输出原文；模型继续判断词族和交叉引用范围 |
| 申请 | 主库 0014_chapter_quality，一份申请一行紧凑状态；同版本/策略活动申请去重，明确重审另建记录 |
| 执行 | 原 question-worker 共用监测器；先原教材清单，再用法/例句/范文引用/译文，最后全文与反证复核 |
| 发现 | 同根因关联由模型明确归并，程序校验目标/引文；未完成归并保留疑义，不凭同词头自动合并或宣布通过 |
| 恢复 | 自然工作块存验证结果，部分检查点引用内容摘要，最终一次合并；完整有效输出只重传，不重复推理 |
| 资格 | 服务器从固定证据和完成检查点重算结论；缺项、伪造引文、失效租约/attempt 或不同终态报告不能签发 |
| 文件 | 证据、阶段产物、原始模型返回和报告存 OneDrive；work/quality 纳入原归档并排除 Git；D1 不存长报告 |
| 界面 | 标题右侧“质检”，蓝银独立窗口、记录/阶段/报告/逐词详情、安全引文、固定版本定位；关闭保留阅读位置 |

结果区分无阻断问题、需修订、待核实及未完成，不使用尚未校准的总分，不授予学习者认证。未形成证据闭合或必要反证结论时不显示通过。
