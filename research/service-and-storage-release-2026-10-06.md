# 章节答疑与永久存储正式升级

北京时间 2026-10-06。本页记录实际工程结果；早先 research 文件是各阶段依据。当前执行权威为 AGENTS.md、OPERATIONS.md、protocol/CHAPTER_QUESTIONS.md、protocol/STORAGE.md 及对应生效代码。

## 已实施

1. 章节标题页答疑入口、中文会话窗口、新回复红点、本机草稿、串行队列、固定全文和会话上下文、回答去重回推、失败明确重新处理。Windows 每分钟普通队列检查，空队列不启动 Codex。实际分析采用本人现有 Codex 登录、gpt-6-sol/high；全文直接提供，不以第三方模型取代。任务末尾更新额度并排入独立资料归档。
2. OneDrive 个人应用目录为永久大文件基座；D1 保留关系与状态，KV 保留近期正文及故障兼容。服务器 Graph 凭据 AES-GCM 加密，密钥为 Worker secret；本机凭据使用 Windows 当前用户 DPAPI。没有扩大网盘权限，没有公开预授权下载 URL。
3. 正式日课新版本先存永久文件再写三十天缓存；阅读、答疑、雅思历史来源均可从永久正文回读。短点读从 D1 BLOB 移至永久音频位置，既有文本/声音身份继续复用。长练习音频、原声、完整模型返回和参考/作答状态通过既有适配层接入永久存储；写入故障保留兼容副本及归档标记。
4. 默认开启章节已有点读音频预下载，单一设置开关。按章顺序读取八 MiB 包，完整包与切片 SHA-256 核验；不自动合成、不按词附近预测下载。正文先显示，关闭预下载仍保持正常正文/索引和按需发音。仅下载已有音频，未来点击的新声音在下一次任务收尾并入章节包。
5. 独立本机归档服务不阻塞答疑：只归档待迁移文件、只更新有新增声音的章节包；工作文稿按任务组压缩切块，快照数据页按摘要复用。永久表、历史版本与原始工作材料保留，正式临时页及会话凭据不进入永久快照。快照本机重建验证完整性和外键后才发布恢复清单。
6. OneDrive recovery-index.json 独立保留各次快照直接定位；每份快照含全部恢复页与工作块的直接 itemId。恢复 --direct 只需 Microsoft 应用目录授权，生产 Cloudflare 数据库和 publisher 凭据不可用也可恢复。先恢复独立目录，生产库不会被验证脚本覆盖。

## 资源与工程取舍

- 本次不改 VIX 选词、日课四十主词、雅思范围/题量、休息开关和既有日课/雅思任务时间。
- Graph app folder 根目录创建 children 必须使用已解析的实际 itemId；实际 special/approot/children 创建失败已修正。
- 免费 Worker 单轮外部请求预算包括 Graph 上传、回读校验与模型请求。原声采集据此分批推进，仍保留全部四路证据；不把分批当删减模型的理由。
- OneDrive 是永久文件库，D1 是关系数据库，不对每次阅读做跨库轮换，不另开收费 R2。所有已生成资产保持永久身份，不为缓存失效付费重建。
- 任务目录和数据页去重复用，恢复清单排除备份自身目录，避免备份递归膨胀。快照导出发生并发不一致时核验阻止发布该清单，已有块保留供重试。
- 普通文件归档可有限重试；这不是余额不足的自动生成续作。余额页面仍只显示上次任务查询记录。
- QA 的电脑运行、Windows 会话、网络和 Codex 登录是实际运行前提；OneDrive 访问需维持有效授权与存储容量。不是承诺任意断网或账户停用时始终在线。
