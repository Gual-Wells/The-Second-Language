# 第六版：显示保真、古旧轮廓与连续卷展

2026-10-17。基线`codex/medieval-scroll-lab-2026-10-16@b09d256`，起点干净；仅试样与作用域样式，不替换生产入口。

## 用户决定

- 高分辨率应更清楚显示缺陷、污损、纹理，不能用增加照明、高光或漂白实现。
- 皮扣取消果冻化动作，恢复第四版并缩小；不继续完善本轮弹簧方案。
- 从第四版有年代感的素材方向继续，不能把“避免脏污”误解为清除所有使用痕迹。
- **古旧不包括霉变。**第一轮新增素材出现黑点簇、灰黑斑块而被否决；最终版重新去除，保留暖色手持磨痕、旧水痕及折谷积尘。
- 边缘需要手工裁切与长期使用的合理轮廓，避免一圈焦脆边及过多圆润角。

## 核实与处理

### 明暗与细节

第五版仍继承强光、ACES和非金属反射。第六版关镜面与sheen，采用中性、受控漫反射并取消ACES再调色。由于素材已包含细小受光，近乎正视的区域保留45%纹理原稿作为明暗参照，曲面过渡到动态漫反射，避免相同细节被重复照亮。不是通过加锐、增加随机噪声或全局调亮来提高保真。

`check-scroll-fidelity-v6.mjs`以实际GPU导出与真实排字原稿的同UV区域比较，排除字形边缘，使用匹配物理面积的均值避免不同分辨率的单像素采样混叠。它核对宽尺度磨痕/色差能否保留，**不衡量原生纹理分辨率、真实材料精度或美术质量**。最初单像素探针受微纹理、字边与采样位置影响，不作为最终质量门槛。最终结果见`fidelity.json`。

### 白线根因

旧顶点函数只在展开分支增加残余卷边，且在最后9%内用完成权重覆盖连接处衰减，使卷绕区和展开区在同一边界不再相接。

`check-scroll-continuity-v6.mjs`将实际v5/v6 GLSL交给WebGL2 transform feedback执行，在7个末段进度、5个横向点，取连接两侧相距0.00004世界单位的点：旧版最大间距约0.315824，新版约0.00004695。新版非零值主要是两个采样点原本有间隔，不能将它冒称“绝对零误差”。`last-turn-*`截图另核对最终实际着色画面；反向也使用同一状态函数。

### 皮扣

取消Cannon及柔性网格，恢复v4相同进度、位置与角度函数。几何`.41×.77`，对应v4的`.53×.99`约77%；不是把整张画布缩小或改变卷轴。纸卷本身仍用v5的高密度显示与GPU变形。

### 纸膜设计

最终素材由v4方向编辑两轮。第一轮重做裁边和积污，但黑点及灰斑有霉变读感，未采用；原件仅保留本机任务缓存作恢复。第二轮明确移除这些表现。主要轮廓是连续刀裁边、局部轻微不直、少量斜切角和短裂口；并非四边等量损坏。

动态/图像/字库与研究来源集中于[页面来源](../../web/labs/chapter-scroll-v6/CREDITS.md)。图像不是历史实物扫描，不声称完成了生物/机械老化仿真。

## 验收边界
